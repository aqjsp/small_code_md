# C++继承与多态概念指南

## 1. 继承的核心概念

### 1.1 什么是继承

继承是面向对象编程的基础特性之一，它允许一个类（派生类）获得另一个类（基类）的属性和行为。继承建立了"is-a"关系，表示派生类是基类的一种特殊形式。

继承的本质是代码重用和概念抽象。通过继承，我们可以：
- 避免重复编写相似的代码
- 建立清晰的概念层次
- 支持多态行为
- 提高代码的可维护性

**继承的核心思想**：

继承不仅仅是代码重用的机制，更是一种表达概念关系的工具。在现实世界中，许多事物之间存在自然的层次关系，例如"狗是哺乳动物"、"哺乳动物是动物"。继承机制允许我们在代码中直接表达这种关系，使程序结构更加符合现实世界的模型。

**继承的设计原则**：

1. **里氏替换原则（Liskov Substitution Principle）**：
   - 派生类对象应该能够替换基类对象，而不影响程序的正确性
   - 派生类应该扩展基类的功能，而不是改变基类的行为
   - 违反这一原则会导致多态行为异常和难以预测的程序行为

2. **接口隔离原则（Interface Segregation Principle）**：
   - 基类应该提供最小化的接口，避免强迫派生类实现不需要的方法
   - 可以通过抽象基类或接口来分离不同的关注点

3. **单一职责原则（Single Responsibility Principle）**：
   - 每个类应该只有一个变化的理由
   - 基类和派生类都应该有明确的职责边界

**继承的最佳实践**：

1. **优先使用组合而非继承**：
   - 继承应该用于表达"is-a"关系，而不是代码重用
   - 对于"has-a"关系，应该使用组合
   - 过度使用继承会导致类层次结构复杂和脆弱的基类问题

2. **保持继承层次的浅层**：
   - 深层继承（超过3-4层）会增加理解和维护的难度
   - 考虑使用组合或设计模式来替代深层继承

3. **使用虚析构函数**：
   - 当基类指针指向派生类对象时，基类析构函数应该声明为虚函数
   - 这确保了正确的析构顺序和资源释放

4. **谨慎使用多重继承**：
   - 多重继承增加了复杂性，可能导致菱形继承问题
   - 考虑使用接口或组合来替代多重继承

5. **避免在构造函数和析构函数中调用虚函数**：
   - 在这些函数中调用虚函数不会产生多态行为
   - 可能导致调用未完全构造或已部分析构的对象的方法

### 1.2 继承的类型

**公有继承（public inheritance）**
- 最常用的继承方式
- 保持基类的访问控制级别
- 支持完整的"is-a"关系
- 允许派生类对象替代基类对象使用

公有继承是最符合面向对象思想的继承方式，它建立了真正的"is-a"关系。在这种继承中，基类的公有成员在派生类中仍然是公有成员，基类的保护成员在派生类中仍然是保护成员，而基类的私有成员对派生类不可见但仍然存在于对象中。

公有继承的设计意图是创建一个特化的类，该类可以完全替代基类使用。例如，"狗"是"哺乳动物"的一种特化，因此"狗"类应该公有继承"哺乳动物"类。

**保护继承（protected inheritance）**
- 将基类的公有成员变为保护成员
- 主要用于受限的接口继承
- 使用场景相对有限

保护继承改变了基类公有成员的访问级别，使它们在派生类中变为保护成员。这意味着派生类的成员函数可以访问这些成员，但派生类的对象不能直接访问它们。

保护继承通常用于实现"implemented-in-terms-of"关系，但又不希望暴露基类的接口。这种继承方式在实际应用中较少使用，因为它破坏了基类的接口契约。

**私有继承（private inheritance）**
- 将基类的所有成员变为私有
- 表达"implemented-in-terms-of"关系
- 用于实现继承而非接口继承

私有继承将基类的公有和保护成员都变为派生类的私有成员。这意味着派生类的成员函数可以访问这些成员，但派生类的对象和进一步派生的类都不能访问它们。

私有继承主要用于实现继承，即派生类使用基类的实现，但不希望暴露基类的接口。在现代C++中，私有继承通常可以被组合替代，因为组合提供了更清晰的关系表达和更少的设计约束。

**继承访问控制的内存模型**：

继承不仅影响访问控制，还影响对象的内存布局。在大多数C++实现中，派生类对象包含一个完整的基类子对象，然后是派生类自己的成员。这种布局确保了派生类对象可以被当作基类对象使用，因为基类子对象的内存布局与基类对象完全相同。

**继承与构造函数/析构函数**：

继承关系会影响构造函数和析构函数的调用顺序：
1. 构造函数调用顺序：先调用基类构造函数，再调用派生类构造函数
2. 析构函数调用顺序：先调用派生类析构函数，再调用基类析构函数

这种顺序确保了对象正确初始化和清理，特别是当基类和派生类都有资源管理需求时。

### 1.3 单继承与多重继承

**单继承（Single Inheritance）**
- 一个类直接继承自一个基类
- 继承关系清晰简单
- 避免了复杂的继承层次问题

单继承是最简单的继承形式，它建立了线性的继承层次结构。在单继承中，每个类最多只有一个直接基类，这使得继承关系非常清晰，易于理解和维护。

单继承的优点包括：
1. 简单性：继承关系直观，容易理解类的层次结构
2. 可维护性：修改基类时影响范围有限，容易预测
3. 避免歧义：不存在名称冲突和二义性问题
4. 性能：对象布局简单，虚函数表结构清晰

然而，单继承也有局限性，它无法表达一个类同时具有多个不同特性的情况。例如，一个"会飞的游泳动物"无法通过单继承同时表达"飞行动物"和"游泳动物"的特性。

**多重继承（Multiple Inheritance）**
- 一个类可以同时继承自多个基类
- 提供更灵活的设计能力
- 需要处理潜在的冲突和复杂性

多重继承允许一个派生类同时继承多个基类的特性，这提供了比单继承更大的设计灵活性。通过多重继承，可以组合不同基类的功能，创建具有多重特性的复合类。

多重继承的主要挑战包括：
1. **名称冲突**：当多个基类有相同名称的成员时，需要显式限定
2. **菱形继承问题**：当多个基类继承自同一个共同基类时，会导致数据成员重复
3. **对象布局复杂性**：多重继承的对象内存布局更加复杂
4. **构造函数调用顺序**：需要明确多个基类构造函数的调用顺序

**菱形继承问题**：

菱形继承是多重继承中最著名的问题，它发生在以下继承结构中：
```
      Base
     /    \
  Left    Right
     \    /
    Derived
```

在这种结构中，`Derived`类通过`Left`和`Right`两条路径继承了`Base`类，导致`Base`类的成员在`Derived`对象中出现两次。这不仅是内存浪费，还可能导致访问歧义。

C++通过**虚继承**（virtual inheritance）解决菱形继承问题。虚继承确保在继承层次中共享基类的单一实例，而不是创建多个副本。

**多重继承的设计原则**：

1. **优先使用组合**：在可能的情况下，优先考虑组合而非继承
2. **保持接口简洁**：每个基类应该代表一个明确的抽象或特性
3. **使用虚继承解决菱形问题**：当可能出现菱形继承时，使用虚继承
4. **明确继承关系**：确保每个继承关系都有明确的"is-a"语义

**多重继承的应用场景**：

多重继承在以下场景中特别有用：
1. **混入类（Mixin Classes）**：添加可选功能而不影响主要继承层次
2. **接口组合**：从多个抽象基类继承接口
3. **策略模式**：通过继承不同的策略类实现算法选择
4. **特性组合**：组合多个不相关的特性类

现代C++设计倾向于谨慎使用多重继承，特别是在复杂的继承层次中。许多情况下，组合和接口设计可以提供更清晰的解决方案。

## 2. 多态的基本原理

### 2.1 多态的概念

多态（Polymorphism）是面向对象编程的三大特性之一，它允许不同类的对象对同一消息做出不同的响应。多态的字面意思是"多种形态"，在编程中指的是同一接口或操作可以作用于不同类型的对象，并产生不同的行为。

多态的核心思想是将"做什么"与"怎么做"分离开来，通过统一的接口处理不同的对象类型，而不需要知道对象的具体类型。这种机制大大提高了代码的灵活性和可扩展性，使得程序更容易适应需求变化。

**多态的类型**：

C++支持两种主要的多态形式：
1. **编译时多态（静态多态）**：在编译阶段确定调用哪个函数
2. **运行时多态（动态多态）**：在运行阶段确定调用哪个函数

这两种多态形式各有特点，适用于不同的场景，共同构成了C++强大的多态支持。

**多态的优势**：

1. **代码复用**：通过统一的接口处理不同类型的对象
2. **扩展性**：添加新类型不需要修改现有代码
3. **灵活性**：可以在运行时决定使用哪种具体实现
4. **解耦**：减少代码间的直接依赖关系

多态的核心价值在于：
- 提高代码的灵活性
- 支持开闭原则（对扩展开放，对修改关闭）
- 简化客户端代码
- 支持统一的接口处理不同类型的对象

### 2.2 静态多态与动态多态

**静态多态（Static Polymorphism）**
- 在编译时确定函数调用
- 主要通过函数重载和模板实现
- 执行效率高，无运行时开销
- 类型安全，编译时检查

静态多态是通过编译器在编译阶段解析函数调用实现的，它不需要运行时的类型检查和函数查找，因此执行效率很高。静态多态主要有两种实现方式：

1. **函数重载**：在同一作用域内定义多个同名函数，但参数列表不同
2. **模板**：通过泛型编程实现类型无关的算法和容器

静态多态的优点是性能优异，因为所有类型信息在编译时都已确定，编译器可以进行充分的优化。缺点是灵活性相对较低，需要在编译时知道所有可能的类型。

**动态多态（Dynamic Polymorphism）**
- 在运行时确定函数调用
- 通过继承和虚函数实现
- 提供更大的灵活性
- 有一定的运行时开销

动态多态是通过虚函数机制实现的，它允许在运行时根据对象的实际类型调用相应的函数版本。这种机制使得程序可以在不知道对象具体类型的情况下处理对象，提供了极大的灵活性。

**静态多态与动态多态的比较**：

| 特性 | 静态多态 | 动态多态 |
|------|----------|----------|
| 绑定时间 | 编译时 | 运行时 |
| 实现方式 | 函数重载、模板 | 虚函数 |
| 性能开销 | 无 | 有（虚函数调用） |
| 类型安全 | 编译时检查 | 运行时检查 |
| 灵活性 | 较低 | 较高 |
| 代码膨胀 | 可能较大（模板实例化） | 较小 |

### 2.3 虚函数的工作机制

**虚函数表（Virtual Function Table）**

虚函数表（常简称为vtable）是C++实现动态多态的核心机制。每个包含虚函数的类都有一个对应的虚函数表，这个表是一个函数指针数组，存储了该类所有虚函数的地址。

**虚函数表的结构**：

虚函数表通常按照以下规则构建：
1. 表中按照虚函数在类中声明的顺序存储函数指针
2. 如果派生类重写了基类的虚函数，则用派生类的函数地址替换基类的函数地址
3. 如果派生类添加了新的虚函数，则将新函数的指针添加到表的末尾
4. 纯虚函数在表中也有对应的条目（在某些实现中可能为空或指向特殊函数）

**虚函数指针（vptr）**：

每个包含虚函数的类的对象都会包含一个隐藏的指针成员，称为虚函数指针（vptr），它指向该类对应的虚函数表。这个指针通常由编译器在对象的内存布局中自动添加，位置可能因编译器而异（通常在对象开始处）。

**虚函数调用的过程**：

当通过基类指针或引用调用虚函数时，发生以下过程：
1. 程序通过对象的vptr找到对应的虚函数表
2. 在虚函数表中查找被调用函数的指针
3. 通过函数指针调用实际的函数实现

这个过程发生在运行时，因此能够根据对象的实际类型调用正确的函数版本。

**虚函数表的内存布局**：

考虑以下继承层次：
```cpp
class Base {
public:
    virtual void func1() {}
    virtual void func2() {}
};

class Derived : public Base {
public:
    void func1() override {}  // 重写
    virtual void func3() {}  // 新增
};
```

对应的虚函数表布局大致如下：
```
Base的vtable:
[0] &Base::func1
[1] &Base::func2

Derived的vtable:
[0] &Derived::func1  // 重写Base::func1
[1] &Base::func2     // 继承Base::func2
[2] &Derived::func3  // 新增虚函数
```

**多重继承中的虚函数表**：

在多重继承情况下，情况更加复杂：
1. 每个基类都有自己的虚函数表
2. 派生类对象包含多个vptr，分别指向不同的虚函数表
3. 调用虚函数时，需要通过适当的vptr查找对应的虚函数表

**虚函数表的实现细节**：

虽然C++标准没有规定虚函数表的具体实现方式，但大多数编译器采用类似的策略：
1. 虚函数表通常是静态数据，每个类共享一个表
2. 对象中的vptr在构造函数中初始化
3. 析构函数调用过程中，vptr会被更新为基类的vptr

**虚函数调用的性能开销**：

虚函数调用相比普通函数调用有一些额外开销：
1. 间接调用：需要通过指针跳转，无法内联
2. 缓存未命中：虚函数表可能导致缓存效率降低
3. 分支预测：虚函数调用可能降低分支预测准确率

然而，现代CPU和编译器的优化使得这种开销在大多数情况下可以接受。对于性能关键代码，可以考虑使用静态多态（模板）替代。

**虚函数与构造函数/析构函数**：

在构造函数和析构函数中调用虚函数有特殊规则：
1. 构造函数中调用虚函数，不会发生动态绑定，而是调用当前类的版本
2. 析构函数中调用虚函数，同样不会发生动态绑定

这是因为对象的构造和析构是分阶段进行的，在某个阶段中，对象只是部分构造或部分析构，不能安全地调用派生类的实现。

### 2.4 纯虚函数与抽象类

**纯虚函数的概念**

纯虚函数是在基类中声明但没有实现的虚函数，它在基类中的声明形式为在函数声明后加上 "= 0"。纯虚函数的存在使得该类成为抽象类，不能被实例化。

纯虚函数的主要作用是定义接口契约，强制派生类必须提供特定的实现。这种机制允许程序员在基类中定义一组操作，而不必提供具体的实现，将实现的责任委托给派生类。

**抽象类的特性**

抽象类是包含至少一个纯虚函数的类，具有以下特性：
1. 不能直接实例化抽象类
2. 可以作为基类被其他类继承
3. 可以包含非纯虚函数和成员变量
4. 可以提供构造函数和析构函数
5. 派生类必须实现所有纯虚函数才能成为具体类

抽象类的设计目的是为了定义一个通用的接口和行为框架，为派生类提供一致的结构和契约。

**抽象类与接口的区别**

在C++中，没有专门的"interface"关键字，但可以通过抽象类模拟接口。抽象类和接口的概念有细微差别：

1. **抽象类**：可以包含实现代码和成员变量，提供部分通用实现
2. **接口**：通常只包含纯虚函数，不包含实现代码和成员变量

在实际设计中，可以根据需求选择使用抽象类或接口：
- 需要共享代码时，使用抽象类
- 只需要定义契约时，使用接口风格的抽象类

**抽象类的设计原则**

1. **最小接口原则**：只包含必要的纯虚函数，避免接口过于庞大
2. **职责单一**：每个抽象类应该代表一个明确的抽象概念
3. **稳定性**：接口一旦定义，应尽量避免修改，以免影响现有实现
4. **文档完整**：为每个纯虚函数提供清晰的文档说明其行为和约定

**抽象类的应用场景**

1. **框架设计**：定义扩展点和插件接口
2. **策略模式**：定义可互换的算法族
3. **模板方法模式**：定义算法骨架，将具体步骤延迟到子类
4. **组件系统**：定义组件间的交互协议

**抽象类的最佳实践**

1. **虚析构函数**：抽象类通常应声明虚析构函数，确保通过基类指针删除派生类对象时正确调用析构函数
2. **访问控制**：根据需要选择适当的访问控制（public或protected）
3. **参数和返回值**：尽量使用基类引用或指针作为参数和返回值，增强灵活性
4. **异常规范**：考虑在纯虚函数声明中添加异常规范，明确可能抛出的异常

**抽象类与多重继承**

抽象类在多重继承中特别有用，因为：
1. 抽象类通常不包含数据成员，减少了多重继承的复杂性
2. 可以通过多个抽象类组合多个接口
3. 避免了菱形继承问题的许多复杂性

**现代C++中的接口设计**

C++11及以后版本提供了一些增强接口设计的特性：
1. **override关键字**：明确标识重写函数，提高代码可读性
2. **final关键字**：防止进一步重写，增强安全性
3. **=default和=delete**：更精确地控制特殊成员函数
4. **智能指针**：更好的资源管理，与接口结合使用更安全

**接口隔离原则（ISP）**

接口隔离原则建议客户端不应该依赖它不需要的接口。在C++中，这意味着：
1. 设计小而专注的抽象类
2. 避免创建庞大的"万能"接口
3. 通过多重继承组合多个小接口

这种设计使得系统更加灵活，减少了不必要的依赖关系，提高了代码的可维护性。

```cpp
class Triangle : public Shape {
private:
    double side1, side2, side3;
    
public:
    Triangle(double s1, double s2, double s3) 
        : Shape("三角形"), side1(s1), side2(s2), side3(s3) {
        if (!isValidTriangle()) {
            throw std::invalid_argument("无效的三角形边长");
        }
        std::cout << "创建三角形: " << side1 << ", " << side2 << ", " << side3 << std::endl;
    }
    
    ~Triangle() {
        std::cout << "销毁三角形" << std::endl;
    }
    
    // 实现纯虚函数
    double getArea() const override {
        // 使用海伦公式
        double s = getPerimeter() / 2;
        return sqrt(s * (s - side1) * (s - side2) * (s - side3));
    }
    
    double getPerimeter() const override {
        return side1 + side2 + side3;
    }
    
    void draw() const override {
        std::cout << "绘制三角形 (" << side1 << ", " << side2 << ", " << side3 << ")" << std::endl;
        std::cout << "    *    " << std::endl;
        std::cout << "   * *   " << std::endl;
        std::cout << "  *   *  " << std::endl;
        std::cout << " *     * " << std::endl;
        std::cout << "********* " << std::endl;
    }
    
    // 三角形特有的方法
    bool isValidTriangle() const {
        return (side1 + side2 > side3) && 
               (side1 + side3 > side2) && 
               (side2 + side3 > side1);
    }
    
    bool isEquilateral() const {
        return side1 == side2 && side2 == side3;
    }
    
    bool isIsosceles() const {
        return side1 == side2 || side2 == side3 || side1 == side3;
    }
};
```

## 4. 继承与多态的设计模式

继承与多态是面向对象编程的核心机制，它们为许多设计模式提供了基础。下面介绍几种与继承和多态密切相关的设计模式及其在实际开发中的应用。

### 4.1 策略模式（Strategy Pattern）

**概念与原理**：

策略模式定义了一系列算法，并将每个算法封装起来，使它们可以互相替换。策略模式让算法的变化独立于使用算法的客户。这个模式通过继承和多态机制，允许在运行时动态选择算法。

**设计优势**：

1. **算法可替换性**：可以在运行时切换不同的算法实现
2. **代码复用**：避免使用条件语句来选择算法
3. **扩展性**：添加新算法不需要修改现有代码
4. **单一职责**：每个算法类只负责一个特定的算法实现

**实际应用场景**：

- 数据压缩算法选择（ZIP、RAR、7Z等）
- 排序算法选择（快速排序、归并排序、堆排序等）
- 支付方式选择（信用卡、支付宝、微信支付等）
- 路径规划算法选择（最短路径、最快路径、最少收费等）

### 4.2 模板方法模式（Template Method Pattern）

**概念与原理**：

模板方法模式在一个方法中定义一个算法的骨架，而将一些步骤延迟到子类中。模板方法使得子类可以不改变一个算法的结构即可重定义该算法的某些特定步骤。这个模式充分利用了继承和多态的特性。

**设计优势**：

1. **代码复用**：避免重复代码，将通用代码放在基类中
2. **控制反转**：父类调用子类的操作，而不是相反
3. **扩展性**：子类可以扩展或重写父类的特定步骤
4. **一致性**：确保算法的整体结构保持一致

**实际应用场景**：

- 数据库访问流程（连接、查询、处理结果、关闭连接）
- 文件处理流程（打开、读取、处理、关闭）
- 游戏角色生命周期（初始化、更新、渲染、销毁）
- 测试框架执行流程（设置、执行、清理）

### 4.3 观察者模式（Observer Pattern）

**概念与原理**：

观察者模式定义了对象之间的一对多依赖关系，当一个对象（被观察者）状态发生改变时，所有依赖于它的对象（观察者）都会得到通知并自动更新。这个模式通过继承和多态实现松耦合的通信机制。

**设计优势**：

1. **松耦合**：被观察者和观察者之间是松耦合的
2. **广播机制**：支持一对多的依赖关系
3. **动态关系**：可以在运行时动态添加和删除观察者
4. **可复用性**：观察者和被观察者可以独立变化和复用

**实际应用场景**：

- GUI事件处理（按钮点击、鼠标移动等）
- 股票价格监控系统
- 社交媒体通知系统
- 消息队列和发布/订阅系统

### 4.4 工厂方法模式（Factory Method Pattern）

**概念与原理**：

工厂方法模式定义了一个用于创建对象的接口，但让子类决定实例化哪一个类。工厂方法使一个类的实例化延迟到其子类。这个模式利用了继承和多态来实现对象创建的灵活性。

**设计优势**：

1. **解耦**：将对象的创建和使用分离
2. **扩展性**：添加新产品类不需要修改现有代码
3. **封装性**：隐藏了具体产品类的实现细节
4. **一致性**：通过统一的接口创建不同类型的对象

**实际应用场景**：

- 数据库连接创建（MySQL、PostgreSQL、SQLite等）
- 日志记录器创建（文件日志、控制台日志、远程日志等）
- UI组件创建（按钮、文本框、列表等）
- 文档处理器创建（Word、PDF、Excel等）

### 4.5 装饰器模式（Decorator Pattern）

**概念与原理**：

装饰器模式动态地给一个对象添加一些额外的职责，就增加功能来说，装饰器模式相比生成子类更为灵活。这个模式通过继承和多态机制，允许在不改变对象结构的情况下扩展对象的功能。

**设计优势**：

1. **灵活性**：比静态继承更灵活地添加功能
2. **可组合**：可以组合多个装饰器实现复杂功能
3. **透明性**：装饰器对客户端透明
4. **单一职责**：每个装饰器只负责一个特定的功能增强

**实际应用场景**：

- GUI组件装饰（添加滚动条、边框、阴影等）
- 流处理（缓冲流、加密流、压缩流等）
- Web中间件（认证、日志、缓存等）
- 游戏装备系统（武器附加属性、防具附加效果等）

### 4.6 状态模式（State Pattern）

**概念与原理**：

状态模式允许一个对象在其内部状态改变时改变它的行为，对象看起来似乎修改了它的类。这个模式通过继承和多态，将状态相关的行为局部化，并将不同状态的行为分离开来。

**设计优势**：

1. **状态封装**：将每个状态的行为封装到独立的类中
2. **可扩展性**：添加新状态不需要修改现有代码
3. **避免条件语句**：减少大型条件语句的使用
4. **清晰性**：使状态转换更加明确和可控

**实际应用场景**：

- 游戏角色状态（站立、行走、跳跃、攻击等）
- 订单状态处理（待支付、已支付、已发货、已完成等）
- 网络连接状态（连接中、已连接、断开连接等）
- 音视频播放器状态（播放、暂停、停止、快进等）

### 4.7 访问者模式（Visitor Pattern）

**概念与原理**：

访问者模式表示一个作用于某对象结构中的各元素的操作。它使你可以在不改变各元素的类的前提下定义作用于这些元素的新操作。这个模式通过继承和多态，将操作从数据结构中分离出来。

**设计优势**：

1. **操作集中**：将相关操作集中到一个访问者类中
2. **数据结构稳定**：不需要修改数据结构类
3. **灵活性**：可以添加新的操作而不影响数据结构
4. **分离关注点**：将数据结构和操作分离

**实际应用场景**：

- 编译器语法树遍历和操作
- 文档对象模型（DOM）操作
- 复杂数据结构的分析处理
- 代码生成和转换工具

### 4.8 设计模式选择指南

**根据需求选择合适的设计模式**：

1. **需要算法替换**：选择策略模式
2. **需要固定流程但步骤可变**：选择模板方法模式
3. **需要一对多通知机制**：选择观察者模式
4. **需要灵活创建对象**：选择工厂方法模式
5. **需要动态添加功能**：选择装饰器模式
6. **需要状态相关行为**：选择状态模式
7. **需要对复杂结构操作**：选择访问者模式

**设计模式的组合使用**：

在实际项目中，设计模式往往不是孤立使用的，而是组合使用以解决更复杂的问题：

- 策略模式与工厂方法模式结合，实现策略的动态创建和替换
- 观察者模式与模板方法模式结合，实现通知流程的标准化
- 装饰器模式与工厂方法模式结合，实现装饰对象的创建
- 状态模式与策略模式结合，实现状态相关的策略选择

**设计模式的最佳实践**：

1. **不要过度设计**：只在确实需要灵活性和扩展性时使用设计模式
2. **理解模式的意图**：不要为了使用模式而使用模式
3. **保持简单**：优先选择最简单的解决方案
4. **考虑性能**：某些模式可能引入额外的性能开销
5. **文档化**：记录设计模式的使用原因和方式

通过合理使用这些设计模式，可以充分发挥继承和多态的优势，创建出灵活、可维护、可扩展的软件系统。

## 5. 继承与多态的实际应用案例

理论知识和设计模式最终要应用到实际项目中才能真正发挥价值。本章将通过几个实际应用案例，展示继承和多态在真实场景中的应用，帮助读者更好地理解如何在实际开发中有效使用这些概念。

### 5.1 游戏开发中的继承与多态

游戏开发是继承和多态应用的典型场景，因为游戏世界通常包含各种不同类型的实体，它们有共同的行为但也有各自的特点。

```cpp
class GameObject {
protected:
    float x_, y_;          // 位置坐标
    float width_, height_; // 尺寸
    float health_;         // 生命值
    bool active_;          // 是否激活
    
public:
    GameObject(float x, float y, float width, float height, float health)
        : x_(x), y_(y), width_(width), height_(height), health_(health), active_(true) {}
    
    virtual ~GameObject() = default;
    
    // 纯虚函数，定义游戏实体的基本行为
    virtual void update(float deltaTime) = 0;
    virtual void render() const = 0;
    virtual void handleCollision(GameObject* other) = 0;
    
    // 通用方法
    virtual void takeDamage(float amount) {
        health_ -= amount;
        if (health_ <= 0) {
            active_ = false;
        }
    }
    
    // 获取状态
    bool isActive() const { return active_; }
    float getX() const { return x_; }
    float getY() const { return y_; }
    float getHealth() const { return health_; }
    
    // 设置位置
    void setPosition(float x, float y) {
        x_ = x;
        y_ = y;
    }
};
```

```cpp
// 敌人基类
class Enemy : public GameObject {
protected:
    float speed_;
    int scoreValue_;
    
public:
    Enemy(float x, float y, float width, float height, float health, 
          float speed, int scoreValue)
        : GameObject(x, y, width, height, health),
          speed_(speed), scoreValue_(scoreValue) {}
    
    void handleCollision(GameObject* other) override {
        Bullet* bullet = dynamic_cast<Bullet*>(other);
        if (bullet && bullet->isPlayerBullet()) {
            takeDamage(bullet->getDamage());
            bullet->setActive(false);
            
            if (!isActive()) {
                // 敌人被消灭，增加玩家分数
                Player* player = gameManager->getPlayer();
                if (player) {
                    player->addScore(scoreValue_);
                }
            }
        }
    }
    
    int getScoreValue() const { return scoreValue_; }
};

class TrackingEnemy : public Enemy {
private:
    float detectionRange_;
    
public:
    TrackingEnemy(float x, float y) 
        : Enemy(x, y, 28.0f, 28.0f, 30.0f, 80.0f, 25),
          detectionRange_(200.0f) {}
    
    void update(float deltaTime) override {
        Player* player = gameManager->getPlayer();
        if (player) {
            // 计算与玩家的距离
            float dx = player->getX() - x_;
            float dy = player->getY() - y_;
            float distance = sqrt(dx*dx + dy*dy);
            
            // 如果在检测范围内，则追踪玩家
            if (distance <= detectionRange_) {
                // 归一化方向向量
                dx /= distance;
                dy /= distance;
                
                // 向玩家方向移动
                x_ += dx * speed_ * deltaTime;
                y_ += dy * speed_ * deltaTime;
            } else {
                // 默认向下移动
                y_ -= speed_ * deltaTime;
            }
        } else {
            // 没有玩家时默认向下移动
            y_ -= speed_ * deltaTime;
        }
        
        // 如果移出屏幕底部，则标记为非激活
        if (y_ < -height_) {
            setActive(false);
        }
    }
    
    void render() const override {
        // 渲染追踪敌人
        drawCircle(x_, y_, width_/2, ORANGE);
```

```cpp
class GameManager {
private:
    std::vector<std::unique_ptr<GameObject>> gameObjects_;
    Player* player_;
    float enemySpawnTimer_;
    float enemySpawnInterval_;
    int waveNumber_;
    
public:
    GameManager() 
        : player_(nullptr), enemySpawnTimer_(0.0f), 
          enemySpawnInterval_(2.0f), waveNumber_(1) {
        // 初始化游戏
        initGame();
    }
    
    void initGame() {
        // 创建玩家
        player_ = new Player(0.0f, -200.0f);
        gameObjects_.push_back(std::unique_ptr<GameObject>(player_));
    }
    
    void update(float deltaTime) {
        // 更新所有游戏对象
        for (auto& obj : gameObjects_) {
            if (obj->isActive()) {
                obj->update(deltaTime);
            }
        }
        
        // 处理碰撞检测
        handleCollisions();
        
        // 生成敌人
        spawnEnemies(deltaTime);
        
        // 移除非激活对象
        removeInactiveObjects();
        
        // 检查游戏状态
        checkGameState();
    }
    
    void render() const {
        // 渲染所有游戏对象
        for (const auto& obj : gameObjects_) {
            if (obj->isActive()) {
                obj->render();
            }
        }
        
        // 渲染UI
        renderUI();
    }
    
    void addGameObject(GameObject* obj) {
        gameObjects_.push_back(std::unique_ptr<GameObject>(obj));
    }
    
    Player* getPlayer() const { return player_; }
    
private:
    void handleCollisions() {
        // 简单的碰撞检测
        for (size_t i = 0; i < gameObjects_.size(); ++i) {
            if (!gameObjects_[i]->isActive()) continue;
            
            for (size_t j = i + 1; j < gameObjects_.size(); ++j) {
                if (!gameObjects_[j]->isActive()) continue;
                
                // 检查碰撞
                if (checkCollision(gameObjects_[i].get(), gameObjects_[j].get())) {
                    gameObjects_[i]->handleCollision(gameObjects_[j].get());
                    gameObjects_[j]->handleCollision(gameObjects_[i].get());
                }
            }
        }
    }
    
    bool checkCollision(const GameObject* a, const GameObject* b) {
        // 简单的矩形碰撞检测
        float aLeft = a->getX() - a->getWidth()/2;
        float aRight = a->getX() + a->getWidth()/2;
        float aTop = a->getY() + a->getHeight()/2;
        float aBottom = a->getY() - a->getHeight()/2;
        
        float bLeft = b->getX() - b->getWidth()/2;
        float bRight = b->getX() + b->getWidth()/2;
        float bTop = b->getY() + b->getHeight()/2;
        float bBottom = b->getY() - b->getHeight()/2;
        
        return !(aLeft > bRight || aRight < bLeft || aTop < bBottom || aBottom > bTop);
    }
    
    void spawnEnemies(float deltaTime) {
        enemySpawnTimer_ += deltaTime;
        
        if (enemySpawnTimer_ >= enemySpawnInterval_) {
            enemySpawnTimer_ = 0.0f;
            
            // 随机生成敌人
            float x = (rand() % 600) - 300.0f;  // -300 到 300
            float y = 250.0f;  // 屏幕顶部
            
            int enemyType = rand() % 3;
            switch (enemyType) {
                case 0:
                    addGameObject(new BasicEnemy(x, y));
                    break;
                case 1:
                    addGameObject(new TrackingEnemy(x, y));
                    break;
                case 2:
                    // 可以添加更多敌人类型
                    addGameObject(new BasicEnemy(x, y));
                    break;
            }
            
            // 随着波数增加，加快生成速度
            enemySpawnInterval_ = std::max(2.0f - waveNumber_ * 0.1f, 0.5f);
        }
    }
    
    void removeInactiveObjects() {
        gameObjects_.erase(
            std::remove_if(gameObjects_.begin(), gameObjects_.end(),
                [](const std::unique_ptr<GameObject>& obj) {
                    return !obj->isActive();
                }),
            gameObjects_.end());
    }
    
    void checkGameState() {
        if (!player_->isActive()) {
            // 游戏结束
            std::cout << "Game Over! Final Score: " << player_->getScore() << std::endl;
            // 重置游戏或显示游戏结束画面
        }
        
        // 检查是否需要进入下一波
        if (gameObjects_.size() <= 1) {  // 只有玩家
            waveNumber_++;
            std::cout << "Wave " << waveNumber_ << " incoming!" << std::endl;
        }
    }
    
    void renderUI() const {
        // 渲染分数、生命值等UI元素
        std::cout << "Score: " << player_->getScore() << std::endl;
        std::cout << "Health: " << player_->getHealth() << std::endl;
        std::cout << "Wave: " << waveNumber_ << std::endl;
    }
};
```

```cpp
class UIComponent {
protected:
```

```cpp
class Button : public UIComponent {
private:
    std::string text_;
    std::function<void()> onClick_;
    bool isHovered_;
    bool isPressed_;
    Color normalColor_;
    Color hoverColor_;
    Color pressedColor_;
    Color textColor_;
    
public:
    Button(float x, float y, float width, float height, const std::string& text,
           std::function<void()> onClick = nullptr)
        : UIComponent(x, y, width, height, "button_" + std::to_string(rand())),
          text_(text), onClick_(onClick), isHovered_(false), isPressed_(false),
          normalColor_(GRAY), hoverColor_(LIGHTGRAY), pressedColor_(DARKGRAY),
          textColor_(BLACK) {}
    
    void render() const override {
        if (!visible_) return;
        
        // 根据状态选择颜色
        Color color = normalColor_;
        if (!enabled_) {
            color = GRAY;
        } else if (isPressed_) {
            color = pressedColor_;
        } else if (isHovered_) {
            color = hoverColor_;
        }
        
        // 绘制按钮背景
        drawRectangle(x_, y_, width_, height_, color);
        
        // 绘制按钮边框
        drawRectangleLines(x_, y_, width_, height_, BLACK);
        
        // 绘制按钮文本
        float textWidth = measureText(text_.c_str(), 20);
        float textHeight = 20;
        float textX = x_ + (width_ - textWidth) / 2;
        float textY = y_ + (height_ - textHeight) / 2;
        
        drawText(text_.c_str(), textX, textY, 20, textColor_);
    }
    
    bool handleEvent(const Event& event) override {
        if (!visible_ || !enabled_) return false;
        
        if (event.type == EventType::MOUSE_MOVE) {
            // 检查鼠标是否悬停在按钮上
            bool wasHovered = isHovered_;
            isHovered_ = containsPoint(event.mouseX, event.mouseY);
            
            // 如果悬停状态改变，可能需要重新渲染
            return wasHovered != isHovered_;
        }
        else if (event.type == EventType::MOUSE_BUTTON_DOWN) {
            if (isHovered_) {
                isPressed_ = true;
                return true;
            }
        }
        else if (event.type == EventType::MOUSE_BUTTON_UP) {
            if (isPressed_ && isHovered_) {
                isPressed_ = false;
                
                // 触发点击事件
                if (onClick_) {
                    onClick_();
                }
                return true;
            }
            isPressed_ = false;
        }
        
        return false;
    }
    
    // 设置按钮样式
    void setColors(Color normal, Color hover, Color pressed, Color text) {
        normalColor_ = normal;
        hoverColor_ = hover;
        pressedColor_ = pressed;
        textColor_ = text;
    }
    
    // 设置点击回调
    void setOnClick(std::function<void()> onClick) {
        onClick_ = onClick;
    }
    
    const std::string& getText() const { return text_; }
    void setText(const std::string& text) { text_ = text; }
};
```

```cpp
class TextBox : public UIComponent {
private:
    std::string text_;
    std::string placeholder_;
    bool isFocused_;
    bool isPassword_;
    int maxLength_;
    int cursorPosition_;
    float cursorBlinkTimer_;
    bool showCursor_;
    Color backgroundColor_;
    Color textColor_;
    Color placeholderColor_;
    Color focusedBorderColor_;
    
public:
    TextBox(float x, float y, float width, float height, 
            const std::string& placeholder = "")
        : UIComponent(x, y, width, height, "textbox_" + std::to_string(rand())),
          text_(""), placeholder_(placeholder), isFocused_(false), 
          isPassword_(false), maxLength_(50), cursorPosition_(0),
          cursorBlinkTimer_(0.0f), showCursor_(true),
          backgroundColor_(WHITE), textColor_(BLACK), 
          placeholderColor_(GRAY), focusedBorderColor_(BLUE) {}
    
    void render() const override {
        if (!visible_) return;
        
        // 绘制文本框背景
        drawRectangle(x_, y_, width_, height_, backgroundColor_);
        
        // 绘制边框
        Color borderColor = isFocused_ ? focusedBorderColor_ : BLACK;
        drawRectangleLines(x_, y_, width_, height_, borderColor);
        
        // 确定要显示的文本
        std::string displayText = text_.empty() ? placeholder_ : text_;
        Color color = text_.empty() ? placeholderColor_ : textColor_;
        
        // 如果是密码框，则显示星号
        if (isPassword_ && !text_.empty()) {
            displayText = std::string(text_.length(), '*');
        }
        
        // 绘制文本
        float textX = x_ + 5;
        float textY = y_ + (height_ - 20) / 2;
        drawText(displayText.c_str(), textX, textY, 20, color);
        
        // 绘制光标
        if (isFocused_ && showCursor_) {
            float cursorX = textX + measureText(displayText.substr(0, cursorPosition_).c_str(), 20);
            drawLine(cursorX, textY, cursorX, textY + 20, BLACK);
        }
    }
    
    void update(float deltaTime) override {
        if (!visible_ || !enabled_) return;
        
        // 更新光标闪烁
        if (isFocused_) {
            cursorBlinkTimer_ += deltaTime;
            if (cursorBlinkTimer_ >= 0.5f) {
                showCursor_ = !showCursor_;
                cursorBlinkTimer_ = 0.0f;
            }
        }
    }
    
    bool handleEvent(const Event& event) override {
        if (!visible_ || !enabled_) return false;
        
        if (event.type == EventType::MOUSE_BUTTON_DOWN) {
            // 检查是否点击在文本框内
            bool wasFocused = isFocused_;
            isFocused_ = containsPoint(event.mouseX, event.mouseY);
            
            // 如果获得焦点，计算光标位置
            if (isFocused_ && !wasFocused) {
                calculateCursorPosition(event.mouseX);
            }
            
            return wasFocused != isFocused_;
        }
        else if (event.type == EventType::KEY_INPUT && isFocused_) {
            // 处理键盘输入
            if (event.key == KEY_BACKSPACE) {
                if (cursorPosition_ > 0) {
                    text_.erase(cursorPosition_ - 1, 1);
                    cursorPosition_--;
                }
            }
            else if (event.key == KEY_DELETE) {
                if (cursorPosition_ < text_.length()) {
                    text_.erase(cursorPosition_, 1);
                }
            }
            else if (event.key == KEY_LEFT) {
                if (cursorPosition_ > 0) {
                    cursorPosition_--;
                }
            }
            else if (event.key == KEY_RIGHT) {
                if (cursorPosition_ < text_.length()) {
                    cursorPosition_++;
                }
            }
            else if (event.key == KEY_HOME) {
                cursorPosition_ = 0;
            }
            else if (event.key == KEY_END) {
                cursorPosition_ = text_.length();
            }
            else if (event.charCode > 0 && text_.length() < maxLength_) {
                // 插入字符
                text_.insert(cursorPosition_, 1, static_cast<char>(event.charCode));
                cursorPosition_++;
            }
            
            return true;
        }
        
        return false;
    }
    
    // 设置文本框属性
    void setPassword(bool isPassword) { isPassword_ = isPassword; }
    void setMaxLength(int maxLength) { maxLength_ = maxLength; }
    void setColors(Color bg, Color text, Color placeholder, Color focusedBorder) {
        backgroundColor_ = bg;
        textColor_ = text;
        placeholderColor_ = placeholder;
        focusedBorderColor_ = focusedBorder;
    }
    
    // 获取和设置文本
    const std::string& getText() const { return text_; }
    void setText(const std::string& text) { 
        text_ = text; 
        cursorPosition_ = text_.length();
    }
    
    bool isFocused() const { return isFocused_; }
    
private:
    void calculateCursorPosition(float mouseX) {
        std::string displayText = isPassword_ ? std::string(text_.length(), '*') : text_;
        
        // 简单实现：找到最接近鼠标位置的字符位置
        float textX = x_ + 5;
        cursorPosition_ = 0;
        
        for (int i = 0; i <= displayText.length(); i++) {
            float charX = textX + measureText(displayText.substr(0, i).c_str(), 20);
            if (charX > mouseX) {
                break;
            }
            cursorPosition_ = i;
        }
    }
};
```

```cpp
class Panel : public UIComponent {
private:
    std::vector<std::unique_ptr<UIComponent>> children_;
    Color backgroundColor_;
    bool clipChildren_;
    
public:
    Panel(float x, float y, float width, float height, const std::string& id = "")
        : UIComponent(x, y, width, height, id.empty() ? "panel_" + std::to_string(rand()) : id),
          backgroundColor_(BLANK), clipChildren_(false) {}
    
    void render() const override {
        if (!visible_) return;
        
        // 绘制面板背景
        if (backgroundColor_.a > 0) {
            drawRectangle(x_, y_, width_, height_, backgroundColor_);
        }
        
        // 绘制子控件
        for (const auto& child : children_) {
            if (child->isVisible()) {
                if (clipChildren_) {
                    // 设置裁剪区域
                    beginScissorMode(x_, y_, width_, height_);
                    child->render();
                    endScissorMode();
                } else {
                    child->render();
                }
            }
        }
    }
    
    void update(float deltaTime) override {
        if (!visible_ || !enabled_) return;
        
        // 更新所有子控件
        for (auto& child : children_) {
            child->update(deltaTime);
        }
    }
    
    bool handleEvent(const Event& event) override {
        if (!visible_ || !enabled_) return false;
        
        // 从上到下处理事件（后添加的控件在上层）
        for (auto it = children_.rbegin(); it != children_.rend(); ++it) {
            if ((*it)->handleEvent(event)) {
                return true;  // 事件被处理，停止传播
            }
        }
        
        return false;
    }
    
    // 添加子控件
    void addChild(std::unique_ptr<UIComponent> child) {
        if (child) {
            children_.push_back(std::move(child));
        }
    }
    
    // 获取子控件
    UIComponent* getChild(const std::string& id) const {
        for (const auto& child : children_) {
            if (child->getId() == id) {
                return child.get();
            }
        }
        return nullptr;
    }
    
    // 移除子控件
    void removeChild(const std::string& id) {
        children_.erase(
            std::remove_if(children_.begin(), children_.end(),
                [&id](const std::unique_ptr<UIComponent>& child) {
                    return child->getId() == id;
                }),
            children_.end());
    }
    
    // 设置面板属性
    void setBackgroundColor(Color color) { backgroundColor_ = color; }
    void setClipChildren(bool clip) { clipChildren_ = clip; }
};
```

```cpp
class UIManager {
private:
    std::vector<std::unique_ptr<UIComponent>> uiComponents_;
    UIComponent* focusedComponent_;
    
public:
    UIManager() : focusedComponent_(nullptr) {}
    
    void render() const {
        // 渲染所有UI组件
        for (const auto& component : uiComponents_) {
            if (component->isVisible()) {
                component->render();
            }
        }
    }
    
    void update(float deltaTime) {
        // 更新所有UI组件
        for (auto& component : uiComponents_) {
            component->update(deltaTime);
        }
    }
    
    bool handleEvent(const Event& event) {
        // 处理事件
        for (auto it = uiComponents_.rbegin(); it != uiComponents_.rend(); ++it) {
            if ((*it)->handleEvent(event)) {
                // 如果是焦点相关事件，更新焦点组件
                if (event.type == EventType::MOUSE_BUTTON_DOWN || 
                    event.type == EventType::KEY_INPUT) {
                    focusedComponent_ = it->get();
                }
                return true;  // 事件被处理，停止传播
            }
        }
        
        return false;
    }
    
    // 添加UI组件
    void addComponent(std::unique_ptr<UIComponent> component) {
        if (component) {
            uiComponents_.push_back(std::move(component));
        }
    }
    
    // 获取UI组件
    UIComponent* getComponent(const std::string& id) const {
        for (const auto& component : uiComponents_) {
            if (component->getId() == id) {
                return component.get();
            }
        }
        return nullptr;
    }
    
    // 移除UI组件

        uiComponents_.erase(
            std::remove_if(uiComponents_.begin(), uiComponents_.end(),
                [&id](const std::unique_ptr<UIComponent>& component) {
                    return component->getId() == id;
                }),
            uiComponents_.end());
    }
    
    // 清空所有UI组件
    void clear() {
        uiComponents_.clear();

    }
```

```cpp
class CSVProcessor : public DataProcessor {
private:
    char delimiter_;
    bool hasHeader_;
    
public:
    CSVProcessor(char delimiter = ',', bool hasHeader = true)
        : delimiter_(delimiter), hasHeader_(hasHeader) {}
    
    bool loadData(const std::string& source) override {
        std::ifstream file(source);
        if (!file.is_open()) {
            std::cerr << "Error: Could not open file " << source << std::endl;
            return false;
        }
        
        rawData_.clear();
        std::string line;
        
        // 读取所有行
        while (std::getline(file, line)) {
            rawData_.push_back(line);
        }
        
        file.close();
        
        // 如果有标题行，则跳过第一行
        if (hasHeader_ && !rawData_.empty()) {
            header_ = rawData_[0];
            rawData_.erase(rawData_.begin());
        }
        
        std::cout << "Loaded " << rawData_.size() << " rows from CSV file" << std::endl;
        return true;
    }
    
    void processData() override {
        processedData_.clear();
        
        for (const auto& row : rawData_) {
            std::vector<std::string> fields = parseCSVLine(row);
            
            // 示例处理：计算每行的数值字段总和
            double sum = 0.0;
            int count = 0;
            
            for (const auto& field : fields) {
                try {
                    double value = std::stod(field);
                    sum += value;
                    count++;
                } catch (const std::exception&) {
                    // 忽略非数值字段
                }
            }
            
            // 创建处理后的行
            std::string processedRow = row;
            if (count > 0) {
                processedRow += delimiter_ + std::to_string(sum / count);  // 添加平均值
            }
            
            processedData_.push_back(processedRow);
        }
        
        std::cout << "Processed " << processedData_.size() << " rows" << std::endl;
    }
    
    bool saveData(const std::string& destination) override {
        std::ofstream file(destination);
        if (!file.is_open()) {
            std::cerr << "Error: Could not create file " << destination << std::endl;
            return false;
        }
        
        // 写入标题行（如果有）
        if (hasHeader_ && !header_.empty()) {
            file << header_ << delimiter_ << "Average" << std::endl;
        }
        
        // 写入处理后的数据
        for (const auto& row : processedData_) {
            file << row << std::endl;
        }
        
        file.close();
        std::cout << "Saved processed data to " << destination << std::endl;
        return true;
    }
    
    // CSV特有方法
    void setDelimiter(char delimiter) { delimiter_ = delimiter; }
    void setHasHeader(bool hasHeader) { hasHeader_ = hasHeader; }
    
private:
    std::string header_;
    
    std::vector<std::string> parseCSVLine(const std::string& line) {
        std::vector<std::string> fields;
        std::stringstream ss(line);
        std::string field;
        
        while (std::getline(ss, field, delimiter_)) {
            // 简单处理引号包围的字段
            if (!field.empty() && field.front() == '"' && field.back() == '"') {
                field = field.substr(1, field.length() - 2);
            }
            fields.push_back(field);
        }
        
        return fields;
    }
};
```

```cpp
class JSONProcessor : public DataProcessor {
private:
    bool prettyPrint_;
    
public:
    JSONProcessor(bool prettyPrint = true) : prettyPrint_(prettyPrint) {}
    
    bool loadData(const std::string& source) override {
        std::ifstream file(source);
        if (!file.is_open()) {
            std::cerr << "Error: Could not open file " << source << std::endl;
            return false;
        }
        
        try {
            // 使用JSON库解析文件
            nlohmann::json jsonData;
            file >> jsonData;
            file.close();
            
            // 将JSON数据转换为字符串行
            rawData_.clear();
            
            if (jsonData.is_array()) {
                for (const auto& item : jsonData) {
                    rawData_.push_back(item.dump());
                }
            } else if (jsonData.is_object()) {
                rawData_.push_back(jsonData.dump());
            } else {
                rawData_.push_back(jsonData.dump());
            }
            
            std::cout << "Loaded JSON data from " << source << std::endl;
            return true;
        } catch (const std::exception& e) {
            std::cerr << "Error parsing JSON: " << e.what() << std::endl;
            return false;
        }
    }
    
    void processData() override {
        processedData_.clear();
        
        for (const auto& line : rawData_) {
            try {
                // 解析JSON
                nlohmann::json item = nlohmann::json::parse(line);
                
                // 示例处理：添加处理时间戳
                item["processed_at"] = getCurrentTimestamp();
                
                // 示例处理：计算某些字段的统计信息
                if (item.contains("values") && item["values"].is_array()) {
                    double sum = 0.0;
                    int count = 0;
                    
                    for (const auto& value : item["values"]) {
                        if (value.is_number()) {
                            sum += value.get<double>();
                            count++;
                        }
                    }
                    
                    if (count > 0) {
                        item["average"] = sum / count;
                        item["count"] = count;
                    }
                }
                
                // 转换回字符串
                std::string processedLine = prettyPrint_ ? item.dump(4) : item.dump();
                processedData_.push_back(processedLine);
            } catch (const std::exception& e) {
                std::cerr << "Error processing JSON line: " << e.what() << std::endl;
                // 如果处理失败，保留原始数据
                processedData_.push_back(line);
            }
        }
        
        std::cout << "Processed " << processedData_.size() << " JSON objects" << std::endl;
    }
    
    bool saveData(const std::string& destination) override {
        std::ofstream file(destination);
        if (!file.is_open()) {
            std::cerr << "Error: Could not create file " << destination << std::endl;
            return false;
        }
        
        try {
            // 将所有处理后的JSON对象合并为一个数组
            nlohmann::json result = nlohmann::json::array();
            
            for (const auto& line : processedData_) {
                nlohmann::json item = nlohmann::json::parse(line);
                result.push_back(item);
            }
            
            // 写入文件
            file << result.dump(prettyPrint_ ? 4 : 0);
            file.close();
            
            std::cout << "Saved processed JSON data to " << destination << std::endl;
            return true;
        } catch (const std::exception& e) {
            std::cerr << "Error saving JSON data: " << e.what() << std::endl;
            return false;
        }
    }
    
    // JSON特有方法
    void setPrettyPrint(bool prettyPrint) { prettyPrint_ = prettyPrint; }
    
private:
    std::string getCurrentTimestamp() {
        auto now = std::chrono::system_clock::now();
        auto time_t = std::chrono::system_clock::to_time_t(now);
        std::stringstream ss;
        ss << std::put_time(std::localtime(&time_t), "%Y-%m-%d %H:%M:%S");
        return ss.str();
    }
};
```

```cpp
            return createProcessor(ProcessorType::CSV);
        } else if (extension == "json") {
            return createProcessor(ProcessorType::JSON);
        } else if (extension == "xml") {
            return createProcessor(ProcessorType::XML);
        }
```

**数据处理管道**：

```cpp
class DataProcessingPipeline {
private:
    std::vector<std::unique_ptr<DataProcessor>> processors_;
    std::vector<std::string> intermediateFiles_;
    
public:
    // 添加处理器
    void addProcessor(std::unique_ptr<DataProcessor> processor) {
        if (processor) {
            processors_.push_back(std::move(processor));
        }
    }
    
    // 执行数据处理管道
    bool execute(const std::string& inputFile, const std::string& outputFile) {
        if (processors_.empty()) {
            std::cerr << "Error: No processors in pipeline" << std::endl;
            return false;
        }
        
        std::string currentInput = inputFile;
        
        // 执行每个处理器
        for (size_t i = 0; i < processors_.size(); i++) {
            auto& processor = processors_[i];
            
            // 加载数据
            if (!processor->loadData(currentInput)) {
                std::cerr << "Error: Failed to load data in processor " << i << std::endl;
                return false;
            }
            
            // 处理数据
            processor->processData();
            
            // 确定输出文件
            std::string currentOutput;
            if (i == processors_.size() - 1) {
                // 最后一个处理器，输出到最终文件
                currentOutput = outputFile;
            } else {
                // 中间处理器，输出到临时文件
                currentOutput = "temp_" + std::to_string(i) + ".dat";
                intermediateFiles_.push_back(currentOutput);
            }
            
            // 保存数据
            if (!processor->saveData(currentOutput)) {
                std::cerr << "Error: Failed to save data in processor " << i << std::endl;
                return false;
            }
            
            // 下一个处理器的输入是当前处理器的输出
            currentInput = currentOutput;
        }
        
        // 清理临时文件
        cleanupTempFiles();
        
        std::cout << "Pipeline execution completed successfully" << std::endl;
        return true;
    }
    
    // 获取处理器数量
    size_t getProcessorCount() const { return processors_.size(); }
    
private:
    void cleanupTempFiles() {
        for (const auto& file : intermediateFiles_) {
            std::remove(file.c_str());
        }
        intermediateFiles_.clear();
    }
};
```

```cpp
class PluginManager {
private:
    std::map<std::string, std::unique_ptr<Plugin>> plugins_;
    std::vector<void*> loadedLibraries_;
    
public:
    ~PluginManager() {
        // 卸载所有插件
        shutdownAllPlugins();
        
        // 卸载所有动态库
        for (void* lib : loadedLibraries_) {
            unloadLibrary(lib);
        }
    }
    
    // 从动态库加载插件
    bool loadPlugin(const std::string& libraryPath) {
        // 加载动态库
        void* lib = loadLibrary(libraryPath.c_str());
        if (!lib) {
            std::cerr << "Error: Failed to load library " << libraryPath << std::endl;
            return false;
        }
        
        // 获取创建插件的函数
        typedef Plugin* (*CreatePluginFunc)();
        CreatePluginFunc createPlugin = (CreatePluginFunc)getLibrarySymbol(lib, "createPlugin");
        
        if (!createPlugin) {
            std::cerr << "Error: Library does not export createPlugin function" << std::endl;
            unloadLibrary(lib);
            return false;
        }
        
        // 创建插件实例
        Plugin* plugin = createPlugin();
        if (!plugin) {
            std::cerr << "Error: Failed to create plugin instance" << std::endl;
            unloadLibrary(lib);
            return false;
        }
        
        // 初始化插件
        if (!plugin->initialize()) {
            std::cerr << "Error: Failed to initialize plugin" << std::endl;
            delete plugin;
            unloadLibrary(lib);
            return false;
        }
        
        // 添加到插件列表
        std::string pluginName = plugin->getName();
        plugins_[pluginName] = std::unique_ptr<Plugin>(plugin);
        loadedLibraries_.push_back(lib);
        
        std::cout << "Loaded plugin: " << pluginName << " v" << plugin->getVersion() << std::endl;
        return true;
    }
    
    // 卸载插件
    bool unloadPlugin(const std::string& pluginName) {
        auto it = plugins_.find(pluginName);
        if (it == plugins_.end()) {
            return false;
        }
        
        // 关闭插件
        it->second->shutdown();
        plugins_.erase(it);
        
        std::cout << "Unloaded plugin: " << pluginName << std::endl;
        return true;
    }
    
    // 获取插件
    Plugin* getPlugin(const std::string& pluginName) const {
        auto it = plugins_.find(pluginName);
        return (it != plugins_.end()) ? it->second.get() : nullptr;
    }
    
    // 获取所有插件名称
    std::vector<std::string> getPluginNames() const {
        std::vector<std::string> names;
        for (const auto& pair : plugins_) {
            names.push_back(pair.first);
        }
        return names;
    }
    
    // 关闭所有插件
    void shutdownAllPlugins() {
        for (auto& pair : plugins_) {
            pair.second->shutdown();
        }
        plugins_.clear();
    }
    
private:
    // 平台相关的动态库加载函数
    void* loadLibrary(const char* path) {
#ifdef _WIN32
        return LoadLibraryA(path);
#else
        return dlopen(path, RTLD_LAZY);
#endif
    }
    
    void unloadLibrary(void* lib) {
#ifdef _WIN32
        FreeLibrary(static_cast<HMODULE>(lib));
#else
        dlclose(lib);
#endif
    }
    
    void* getLibrarySymbol(void* lib, const char* name) {
#ifdef _WIN32
        return GetProcAddress(static_cast<HMODULE>(lib), name);
#else
        return dlsym(lib, name);
#endif
    }
};
```

### 5.5 继承与多态的性能考虑

虽然继承和多态提供了强大的抽象能力，但在性能敏感的场景中，需要考虑它们的开销。

**虚函数调用的开销**：

```cpp
// 测试虚函数调用的性能
class Base {
public:
    virtual void virtualFunction() {
        // 虚函数实现
    }
    
    void nonVirtualFunction() {
        // 非虚函数实现
    }
};

class Derived : public Base {
public:
    void virtualFunction() override {
        // 派生类虚函数实现
    }
};

void performanceTest() {
    const int iterations = 100000000;
    Base* obj = new Derived();
    
    // 测试虚函数调用
    auto start = std::chrono::high_resolution_clock::now();
    for (int i = 0; i < iterations; i++) {
        obj->virtualFunction();
    }
    auto end = std::chrono::high_resolution_clock::now();
    auto virtualDuration = std::chrono::duration_cast<std::chrono::microseconds>(end - start);
    
    // 测试非虚函数调用
    start = std::chrono::high_resolution_clock::now();
    for (int i = 0; i < iterations; i++) {
        obj->nonVirtualFunction();
    }
    end = std::chrono::high_resolution_clock::now();
    auto nonVirtualDuration = std::chrono::duration_cast<std::chrono::microseconds>(end - start);
    
    std::cout << "Virtual function call time: " << virtualDuration.count() << " μs" << std::endl;
    std::cout << "Non-virtual function call time: " << nonVirtualDuration.count() << " μs" << std::endl;
    std::cout << "Overhead ratio: " << (double)virtualDuration.count() / nonVirtualDuration.count() << std::endl;
    
    delete obj;
}
```

**优化策略**：

1. **使用final关键字**：允许编译器去虚拟化优化
2. **减少虚函数调用深度**：避免过深的继承层次
3. **使用CRTP**：在性能关键的场景中使用静态多态
4. **批量处理**：减少虚函数调用次数

继承和多态是C++中强大的面向对象编程机制，它们在许多实际应用场景中发挥着重要作用：

1. **游戏开发**：用于创建各种游戏实体，实现统一的行为处理
2. **GUI系统**：用于创建各种UI控件，实现统一的事件处理
3. **数据处理**：用于处理不同类型的数据源和数据格式
4. **插件系统**：用于实现可扩展的应用程序架构

在使用继承和多态时，需要注意以下几点：

1. **设计良好的接口**：确保基类接口清晰、一致
2. **避免过度继承**：优先使用组合而非继承
3. **考虑性能影响**：在性能敏感的场景中，考虑使用静态多态或其他优化技术
4. **遵循SOLID原则**：特别是单一职责原则和开闭原则

通过合理应用继承和多态，可以创建出灵活、可维护、可扩展的软件系统。

## 6. 现代C++中继承与多态的新特性和最佳实践

现代C++（C++11及以后版本）引入了许多新特性，这些特性极大地增强了继承和多态的表达能力和安全性。本节将介绍这些新特性以及使用继承和多态的最佳实践。

### 6.1 override和final关键字

**override关键字**：

`override`关键字（C++11引入）用于明确标记一个函数是重写基类的虚函数。这不仅可以提高代码的可读性，还能让编译器在函数签名不匹配时提供错误提示。

```cpp
class Base {
public:
    virtual void func(int x) const { /* ... */ }
    virtual void process() { /* ... */ }
};

class Derived : public Base {
public:
    // 正确使用override
    void func(int x) const override { /* ... */ }
    
    // 错误：函数签名不匹配，编译器会报错
    // void func(double x) const override { /* ... */ }  // 编译错误
    
    // 错误：基类中没有对应的虚函数
    // void newFunc() override { /* ... */ }  // 编译错误
};
```

**final关键字**：

`final`关键字（C++11引入）有两种用途：标记虚函数不能被进一步重写，或者标记类不能被继承。

```cpp
class Base {
public:
    // 这个虚函数不能被派生类重写
    virtual void essential() final { /* ... */ }
    
    virtual void normal() { /* ... */ }
};

class Derived : public Base {
public:
    // 错误：不能重写final函数
    // void essential() override { /* ... */ }  // 编译错误
    
    void normal() override { /* ... */ }
};

// 这个类不能被继承
class FinalClass final {
    // ...
};

// 错误：不能继承final类
// class DerivedFromFinal : public FinalClass { /* ... */ }  // 编译错误
```

### 6.2 继承构造函数（Inheriting Constructors）

C++11引入了继承构造函数的特性，允许派生类直接使用基类的构造函数，而不需要重新定义。

```cpp
class Base {
public:
    Base(int x) : value(x) {}
    Base(double x, double y) : value(x + y) {}
    Base(const std::string& s) : value(std::stoi(s)) {}
    
private:
    int value;
};

class Derived : public Base {
public:
    // 继承Base的所有构造函数
    using Base::Base;
    
    // 可以添加自己的构造函数
    Derived(int x, int y) : Base(x), extra(y) {}
    
private:
    int extra = 0;
};

// 使用示例
Derived d1(42);           // 调用Base(int)
Derived d2(3.14, 2.71);   // 调用Base(double, double)
Derived d3("123");        // 调用Base(const std::string&)
Derived d4(10, 20);       // 调用Derived自己的构造函数
```

### 6.3 委托构造函数（Delegating Constructors）

C++11允许一个构造函数调用同一个类的其他构造函数，这被称为委托构造函数。这个特性可以减少代码重复，提高维护性。

```cpp
class Point {
public:
    // 主构造函数
    Point(double x, double y) : x_(x), y_(y) {
        // 通用初始化代码
        std::cout << "Point(" << x_ << ", " << y_ << ")" << std::endl;
    }
    
    // 委托给主构造函数
    Point() : Point(0.0, 0.0) {}
    
    // 委托给主构造函数
    Point(double x) : Point(x, 0.0) {}
    
    // 委托给主构造函数
    Point(const std::pair<double, double>& p) : Point(p.first, p.second) {}
    
private:
    double x_, y_;
};
```

### 6.4 nullptr和类型安全的空指针

C++11引入了`nullptr`关键字，作为类型安全的空指针常量，替代了传统的`NULL`宏。这在处理多态和继承时特别有用。

```cpp
class Base {
public:
    virtual void func() { std::cout << "Base::func()" << std::endl; }
    virtual ~Base() = default;
};

class Derived : public Base {
public:
    void func() override { std::cout << "Derived::func()" << std::endl; }
};

void process(Base* ptr) {
    if (ptr != nullptr) {  // 使用nullptr而不是NULL
        ptr->func();
    } else {
        std::cout << "Null pointer provided" << std::endl;
    }
}

// 使用示例
Base* b1 = new Base();
Base* b2 = new Derived();
Base* b3 = nullptr;  // 使用nullptr而不是NULL

process(b1);  // 输出: Base::func()
process(b2);  // 输出: Derived::func()
process(b3);  // 输出: Null pointer provided
```

### 6.5 智能指针与多态

现代C++推荐使用智能指针来管理动态分配的对象，特别是在涉及多态的情况下。智能指针可以自动管理内存，避免内存泄漏。

**unique_ptr与多态**：

```cpp
#include <memory>
#include <vector>

class Shape {
public:
    virtual ~Shape() = default;
    virtual void draw() const = 0;
};

class Circle : public Shape {
public:
    void draw() const override { std::cout << "Drawing a circle" << std::endl; }
};

class Rectangle : public Shape {
public:
    void draw() const override { std::cout << "Drawing a rectangle" << std::endl; }
};

void drawShapes() {
    // 使用unique_ptr管理多态对象
    std::vector<std::unique_ptr<Shape>> shapes;
    
    // 添加形状
    shapes.push_back(std::make_unique<Circle>());
    shapes.push_back(std::make_unique<Rectangle>());
    
    // 绘制所有形状
    for (const auto& shape : shapes) {
        shape->draw();
    }
    
    // 不需要手动删除，unique_ptr会自动清理
}
```

**shared_ptr与多态**：

```cpp
#include <memory>
#include <iostream>

class Animal {
public:
    virtual ~Animal() = default;
    virtual void makeSound() const = 0;
};

class Dog : public Animal {
public:
    void makeSound() const override { std::cout << "Woof!" << std::endl; }
};

class Cat : public Animal {
public:
    void makeSound() const override { std::cout << "Meow!" << std::endl; }
};

// 使用shared_ptr共享动物的所有权
void demonstrateSharedOwnership() {
    std::shared_ptr<Animal> dog = std::make_shared<Dog>();
    std::shared_ptr<Animal> cat = std::make_shared<Cat>();
    
    // 创建额外的引用
    std::shared_ptr<Animal> anotherDog = dog;
    std::shared_ptr<Animal> anotherCat = cat;
    
    std::cout << "Dog use count: " << dog.use_count() << std::endl;  // 输出: 2
    std::cout << "Cat use count: " << cat.use_count() << std::endl;  // 输出: 2
    
    dog->makeSound();  // 输出: Woof!
    cat->makeSound();  // 输出: Meow!
}
```

### 6.6 移动语义与继承

C++11引入的移动语义在继承和多态场景中也非常有用，特别是对于资源管理的类。

```cpp
class Resource {
public:
    Resource() { std::cout << "Resource acquired" << std::endl; }
    ~Resource() { std::cout << "Resource released" << std::endl; }
    
    // 禁止拷贝
    Resource(const Resource&) = delete;
    Resource& operator=(const Resource&) = delete;
    
    // 允许移动
    Resource(Resource&&) noexcept { std::cout << "Resource moved" << std::endl; }
    Resource& operator=(Resource&&) noexcept {
        std::cout << "Resource move-assigned" << std::endl;
        return *this;
    }
};

class Base {
public:
    Base() : resource_(std::make_unique<Resource>()) {}
    
    // 虚析构函数
    virtual ~Base() = default;
    
    // 虚函数
    virtual void process() { std::cout << "Base processing" << std::endl; }
    
    // 移动构造函数
    Base(Base&&) noexcept = default;
    Base& operator=(Base&&) noexcept = default;
    
    // 禁止拷贝
    Base(const Base&) = delete;
    Base& operator=(const Base&) = delete;
    
protected:
    std::unique_ptr<Resource> resource_;
};

class Derived : public Base {
public:
    Derived() : Base() {}
    
    void process() override { std::cout << "Derived processing" << std::endl; }
    
    // 移动构造函数
    Derived(Derived&&) noexcept = default;
    Derived& operator=(Derived&&) noexcept = default;
    
    // 禁止拷贝
    Derived(const Derived&) = delete;
    Derived& operator=(const Derived&) = delete;
};

// 使用示例
void demonstrateMoveSemantics() {
    Derived d1;
    d1.process();  // 输出: Derived processing
    
    // 移动构造
    Derived d2 = std::move(d1);
    d2.process();  // 输出: Derived processing
    
    // 移动赋值
    Derived d3;
    d3 = std::move(d2);
    d3.process();  // 输出: Derived processing
}
```

### 6.7 协变返回类型（Covariant Return Types）

协变返回类型允许派生类重写基类虚函数时返回更具体的类型。这个特性在C++早期就存在，但在现代C++中与智能指针结合使用时特别有用。

```cpp
class Base {
public:
    virtual ~Base() = default;
    virtual Base* clone() const = 0;  // 返回Base*
};

class Derived : public Base {
public:
    // 协变返回类型：返回Derived*而不是Base*
    Derived* clone() const override {
        return new Derived(*this);
    }
};

// 与智能指针结合使用
class ModernBase {
public:
    virtual ~ModernBase() = default;
    virtual std::unique_ptr<ModernBase> clone() const = 0;
};

class ModernDerived : public ModernBase {
public:
    // 协变返回类型：返回unique_ptr<ModernDerived>
    std::unique_ptr<ModernDerived> clone() const override {
        return std::make_unique<ModernDerived>(*this);
    }
};
```

### 6.8 现代C++中的最佳实践

**使用智能指针管理多态对象**：

```cpp
// 不推荐：使用裸指针和手动内存管理
Base* createObject() {
    return new Derived();  // 谁来delete？
}

// 推荐：使用智能指针自动管理内存
std::unique_ptr<Base> createObject() {
    return std::make_unique<Derived>();  // 自动管理内存
}
```

**使用override和final关键字**：

```cpp
class Base {
public:
    virtual void func() = 0;
};

class Derived : public Base {
public:
    // 推荐：明确标记override
    void func() override { /* ... */ }
};
```

**优先使用组合而非继承**：

```cpp
// 不推荐：过度使用继承
class TextEditor : public Window, public FileManager, public Printer { /* ... */ };

// 推荐：使用组合
class TextEditor {
private:
    Window window_;
    FileManager fileManager_;
    Printer printer_;
public:
    // 通过组合对象提供功能
};
```

**使用接口分离原则**：

```cpp
// 不推荐：大而全的接口
class MultimediaDevice {
public:
    virtual void playAudio() = 0;
    virtual void playVideo() = 0;
    virtual void takePhoto() = 0;
    virtual void recordVideo() = 0;
};

// 推荐：分离的接口
class AudioPlayer {
public:
    virtual void playAudio() = 0;
};

class VideoPlayer {
public:
    virtual void playVideo() = 0;
};

class Camera {
public:
    virtual void takePhoto() = 0;
    virtual void recordVideo() = 0;
};

// 设备可以实现需要的接口
class Smartphone : public AudioPlayer, public VideoPlayer, public Camera { /* ... */ };
class MP3Player : public AudioPlayer { /* ... */ };
```

**使用CRTP实现静态多态**：

```cpp
template <typename Derived>
class BaseCRTP {
public:
    void interface() {
        static_cast<Derived*>(this)->implementation();
    }
};

class DerivedCRTP : public BaseCRTP<DerivedCRTP> {
public:
    void implementation() {
        std::cout << "DerivedCRTP implementation" << std::endl;
    }
};
```

**使用constexpr和if constexpr进行编译时多态**：

```cpp
template <typename T>
constexpr bool isPolymorphic = std::is_polymorphic_v<T>;

template <typename T>
void process(T& obj) {
    if constexpr (isPolymorphic<T>) {
        // 运行时多态处理
        std::cout << "Processing polymorphic object" << std::endl;
    } else {
        // 非多态处理
        std::cout << "Processing non-polymorphic object" << std::endl;
    }
}
```

### 6.9 性能优化建议

**虚函数调用优化**：

1. **减少虚函数调用深度**：避免过深的继承层次
2. **使用final关键字**：允许编译器去虚拟化优化
3. **考虑CRTP**：在性能关键的场景中使用静态多态

**内存布局优化**：

1. **保持虚函数表紧凑**：将相关虚函数放在一起
2. **避免虚继承过度使用**：虚继承会增加额外开销
3. **考虑对象池**：对于频繁创建销毁的多态对象

**缓存友好设计**：

1. **数据局部性**：将相关数据放在一起
2. **避免虚函数指针间接访问**：在性能关键代码中考虑
3. **使用SOA（Structure of Arrays）**：对于大量同类型对象

通过合理应用这些现代C++特性和最佳实践，可以编写出更安全、更高效、更易维护的继承和多态代码。
