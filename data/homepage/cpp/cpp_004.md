# C++函数、数组与字符串基础概念

## 1. 函数的基本概念

函数是C++程序的基本构建模块，它是一段执行特定任务的代码块。通过函数，我们可以将复杂的问题分解为更小、更易管理的部分，提高代码的可读性、可维护性和重用性。

### 1.1 函数的定义与声明

**函数的定义与声明**

在C++中，函数使用前需要先声明，定义可以在声明之后的其他位置。函数声明（也称为函数原型）告诉编译器函数的存在，包括函数名、返回类型和参数列表，而不提供函数体的实现。

函数定义则包含函数体的具体实现，是函数功能的实际代码。

函数的基本组成部分包括：
- **返回类型**：指定函数返回值的数据类型，可以是基本类型、自定义类型或void（表示无返回值）
- **函数名**：标识函数的名称，遵循C++命名规则
- **参数列表**：函数接收的输入，包含参数类型和参数名
- **函数体**：包含执行特定任务的代码块

```cpp
#include <iostream>

// 函数声明（原型）
// 声明告诉编译器函数的存在，包括返回类型、函数名和参数列表
// 这是一种"承诺"，告诉编译器这些函数将在后面定义
int add(int a, int b);  // 返回两个整数的和，参数a和b是形式参数（形参）
void printMessage(const std::string& message);  // 打印消息，无返回值，使用const引用避免字符串复制
double calculateArea(double radius);  // 计算圆的面积，参数是圆的半径

// 函数定义
// 提供函数的实际实现，包含执行特定任务的代码块
int add(int a, int b) {
    // 函数体：执行加法运算并返回结果
    // return语句将结果返回给调用者，并结束函数执行
    return a + b;  // 返回a和b的和
}

void printMessage(const std::string& message) {
    // 函数体：使用iostream库输出消息到控制台
    // std::cout是标准输出流对象，<<是输出运算符
    // std::endl是换行符，并刷新输出缓冲区
    std::cout << "消息: " << message << std::endl;
    // void函数不需要return语句，函数执行完毕后自动返回
}

double calculateArea(double radius) {
    // 函数体：使用圆的面积公式 πr² 计算面积
    // const定义常量PI，避免魔法数字（magic number）
    const double PI = 3.14159;  // 圆周率常量
    return PI * radius * radius;  // 返回计算出的圆面积
}

int main() {
    // 函数调用：使用函数名和实际参数（实参）来执行函数
    // 实参是传递给函数的实际值，与形参一一对应
    
    int result = add(5, 3);  // 实参5和3传递给函数add，返回值存储在result变量中
    std::cout << "5 + 3 = " << result << std::endl;  // 输出计算结果
    
    printMessage("Hello, C++!");  // 字符串字面量作为实参传递给printMessage函数
    // 注意：字符串字面量会自动转换为std::string类型
    
    double area = calculateArea(5.0);  // 5.0作为半径参数传递给calculateArea函数
    // 整数5.0是double类型的字面量，确保类型匹配
    std::cout << "半径为5的圆面积: " << area << std::endl;  // 输出计算结果
    
    return 0;  // main函数返回0表示程序正常结束，非0值通常表示错误
}
```

**函数重载示例**

函数重载是C++的一个重要特性，它允许在同一作用域内定义多个同名函数，但这些函数的参数列表必须不同（参数类型、参数个数或参数顺序不同）。编译器会根据调用时提供的实参类型和数量来选择最合适的函数版本。

重载解析是编译器确定调用哪个重载函数的过程，遵循以下规则：
1. **精确匹配**：实参类型与形参类型完全匹配
2. **类型提升**：如char到int，float到double等标准类型提升
3. **标准转换**：如int到double，派生类到基类等
4. **用户自定义转换**：通过构造函数或类型转换运算符实现的转换
5. **省略号匹配**：使用省略号(...)的函数作为最后选择

重载函数不能仅通过返回类型区分，因为调用函数时可能不使用返回值，会导致编译器无法确定调用哪个版本。

```cpp
#include <iostream>
#include <string>

// 重载函数 - 不同参数类型
// 编译器根据参数类型选择合适的函数版本
// 函数重载允许在同一作用域内定义多个同名函数，但参数列表必须不同

void print(int value) {
    // 当参数是int类型时调用此版本
    std::cout << "整数: " << value << std::endl;
}

void print(double value) {
    // 当参数是double类型时调用此版本
    // 注意：float参数会优先匹配此版本（通过类型提升）
    std::cout << "浮点数: " << value << std::endl;
}

void print(const std::string& value) {
    // 当参数是std::string类型时调用此版本
    // 使用const引用避免不必要的字符串复制
    std::cout << "字符串: " << value << std::endl;
}

// 重载函数 - 不同参数个数
// 编译器根据参数数量选择合适的函数版本
// 这种重载方式可以提供默认参数的替代方案

int max(int a, int b) {
    // 返回两个整数中的较大值
    // 使用三元运算符(?:)进行条件判断，简洁高效
    return (a > b) ? a : b;  // 如果a>b则返回a，否则返回b
}

int max(int a, int b, int c) {
    // 返回三个整数中的最大值
    // 通过调用两个参数的max函数实现代码重用，避免重复逻辑
    // 先比较a和b的最大值，再与c比较
    return max(max(a, b), c);  // 嵌套调用：先计算max(a,b)，再将其结果与c比较
}

// 重载函数 - 参数顺序不同
// 当参数类型相同但顺序不同时，编译器也能区分不同的重载版本
// 这种重载方式在处理有顺序要求的数据时特别有用

void display(int a, double b) {
    // 第一个参数是int，第二个参数是double
    std::cout << "整数: " << a << ", 浮点数: " << b << std::endl;
}

void display(double a, int b) {
    // 第一个参数是double，第二个参数是int
    // 参数类型顺序与上一个函数不同，因此是有效的重载
    std::cout << "浮点数: " << a << ", 整数: " << b << std::endl;
}

int main() {
    // 编译器根据实参类型选择合适的print函数
    // 这个过程称为重载解析(overload resolution)
    print(42);        // 调用 print(int)，因为42是int类型
    print(3.14);      // 调用 print(double)，因为3.14是double类型
    print("Hello World"); // 调用 print(const std::string&)，字符串字面量转换为std::string
    
    // 编译器根据实参数量选择合适的max函数
    std::cout << "两个数的最大值: " << max(10, 20) << std::endl;    // 调用 max(int, int)，两个参数
    std::cout << "三个数的最大值: " << max(10, 20, 15) << std::endl; // 调用 max(int, int, int)，三个参数
    
    // 编译器根据实参类型和顺序选择合适的display函数
    display(5, 3.14);   // 调用 display(int, double)，第一个参数是int，第二个是double
    display(3.14, 5);   // 调用 display(double, int)，第一个参数是double，第二个是int
    
    // 模糊调用示例（会导致编译错误）
    // print(5.0f); // float可以转换为int或double，导致调用模糊
    // 编译器无法确定应该调用print(int)还是print(double)，因为两种转换都可行
    // 解决方法：显式转换，如print(static_cast<int>(5.0f))或print(static_cast<double>(5.0f))
    
    return 0;
}
```

### 1.2 参数传递的基本方式

C++提供了三种主要的参数传递方式：值传递、引用传递和指针传递。每种方式在内存使用、性能和安全性方面都有不同的特点和适用场景。

**值传递、引用传递和指针传递**

值传递是默认的参数传递方式，它创建参数的副本传递给函数。这种方式安全但可能效率低下，特别是对于大型对象。

引用传递通过引用（别名）传递参数，允许函数直接访问和修改原始数据。这种方式高效但需要谨慎使用，以避免意外的副作用。

指针传递通过传递变量的地址来访问和修改数据。它提供了灵活性，但需要处理指针的有效性检查和内存管理。

```cpp
#include <iostream>

// 值传递 - 传递副本，不影响原变量
// 值传递在栈上创建参数的副本，函数内部操作的是副本而非原始数据
// 这是最安全的传递方式，因为函数无法修改原始数据
void passByValue(int x) {
    x = 100;  // 只修改副本，不影响原始变量
    std::cout << "函数内 x = " << x << std::endl;
    // 函数结束时，副本x被销毁，原始变量保持不变
}

// 引用传递 - 传递别名，会影响原变量
// 引用传递不创建副本，函数直接操作原始数据
// 引用相当于变量的别名，对引用的操作就是对原始变量的操作
void passByReference(int& x) {
    x = 200;  // 直接修改原始变量
    std::cout << "函数内 x = " << x << std::endl;
    // 函数结束时，原始变量已被修改
}

// 指针传递 - 传递地址，可以修改原变量
// 指针传递传递变量的地址，通过解引用访问和修改原始数据
// 指针可以指向nullptr，因此需要有效性检查
void passByPointer(int* x) {
    if (x != nullptr) {  // 检查指针有效性，避免空指针解引用
        *x = 300;  // 通过指针解引用修改原变量
        std::cout << "函数内 *x = " << *x << std::endl;
        // *x表示指针x指向的值
    } else {
        std::cout << "错误：传入空指针" << std::endl;
    }
}

// 常量引用传递 - 高效且安全
// 常量引用结合了引用传递的效率和值传递的安全性
// const关键字确保函数不能修改原始数据，引用避免复制开销
void printValue(const int& x) {
    std::cout << "值为: " << x << std::endl;
    // x = 400;  // 编译错误：不能修改const引用，保证数据安全
    // 常量引用是只读的，任何修改尝试都会导致编译错误
}

// 大型对象的传递示例
struct LargeObject {
    int data[1000];  // 假设这是一个大型对象，包含1000个整数
    // 在实际应用中，可能包含更复杂的数据结构
};

// 值传递大型对象 - 效率低
void processByValue(LargeObject obj) {
    // 创建大型对象的副本，消耗大量内存和时间
    // 对于包含1000个整数的对象，需要复制4000字节（假设int为4字节）
    std::cout << "处理大型对象（值传递）" << std::endl;
    // 函数结束时，副本obj被销毁，调用析构函数（如果有）
}

// 引用传递大型对象 - 高效
void processByReference(LargeObject& obj) {
    // 不创建副本，直接操作原始对象
    // 只传递引用（通常是一个指针大小，如8字节），而不是整个对象
    std::cout << "处理大型对象（引用传递）" << std::endl;
    // 注意：函数可以修改原始对象，需要谨慎使用
}

// 常量引用传递大型对象 - 高效且安全
void processByConstReference(const LargeObject& obj) {
    // 不创建副本，且不能修改原始对象
    // 这是处理大型只读对象的推荐方式
    std::cout << "处理大型对象（常量引用传递）" << std::endl;
    // obj.data[0] = 42;  // 编译错误：不能修改const对象
}

int main() {
    int num = 10;  // 定义一个整型变量，初始值为10
    
    std::cout << "原始值: " << num << std::endl;
    
    // 值传递示例
    passByValue(num);  // 传递num的副本给函数
    std::cout << "值传递后: " << num << std::endl;  // 原始值未改变，仍为10
    
    // 引用传递示例
    passByReference(num);  // 传递num的引用给函数
    std::cout << "引用传递后: " << num << std::endl;  // 原始值被修改为200
    
    // 指针传递示例
    passByPointer(&num);  // 传递num的地址给函数
    std::cout << "指针传递后: " << num << std::endl;  // 原始值被修改为300
    
    // 常量引用传递示例
    printValue(num);  // 高效且安全地访问值，不修改原始数据
    // 此时num的值仍为300
    
    // 大型对象传递示例
    LargeObject largeObj;  // 创建一个大型对象
    processByValue(largeObj);        // 低效：创建副本，复制4000字节
    processByReference(largeObj);     // 高效：直接操作，只传递引用（8字节）
    processByConstReference(largeObj); // 高效且安全：只读访问，不创建副本
    
    // 指针传递与空指针示例
    passByPointer(nullptr);  // 传递空指针，函数会检查并处理
    
    return 0;
}
```

**参数传递的最佳实践**

1. **基本数据类型**：对于int、char、double等基本类型，通常使用值传递
2. **大型对象**：对于类、结构体等大型对象，使用常量引用传递（只读）或引用传递（需要修改）
3. **可选参数**：使用指针传递表示可选参数（可以传递nullptr）
4. **数组参数**：通常使用指针传递，因为数组名会退化为指针
5. **安全性考虑**：优先使用const引用，除非确实需要修改原始数据

**性能影响分析**

- 值传递：对于大型对象，复制操作可能消耗大量时间和内存
- 引用传递：只需要传递一个引用（通常是一个指针大小），效率高
- 指针传递：与引用传递类似，但需要额外的有效性检查
- 常量引用：结合了引用传递的效率和值传递的安全性

## 2. 数组的基本原理

数组是C++中最基本的数据结构之一，它是一组相同类型元素的连续集合。理解数组的内存组织和访问原理对于高效编程至关重要。

### 2.1 一维数组操作

一维数组是最简单的数组形式，它在内存中连续存储相同类型的元素。数组的访问通过下标实现，下标从0开始，最大值为数组大小减1。

数组与指针有着密切的关系：数组名在大多数表达式中会退化为指向其首元素的指针。这种关系使得数组和指针在许多情况下可以互换使用，但也带来了一些容易混淆的地方。

```cpp
#include <iostream>
#include <cstddef>  // 用于std::size_t

// 数组作为参数传递
// 注意：数组作为函数参数时会退化为指针，因此需要额外传递数组大小
// 这意味着函数内部无法直接获取数组的长度，必须通过参数显式传递
void printArray(int arr[], std::size_t size) {
    std::cout << "数组元素: ";
    for (std::size_t i = 0; i < size; i++) {
        std::cout << arr[i] << " ";  // 使用下标访问，等同于*(arr + i)
    }
    std::cout << std::endl;
}

// 使用指针遍历数组
// 这种写法与上面的函数完全等价，只是参数声明方式不同
// 两者都接收一个指向数组首元素的指针
void printArrayWithPointer(int* arr, std::size_t size) {
    std::cout << "使用指针遍历数组: ";
    for (std::size_t i = 0; i < size; i++) {
        std::cout << *(arr + i) << " ";  // 使用指针算术访问，等同于arr[i]
    }
    std::cout << std::endl;
}

// 查找数组中的最大值
// 函数返回数组中的最大元素值
// 使用std::size_t作为大小参数类型，这是C++中表示大小的推荐类型
int findMax(int arr[], std::size_t size) {
    if (size == 0) {
        throw std::invalid_argument("数组不能为空");  // 抛出异常比返回特殊值更安全
    }
    
    int max = arr[0];  // 假设第一个元素是最大值，作为比较基准
    for (std::size_t i = 1; i < size; i++) {
        if (arr[i] > max) {
            max = arr[i];  // 发现更大的值，更新max
        }
    }
    return max;  // 返回找到的最大值
}

// 数组排序（冒泡排序）
// 冒泡排序通过多次遍历数组，比较相邻元素并交换位置来排序
// 时间复杂度：O(n²)，空间复杂度：O(1)，适用于小规模数据
void bubbleSort(int arr[], std::size_t size) {
    for (std::size_t i = 0; i < size - 1; i++) {
        // 每次遍历后，最大的元素会"冒泡"到数组末尾
        // 内层循环范围逐渐缩小，因为末尾元素已经有序
        for (std::size_t j = 0; j < size - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                // 交换元素，使用临时变量进行交换
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}

// 演示数组与指针的关系
// 这个函数展示了数组名在表达式中的行为，以及指针算术的基本操作
void demonstrateArrayPointerRelation() {
    int numbers[] = {10, 20, 30, 40, 50};
    
    // 数组名与指针
    int* ptr = numbers;  // 数组名退化为指向首元素的指针
    // 注意：这里不是将整个数组复制给ptr，而是让ptr指向数组的首元素
    std::cout << "数组名与指针的关系:" << std::endl;
    std::cout << "numbers: " << numbers << std::endl;  // 输出数组首元素的地址
    std::cout << "ptr: " << ptr << std::endl;          // 输出指针的值（也是数组首元素的地址）
    std::cout << "&numbers[0]: " << &numbers[0] << std::endl;  // 显式获取首元素地址
    
    // 数组访问方式
    // 下标访问和指针访问在底层是等价的，编译器会将arr[i]转换为*(arr + i)
    std::cout << "\n不同的数组访问方式:" << std::endl;
    std::cout << "numbers[2]: " << numbers[2] << std::endl;           // 下标访问
    std::cout << "*(numbers + 2): " << *(numbers + 2) << std::endl;   // 指针算术访问
    std::cout << "ptr[2]: " << ptr[2] << std::endl;                    // 指针的下标访问
    std::cout << "*(ptr + 2): " << *(ptr + 2) << std::endl;            // 指针算术访问
    
    // 指针算术
    // 指针算术会根据指针指向的类型自动调整偏移量
    // 对于int*指针，ptr+1会向后移动sizeof(int)字节（通常是4字节）
    std::cout << "\n指针算术:" << std::endl;
    std::cout << "ptr: " << ptr << ", *ptr: " << *ptr << std::endl;  // 指向第一个元素(10)
    ptr++;  // 指针向后移动一个元素的位置，现在指向第二个元素(20)
    std::cout << "ptr++后: " << ptr << ", *ptr: " << *ptr << std::endl;
    ptr += 2;  // 指针向后移动两个元素的位置，现在指向第四个元素(40)
    std::cout << "ptr += 2后: " << ptr << ", *ptr: " << *ptr << std::endl;
}

int main() {
    int numbers[] = {64, 34, 25, 12, 22, 11, 90};
    // 使用sizeof运算符计算数组大小：数组总字节数除以单个元素字节数
    std::size_t size = sizeof(numbers) / sizeof(numbers[0]);
    // 注意：这种方法只在数组定义在同一作用域内有效，不能用于函数参数中的数组
    
    std::cout << "原始数组:" << std::endl;
    printArray(numbers, size);           // 使用下标方式打印数组
```

### 2.2 二维数组操作

二维数组可以看作是数组的数组，它在逻辑上呈现为表格或矩阵的形式。然而，在物理内存中，二维数组仍然是线性存储的，通常采用行主序（row-major order）的方式，即先存储第一行的所有元素，然后存储第二行的所有元素，依此类推。

理解二维数组的内存布局对于高效编程和性能优化非常重要，特别是在处理大型矩阵或图像数据时。

```cpp
#include <iostream>
#include <cstddef>  // 用于std::size_t

// 打印二维数组
// 注意：函数参数中的二维数组必须指定列数，行数可以省略
// 这是因为C++需要知道列数才能正确计算内存偏移量
// arr[][3]等同于(*arr)[3]，表示指向包含3个整数的数组的指针
void print2DArray(int arr[][3], std::size_t rows) {
    for (std::size_t i = 0; i < rows; i++) {
        for (std::size_t j = 0; j < 3; j++) {
            std::cout << arr[i][j] << " ";
        }
        std::cout << std::endl;
    }
}

// 使用指针遍历二维数组
// 这种方法将二维数组视为一维数组来处理，通过计算线性索引访问元素
// 适用于需要灵活处理不同维度数组的情况
void print2DArrayWithPointer(int* arr, std::size_t rows, std::size_t cols) {
    std::cout << "使用指针遍历二维数组:" << std::endl;
    for (std::size_t i = 0; i < rows; i++) {
        for (std::size_t j = 0; j < cols; j++) {
            // 计算元素在内存中的线性位置：行号 * 列数 + 列号
            // 这反映了二维数组在内存中的实际存储方式（行主序）
            std::size_t index = i * cols + j;
            std::cout << *(arr + index) << " ";
        }
        std::cout << std::endl;
    }
}

// 计算矩阵和
// 遍历二维数组的所有元素并累加它们的值

// 动态分配二维数组
int** create2DArray(std::size_t rows, std::size_t cols) {
    // 分配行指针数组
    int** arr = new int*[rows];
    
    // 为每一行分配内存
    for (std::size_t i = 0; i < rows; i++) {
        arr[i] = new int[cols];

}

// 释放动态分配的二维数组
void delete2DArray(int** arr, std::size_t rows) {

    }
    
    // 再释放行指针数组
    delete[] arr;
}
```

## 3. 字符串处理

字符串是计算机程序中最常用的数据类型之一，用于表示文本信息。在C++中，字符串处理有多种方式，包括C风格的字符数组和C++标准库提供的string类。理解字符串的内部表示、编码方式和处理算法对于开发高效、安全的文本处理程序至关重要。

### 3.1 C风格字符串

C风格字符串是以空字符('\0')结尾的字符数组，是C语言继承而来的字符串表示方式。尽管C++提供了更安全的string类，但在某些场景下，C风格字符串仍然有其应用价值，特别是在与C库交互、嵌入式系统开发等场景。

```cpp
#include <iostream>
#include <cstring>  // 包含C风格字符串处理函数
#include <cstddef>  // 用于std::size_t

// 计算字符串长度（不使用strlen）
// 注意：此函数假设输入是有效的以null结尾的字符串
// 在实际应用中，应考虑添加空指针检查
std::size_t stringLength(const char* str) {
    std::size_t length = 0;
    // 遍历字符数组直到遇到空字符'\0'
    // 空字符是C风格字符串的结束标志，不计入字符串长度
    while (str[length] != '\0') {
        length++;
    }
    return length;
}

// 安全的字符串复制函数
// 确保目标缓冲区不会溢出，防止缓冲区溢出攻击
void safeStringCopy(char* dest, const char* src, std::size_t destSize) {
    if (destSize == 0) return;  // 目标缓冲区大小为0，无法复制
    
    std::size_t i;
    // 复制字符，直到遇到源字符串结尾或目标缓冲区满
    // destSize-1确保为null终止符预留空间
    for (i = 0; i < destSize - 1 && src[i] != '\0'; i++) {
        dest[i] = src[i];
    }
    
    // 确保目标字符串以null结尾
    // 这是C风格字符串正确工作的关键
    dest[i] = '\0';
}

// 字符串连接函数
// 将源字符串连接到目标字符串末尾
void stringConcatenate(char* dest, const char* src, std::size_t destSize) {
    // 找到目标字符串的末尾
    std::size_t destLen = stringLength(dest);
    
    // 计算剩余可用空间
    if (destLen >= destSize) return;  // 目标字符串已满或溢出
    
    std::size_t availableSpace = destSize - destLen - 1;  // 减1为null字符预留空间
    
    // 复制源字符串到目标字符串末尾
    std::size_t i;
    for (i = 0; i < availableSpace && src[i] != '\0'; i++) {
        dest[destLen + i] = src[i];
    }
    
    // 确保目标字符串以null结尾
    dest[destLen + i] = '\0';
}

// 字符串比较函数
// 返回值：0表示相等，负数表示str1<str2，正数表示str1>str2
// 这种返回值约定与标准库的strcmp函数一致
int stringCompare(const char* str1, const char* str2) {
    std::size_t i = 0;
    
    // 逐个字符比较，直到遇到不同字符或字符串结尾
    while (str1[i] != '\0' && str2[i] != '\0') {
        if (str1[i] != str2[i]) {
            return str1[i] - str2[i];  // 返回字符差值
        }
        i++;
    }
    
    // 处理一个字符串是另一个字符串前缀的情况
    // 例如："abc"与"abcd"比较，返回'\0'-'d'的差值
    return str1[i] - str2[i];
}

// 查找子字符串
// 返回子字符串在主字符串中首次出现的位置，未找到返回-1
// 这是一个简单的字符串搜索算法，时间复杂度为O(n*m)
int findSubstring(const char* str, const char* substr) {
    std::size_t strLen = stringLength(str);
    std::size_t substrLen = stringLength(substr);
    
    // 如果子字符串长度大于主字符串，直接返回未找到
    if (substrLen > strLen) return -1;
    
    // 遍历主字符串，寻找可能的匹配位置
    for (std::size_t i = 0; i <= strLen - substrLen; i++) {
        std::size_t j;
        // 检查当前位置是否匹配子字符串
        for (j = 0; j < substrLen; j++) {
            if (str[i + j] != substr[j]) {
                break;  // 不匹配，尝试下一个位置
            }
        }
        
        // 如果子字符串完全匹配
        if (j == substrLen) {
            return static_cast<int>(i);  // 返回匹配位置
        }
    }
    
    return -1;  // 未找到子字符串
}

// 字符串反转函数
// 原地反转字符串，不需要额外的存储空间
// 时间复杂度：O(n/2) ≈ O(n)，空间复杂度：O(1)
void reverseString(char* str) {
    std::size_t len = stringLength(str);  // 获取字符串长度
    
    // 交换对称位置的字符，只需遍历字符串的一半长度
    // 例如：对于"hello"，只需交换h与l、e与o，中间的l保持不变
    for (std::size_t i = 0; i < len / 2; i++) {
        char temp = str[i];  // 保存前半部分的字符
        str[i] = str[len - 1 - i];  // 将后半部分的字符放到前半部分
        str[len - 1 - i] = temp;  // 将保存的字符放到后半部分
    }
}

// 演示字符编码处理
void demonstrateCharacterEncoding() {
    std::cout << "字符编码演示:" << std::endl;
    
    // ASCII字符：使用7位二进制表示128个字符（0-127）
    char asciiChar = 'A';
    std::cout << "ASCII字符 '" << asciiChar << "' 的编码值: " << static_cast<int>(asciiChar) << std::endl;
    
    // 注意：C++中的char类型通常用于存储ASCII字符或UTF-8编码的字节
    // 对于多字节字符（如中文），需要使用多个char或专门的宽字符类型(wchar_t)
    
    // UTF-8编码的中文示例（需要3个字节）
    // UTF-8是变长编码，英文字符用1字节，中文字符通常用3字节
    char utf8Chinese[] = "中";
    std::cout << "UTF-8编码的'中'字占用字节数: " << stringLength(utf8Chinese) << std::endl;
    std::cout << "字节值: ";
    // 使用unsigned char确保正确显示字节值（避免负数）
    for (std::size_t i = 0; i < stringLength(utf8Chinese); i++) {
        std::cout << static_cast<int>(static_cast<unsigned char>(utf8Chinese[i])) << " ";
    }
    std::cout << std::endl;
}

    std::cout << "问候语: " << greeting << std::endl;
```

### 3.2 C++ string类

C++标准库提供的`std::string`类是对C风格字符串的封装，提供了更安全、更便捷的字符串操作方式。`std::string`自动管理内存，避免了缓冲区溢出等安全问题，并提供了丰富的成员函数来处理字符串。理解`std::string`的内部实现和性能特性对于编写高效的字符串处理代码至关重要。

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <algorithm>  // 用于std::sort
#include <cctype>     // 用于字符处理函数

// 演示string的基本操作
void demonstrateBasicStringOperations() {
    std::cout << "=== 基本字符串操作 ===" << std::endl;
    
    // 字符串创建和初始化
    std::string s1;                    // 空字符串，默认构造函数
    std::string s2("Hello");           // 使用C风格字符串初始化
    std::string s3(s2);                // 拷贝构造，深拷贝s2的内容
    std::string s4(10, 'A');           // 重复字符构造，创建包含10个'A'的字符串
    std::string s5("Hello World", 5);  // 从C风格字符串的前5个字符构造，结果为"Hello"
    
    std::cout << "s1: '" << s1 << "' (长度: " << s1.length() << ")" << std::endl;
    std::cout << "s2: '" << s2 << "' (长度: " << s2.length() << ")" << std::endl;
    std::cout << "s3: '" << s3 << "' (长度: " << s3.length() << ")" << std::endl;
    std::cout << "s4: '" << s4 << "' (长度: " << s4.length() << ")" << std::endl;
    std::cout << "s5: '" << s5 << "' (长度: " << s5.length() << ")" << std::endl;
    
    // 字符串赋值：使用赋值运算符，会释放原有内存并分配新内存
    s1 = s2;
    std::cout << "赋值后 s1: '" << s1 << "'" << std::endl;
    
    // 字符串连接：使用+运算符，创建新的字符串对象
    std::string s6 = s2 + " " + s5;  // 结果为"Hello Hello"
    std::cout << "连接后 s6: '" << s6 << "'" << std::endl;

    if (s2 == s3) {
        std::cout << "s2 和 s3 相等" << std::endl;  // 内容相同
    }
    
    if (s2 > s5) {
        std::cout << "s2 大于 s5" << std::endl;  // "Hello" > "Hello"是false，因为长度相同且内容相同
    } else {
```

## 4. 递归的基本思想

递归是一种强大的编程技术，它允许函数直接或间接地调用自身来解决问题。递归的核心思想是将复杂问题分解为更小的、相似的子问题，直到达到可以直接解决的基础情况。理解递归的工作原理、与迭代的区别以及优化技术对于编写高效、可维护的递归代码至关重要。

### 4.1 递归函数示例

```cpp
#include <iostream>
#include <vector>
#include <chrono>  // 用于性能测试

// 计算阶乘 - 基础递归实现
// 时间复杂度: O(n)，空间复杂度: O(n)（由于调用栈）
long long factorial(int n) {
    // 基础情况：递归的终止条件
    if (n <= 1) {
        return 1;
    }
    // 递归情况：函数调用自身，但参数更接近基础情况
    return n * factorial(n - 1);
}

// 计算阶乘 - 尾递归优化版本
// 时间复杂度: O(n)，空间复杂度: O(1)（如果编译器支持尾调用优化）
long long factorialTailRecursive(int n, long long accumulator = 1) {
    // 基础情况
    if (n <= 1) {
        return accumulator;
    }
    // 递归调用是函数的最后一个操作，编译器可以优化为循环
    return factorialTailRecursive(n - 1, n * accumulator);
}

// 计算阶乘 - 迭代实现
// 时间复杂度: O(n)，空间复杂度: O(1)
long long factorialIterative(int n) {
    long long result = 1;
    for (int i = 2; i <= n; ++i) {
        result *= i;
    }
    return result;
}

// 斐波那契数列 - 基础递归实现（效率低下）
// 时间复杂度: O(2^n)，空间复杂度: O(n)
long long fibonacciRecursive(int n) {
    if (n <= 1) {
        return n;
    }
    return fibonacciRecursive(n - 1) + fibonacciRecursive(n - 2);
}

// 斐波那契数列 - 记忆化递归实现（动态规划）
// 时间复杂度: O(n)，空间复杂度: O(n)
long long fibonacciMemoization(int n, std::vector<long long>& memo) {
    if (n <= 1) {
        return n;
    }
    
    // 如果已经计算过，直接返回结果
    if (memo[n] != -1) {
        return memo[n];
    }
    
    // 计算并存储结果
    memo[n] = fibonacciMemoization(n - 1, memo) + fibonacciMemoization(n - 2, memo);
    return memo[n];
}

// 斐波那契数列 - 迭代实现
// 时间复杂度: O(n)，空间复杂度: O(1)
long long fibonacciIterative(int n) {
    if (n <= 1) {
        return n;
    }
    
    long long prev = 0;
    long long curr = 1;
    
    for (int i = 2; i <= n; ++i) {
        long long temp = prev + curr;
        prev = curr;
        curr = temp;
    }
    
    return curr;
}

// 汉诺塔问题 - 经典递归应用
// 时间复杂度: O(2^n)，空间复杂度: O(n)
void hanoi(int n, char from, char to, char aux) {
    // 基础情况：只有一个盘子，直接移动
    if (n == 1) {
        std::cout << "移动盘子从 " << from << " 到 " << to << std::endl;
        return;
    }
    
    // 递归情况：
    // 1. 将上面的n-1个盘子从起始柱移到辅助柱
    hanoi(n - 1, from, aux, to);
    
    // 2. 将最大的盘子从起始柱移到目标柱
    std::cout << "移动盘子从 " << from << " 到 " << to << std::endl;
    
    // 3. 将n-1个盘子从辅助柱移到目标柱
    hanoi(n - 1, aux, to, from);
}

// 二分查找 - 递归版本
// 时间复杂度: O(log n)，空间复杂度: O(log n)
int binarySearchRecursive(int arr[], int left, int right, int target) {
    // 基础情况：未找到目标
    if (left > right) {
        return -1;
    }
    
    // 计算中间位置
    int mid = left + (right - left) / 2;
    
    // 找到目标
    if (arr[mid] == target) {
        return mid;
    }
    // 目标在左半部分
    else if (arr[mid] > target) {
        return binarySearchRecursive(arr, left, mid - 1, target);
    }
    // 目标在右半部分
    else {
        return binarySearchRecursive(arr, mid + 1, right, target);
    }
}

// 二分查找 - 迭代版本
// 时间复杂度: O(log n)，空间复杂度: O(1)
int binarySearchIterative(int arr[], int size, int target) {
    int left = 0;
    int right = size - 1;
    
    while (left <= right) {
        int mid = left + (right - left) / 2;
        
        if (arr[mid] == target) {
            return mid;
        } else if (arr[mid] > target) {
            right = mid - 1;
        } else {
            left = mid + 1;
        }
    }
    
    return -1;
}

// 归并排序 - 递归实现
// 时间复杂度: O(n log n)，空间复杂度: O(n)
void merge(std::vector<int>& arr, int left, int mid, int right) {
    // 创建临时数组
    std::vector<int> leftArr(arr.begin() + left, arr.begin() + mid + 1);
    std::vector<int> rightArr(arr.begin() + mid + 1, arr.begin() + right + 1);
    
    int i = 0, j = 0, k = left;
    
    // 合并两个有序数组
    while (i < leftArr.size() && j < rightArr.size()) {
        if (leftArr[i] <= rightArr[j]) {
            arr[k++] = leftArr[i++];
        } else {
            arr[k++] = rightArr[j++];
        }
    }
    
    // 复制剩余元素
    while (i < leftArr.size()) {
        arr[k++] = leftArr[i++];
    }
    
    while (j < rightArr.size()) {
        arr[k++] = rightArr[j++];
    }
}

void mergeSort(std::vector<int>& arr, int left, int right) {
    // 基础情况：单个元素或空数组已经有序
    if (left >= right) {
        return;
    }
    
    // 分割数组
    int mid = left + (right - left) / 2;
    
    // 递归排序左半部分
    mergeSort(arr, left, mid);
    
    // 递归排序右半部分
    mergeSort(arr, mid + 1, right);
    
    // 合并两个有序数组
    merge(arr, left, mid, right);
}
```

## 5. 函数调用的工作原理

### 5.1 调用过程的基本步骤
1. **准备参数**：将实际参数的值传递给形式参数

- **作用域**：函数内的变量只在函数内部可见

## 6. 参数传递的基本方式

### 6.1 值传递（按值传递）

**基本概念**

**特点和影响**
- **数据安全**：函数内部对参数的修改不会影响原始数据
- **内存开销**：需要复制数据，对于大型对象可能消耗较多内存
- **适用场景**：传递基本数据类型或不需要修改原始数据的情况

**特点和优势**

- **可修改性**：函数可以修改原始数据
- **别名机制**：引用实际上是原始变量的另一个名字
- **适用场景**：需要修改原始数据或传递大型对象时

### 6.3 指针传递

**基本概念**
指针传递是通过传递变量的内存地址来实现数据共享。

**特点和应用**

- **灵活性**：可以指向不同的对象
- **空值处理**：指针可以为空，需要检查有效性
- **动态内存**：常用于动态分配的内存管理

## 9. 递归的基本思想

### 9.1 递归的概念

**什么是递归**
递归是一种解决问题的方法，其中函数调用自身来解决规模更小的相同问题。

**递归的要素**
- **基础情况**：递归的终止条件，不再调用自身
- **递归情况**：函数调用自身处理更小的问题
- **问题分解**：将大问题分解为小问题
- **结果合并**：将小问题的解合并为大问题的解

### 9.2 递归的工作原理

**执行过程**
1. **问题分解**：将当前问题分解为更小的子问题
2. **递归调用**：调用自身处理子问题
3. **栈管理**：每次调用在栈上创建新的执行环境
4. **逐层返回**：从最深层开始逐层返回结果
5. **结果组合**：将各层结果组合成最终答案

**递归与迭代的比较**
- **递归优势**：代码简洁，逻辑清晰，适合处理树形结构
- **递归劣势**：可能消耗大量栈空间，执行效率相对较低
- **迭代优势**：空间效率高，执行速度快
- **迭代劣势**：某些问题的迭代实现较为复杂

### 9.3 递归优化技术

递归虽然代码简洁，但如果不加以优化，可能会导致性能问题和栈溢出。了解递归优化技术对于编写高效的递归代码至关重要。

#### 9.3.1 尾递归优化

尾递归是指递归调用是函数中的最后一个操作，并且递归调用的结果直接作为当前函数的返回值。尾递归可以被编译器优化为循环，从而避免额外的栈空间使用。

**尾递归的条件**
1. 递归调用是函数的最后一个操作
2. 递归调用的结果直接返回，不再进行其他操作
3. 没有需要在递归调用后处理的操作

**尾递归的优势**
- **空间效率**：空间复杂度从O(n)降低到O(1)
- **栈安全**：避免了深度递归导致的栈溢出
- **性能提升**：减少了函数调用的开销

**示例：阶乘的尾递归优化**
```cpp
// 普通递归 - 非尾递归
// 每次递归调用都需要保存当前状态，空间复杂度O(n)
int factorialNonTailRecursive(int n) {
    if (n <= 1) {
        return 1;
    }
    // 递归调用后还有乘法操作，不是尾递归
    return n * factorialNonTailRecursive(n - 1);
}

// 尾递归版本
// 递归调用是最后一个操作，编译器可以优化为循环，空间复杂度O(1)
int factorialTailRecursive(int n, int accumulator = 1) {
    if (n <= 1) {
        return accumulator;
    }
    // 递归调用是最后一个操作，并且直接返回结果
    return factorialTailRecursive(n - 1, n * accumulator);
}
```

#### 9.3.2 记忆化技术

记忆化是一种通过缓存计算结果来避免重复计算的优化技术，特别适用于具有重叠子问题的递归算法。

**记忆化的原理**
1. 为每个子问题的解创建缓存
2. 在计算前检查缓存中是否已有解
3. 如果有，直接返回缓存的结果
4. 如果没有，计算并缓存结果

**记忆化的优势**
- **时间效率**：将指数级时间复杂度降低到多项式级
- **避免重复计算**：特别是对于有重叠子问题的问题
- **实现简单**：只需添加少量缓存代码

**示例：斐波那契数列的记忆化**
```cpp
// 基础递归（效率低下）
// 时间复杂度: O(2^n)，空间复杂度: O(n)
long long fibonacciBasic(int n) {
    if (n <= 1) {
        return n;
    }
    // 重复计算大量子问题
    return fibonacciBasic(n - 1) + fibonacciBasic(n - 2);
}

// 记忆化递归
// 时间复杂度: O(n)，空间复杂度: O(n)
long long fibonacciMemo(int n, std::vector<long long>& memo) {
    if (n <= 1) {
        return n;
    }
    
    // 如果已经计算过，直接返回结果
    if (memo[n] != -1) {
        return memo[n];
    }
    
    // 计算并存储结果
    memo[n] = fibonacciMemo(n - 1, memo) + fibonacciMemo(n - 2, memo);
    return memo[n];
}
```

#### 9.3.3 递归与迭代的转换

有时我们需要将递归算法转换为迭代算法，以避免栈溢出或提高性能。

**转换策略**
1. **显式栈**：使用显式数据结构模拟递归调用栈
2. **尾递归转换**：将尾递归转换为循环
3. **状态机**：使用状态机模拟递归过程

**示例：快速排序的递归与迭代实现**
```cpp
// 递归版本的快速排序
void quickSortRecursive(std::vector<int>& arr, int low, int high) {
    if (low < high) {
        // 分区操作
        int pi = partition(arr, low, high);
        
        // 递归排序分区
        quickSortRecursive(arr, low, pi - 1);
        quickSortRecursive(arr, pi + 1, high);
    }
}

// 迭代版本的快速排序（使用显式栈）
void quickSortIterative(std::vector<int>& arr, int low, int high) {
    // 创建一个显式栈
    std::stack<int> stack;
    
    // 初始值入栈
    stack.push(low);
    stack.push(high);
    
    while (!stack.empty()) {
        // 弹出high和low
        high = stack.top();
        stack.pop();
        low = stack.top();
        stack.pop();
        
        // 分区操作
        int pi = partition(arr, low, high);
        
        // 如果分区左边有元素，入栈
        if (pi - 1 > low) {
            stack.push(low);
            stack.push(pi - 1);
        }
        
        // 如果分区右边有元素，入栈
        if (pi + 1 < high) {
            stack.push(pi + 1);
            stack.push(high);
        }
    }
}
```

#### 9.3.4 递归深度控制

对于可能导致栈溢出的深度递归，我们可以通过控制递归深度来避免问题。

**深度控制策略**
1. **设置最大深度**：限制递归的最大深度
2. **异常处理**：当超过深度时抛出异常
3. **迭代回退**：深度过大时切换到迭代实现

**示例：递归深度控制包装器**
```cpp
// 递归深度控制包装器
template<typename Func>
auto withDepthControl(Func func, int maxDepth) {
    return [func, maxDepth](auto&&... args) -> decltype(auto) {
        thread_local int currentDepth = 0;
        
        if (currentDepth >= maxDepth) {
            throw std::runtime_error("递归深度超过限制");
        }
        
        ++currentDepth;
        try {
            auto result = func(std::forward<decltype(args)>(args)...);
            --currentDepth;
            return result;
        } catch (...) {
            --currentDepth;
            throw;
        }
    };
}
```

## 10. 内存管理的基本概念

### 10.1 栈内存与堆内存

**栈内存的特点**
- **自动管理**：变量的创建和销毁由系统自动处理
- **生命周期**：与作用域绑定，离开作用域自动销毁
- **访问速度**：访问速度快，分配效率高
- **大小限制**：栈空间有限，不适合存储大量数据

**堆内存的特点**
- **手动管理**：需要程序员显式分配和释放
- **灵活性**：可以动态分配任意大小的内存
- **生命周期**：由程序员控制，不受作用域限制
- **访问速度**：相对较慢，但空间更大

### 10.2 内存安全的重要性

**常见内存问题**
- **内存泄漏**：分配的内存没有及时释放
- **野指针**：指向已释放内存的指针
- **缓冲区溢出**：写入超出分配空间的数据
- **重复释放**：对同一块内存多次释放

**安全编程原则**
- **RAII原则**：资源获取即初始化，确保资源正确释放
- **智能指针**：自动管理内存的现代C++工具
- **边界检查**：确保数组访问不越界
- **初始化习惯**：总是初始化变量和指针

```cpp
    Vector3() : x(0), y(0), z(0) {}
    Vector3(float x, float y, float z) : x(x), y(y), z(z) {}
    Vector3(const float* arr) : x(arr[0]), y(arr[1]), z(arr[2]) {}
    
    // 运算符重载
    Vector3 operator+(const Vector3& other) const;
    Vector3 operator-(const Vector3& other) const;
    Vector3 operator*(float scalar) const;
    
    // 静态工厂方法重载
    static Vector3 Zero() { return Vector3(0, 0, 0); }
    static Vector3 One() { return Vector3(1, 1, 1); }
    static Vector3 Up() { return Vector3(0, 1, 0); }
    static Vector3 Right() { return Vector3(1, 0, 0); }
    static Vector3 Forward() { return Vector3(0, 0, 1); }
    
    // 工具函数重载
    float Length() const;
    float LengthSquared() const;
    Vector3 Normalized() const;
    void Normalize();
    
    // 点积和叉积
    float Dot(const Vector3& other) const;
    Vector3 Cross(const Vector3& other) const;
    
    // 插值函数重载
    static Vector3 Lerp(const Vector3& a, const Vector3& b, float t);
    static Vector3 Slerp(const Vector3& a, const Vector3& b, float t);
};
```

**重载的最佳实践**
- **语义一致**：所有重载版本应该有相似的功能和语义
- **参数差异明显**：避免产生歧义的重载
- **文档清晰**：明确说明每个重载版本的区别和用途

   - 使用const引用避免不必要的复制
   - 使用移动语义处理临时对象
   - 考虑使用指针处理可选参数

3. **数组操作**
   - 选择合适的内存布局提高缓存效率
   - 使用SIMD指令和并行处理加速数组操作
   - 考虑使用分块存储处理大型数组

   - 使用字符串视图避免不必要的复制
   - 使用字符串池减少内存分配
   - 注意字符编码和国际化问题

5. **递归应用**
   - 使用递归处理自然递归的问题
