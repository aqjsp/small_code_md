# Git基本操作

## 1 仓库的创建与克隆

### 1.1 创建本地仓库
要在现有项目中创建Git仓库，可以使用`git init`命令：

```bash
# 在项目目录中初始化Git仓库
cd /path/to/your/project
git init

# 初始化时指定仓库名称
git init myproject
cd myproject
```

执行`git init`后，Git会在当前目录下创建一个名为`.git`的子目录，这个子目录包含了Git仓库的所有必需文件。

### 1.2 克隆远程仓库
要从远程服务器克隆一个已存在的仓库，使用`git clone`命令：

```bash
# 克隆仓库
git clone https://github.com/user/repository.git

# 克隆到指定目录
git clone https://github.com/user/repository.git myproject

# 克隆特定分支
git clone -b branchname https://github.com/user/repository.git

# 浅克隆（只获取最新提交，不获取完整历史）
git clone --depth 1 https://github.com/user/repository.git
```

### 1.3 仓库的基本信息查看
```bash
# 查看仓库状态
git status

# 查看远程仓库信息
git remote -v

# 查看仓库配置
git config --list
```

## 2 文件的基本操作

### 2.1 添加文件到暂存区
使用`git add`命令将文件添加到暂存区：

```bash
# 添加单个文件
git add filename.txt

# 添加多个文件
git add file1.txt file2.txt

# 添加所有修改的文件
git add .

# 添加所有修改和新文件，但不包括删除的文件
git add --ignore-removal .

# 添加所有修改、新文件和删除的文件
git add -A

# 交互式添加文件
git add -i
```

### 2.2 查看文件状态
```bash
# 查看当前状态
git status

# 查看简洁状态
git status -s

# 查看被忽略的文件
git status --ignored
```

### 2.3 删除文件
```bash
# 从工作区和暂存区删除文件
git rm filename.txt

# 只从暂存区删除，保留工作区文件
git rm --cached filename.txt

# 删除目录
git rm -r directoryname

# 强制删除（即使文件已修改）
git rm -f filename.txt
```

### 2.4 重命名/移动文件
```bash
# 重命名文件
git mv oldname.txt newname.txt

# 移动文件到其他目录
git mv filename.txt directory/

# 重命名并移动
git mv oldname.txt directory/newname.txt
```

### 2.5 查看文件差异
```bash
# 查看工作区与暂存区的差异
git diff

# 查看暂存区与最新提交的差异
git diff --cached

# 查看工作区与最新提交的差异
git diff HEAD

# 查看特定文件的差异
git diff filename.txt

# 查看两个提交之间的差异
git diff commit1 commit2

# 查看分支间的差异
git diff branch1 branch2

# 显示差异统计信息
git diff --stat
```

## 3 提交与查看提交历史

### 3.1 提交更改
使用`git commit`命令将暂存区的更改提交到仓库：

```bash
# 提交并添加提交信息
git commit -m "提交信息"

# 打开编辑器编写详细的提交信息
git commit

# 跳过暂存区，直接提交所有已跟踪文件的修改
git commit -a -m "提交信息"

# 修改最后一次提交
git commit --amend

# 修改最后一次提交的信息
git commit --amend -m "新的提交信息"

# 空提交（不改变代码，只提交新的提交信息）
git commit --allow-empty -m "空提交"
```

### 3.2 提交信息规范
良好的提交信息应该遵循以下规范：
1. **标题行**：简明扼要地描述更改（不超过50个字符）
2. **空行**：标题行和正文之间用空行分隔
3. **正文**：详细描述更改的内容和原因（每行不超过72个字符）

示例：
```
Fix: 修复用户登录问题

- 修复密码验证逻辑错误
- 添加登录失败次数限制
- 更新错误提示信息

Closes #123
```

### 3.3 查看提交历史
```bash
# 查看提交历史
git log

# 查看简洁的提交历史
git log --oneline

# 查看图形化的提交历史
git log --graph --oneline --all

# 查看特定文件的提交历史
git log filename.txt

# 查看特定作者的提交
git log --author="作者名"

# 查看特定时间段的提交
git log --since="2023-01-01" --until="2023-12-31"

# 查看包含特定关键字的提交
git log --grep="关键字"

# 查看每次提交的文件变更统计
git log --stat

# 查看每次提交的详细变更
git log -p

# 限制显示的提交数量
git log -n 5

# 格式化输出
git log --pretty=format:"%h - %an, %ar : %s"
```

### 3.4 格式化输出选项
`git log --pretty=format`支持的常用占位符：
- `%H`：提交的完整哈希值
- `%h`：提交的简短哈希值
- `%T`：树的完整哈希值
- `%t`：树的简短哈希值
- `%P`：父提交的完整哈希值
- `%p`：父提交的简短哈希值
- `%an`：作者姓名
- `%ae`：作者邮箱
- `%ad`：作者日期
- `%ar`：作者相对日期
- `%cn`：提交者姓名
- `%ce`：提交者邮箱
- `%cd`：提交者日期
- `%cr`：提交者相对日期
- `%s`：提交信息

## 4 撤销操作与修改提交

### 4.1 撤销工作区的修改
```bash
# 撤销单个文件的修改
git checkout -- filename.txt

# 撤销所有文件的修改
git checkout .

# 撤销特定目录的修改
git checkout -- directory/
```

### 4.2 撤销暂存区的修改
```bash
# 将文件从暂存区移除，但保留工作区的修改
git reset HEAD filename.txt

# 将所有文件从暂存区移除
git reset HEAD

# 使用git restore（Git 2.23+）
git restore --staged filename.txt
```

### 4.3 修改提交
```bash
# 修改最后一次提交（包括暂存区的修改）
git commit --amend

# 修改最后一次提交的信息
git commit --amend -m "新的提交信息"

# 修改最后一次提交的作者
git commit --amend --author="新作者 <email@example.com>"
```

### 4.4 重置提交
```bash
# 软重置：保留工作区和暂存区的修改，只重置提交指针
git reset --soft HEAD~1

# 混合重置（默认）：保留工作区的修改，清空暂存区
git reset HEAD~1

# 硬重置：丢弃工作区和暂存区的所有修改
git reset --hard HEAD~1

# 重置到指定提交
git reset --hard commit_id

# 使用git restore（Git 2.23+）
git restore --source=HEAD~1 filename.txt
```

### 4.5 反向提交
```bash
# 创建一个新提交，撤销指定提交的修改
git revert commit_id

# 撤销最近一次提交
git revert HEAD

# 撤销多次提交
git revert commit1..commit2

# 不自动创建提交，只将撤销的修改添加到暂存区
git revert -n commit_id
```

### 4.6 使用reflog找回丢失的提交
```bash
# 查看reflog（记录所有HEAD移动）
git reflog

# 恢复到reflog中的某个状态
git reset --hard HEAD@{2}
```

## 5 查看与比较文件差异

### 5.1 查看文件差异
```bash
# 查看工作区与暂存区的差异
git diff

# 查看暂存区与最新提交的差异
git diff --cached
git diff --staged

# 查看工作区与最新提交的差异
git diff HEAD

# 查看工作区与指定提交的差异
git diff commit_id
```

### 5.2 比较提交
```bash
# 查看两个提交之间的差异
git diff commit1 commit2
```

### 5.3 文件差异选项
```bash
# 只显示文件名，不显示具体差异
git diff --name-only

# 显示差异统计信息
git diff --stat

# 显示单词级别的差异
git diff --word-diff

# 忽略空白字符差异
git diff --ignore-space-change
git diff --ignore-all-space

# 显示函数级别的差异
git diff --function-context
```

### 5.4 比较特定文件
```bash
# 比较工作区与暂存区的特定文件
git diff filename.txt

# 比较暂存区与最新提交的特定文件
git diff --cached filename.txt

# 比较两个提交中的特定文件
git diff commit1 commit2 -- filename.txt
```

### 5.5 使用图形化工具查看差异
```bash
# 使用默认的图形化工具
git difftool

# 比较特定文件
git difftool filename.txt

# 使用特定的差异工具
git difftool --tool=vimdiff filename.txt
```

### 5.6 查看文件历史
```bash
# 查看文件的完整历史
git log --follow filename.txt

# 查看文件每次提交的修改
git log -p filename.txt

# 查看文件是谁在何时修改的
git blame filename.txt

# 查看指定行的修改历史
git blame -L 10,20 filename.txt
```

### 5.7 搜索代码
```bash
# 在所有文件中搜索特定字符串
git grep "搜索字符串"

# 在特定文件中搜索
git grep "搜索字符串" -- filename.txt

# 显示行号
git grep -n "搜索字符串"

# 不区分大小写
git grep -i "搜索字符串"

# 显示匹配的文件名
git grep -l "搜索字符串"

# 显示匹配的行数
git grep -c "搜索字符串"
```

## 6 实用技巧

### 6.1 使用别名简化命令

```bash
# 设置常用别名
git config --global alias.co checkout
git config --global alias alias.br branch
git config --global alias.ci commit
git config --global alias.st status

# 设置更复杂的别名
git config --global alias.unstage 'reset HEAD --'
git config --global alias.last 'log -1 HEAD'
git config --global alias.visual '!gitk'

# 查看所有别名
git config --get-regexp alias

# 删除别名
git config --global --unset alias.aliasname
```

### 6.2 使用.gitignore忽略文件
创建`.gitignore`文件来指定Git应该忽略的文件和目录：

```
# 忽略所有.log文件
*.log

# 忽略特定文件
config.ini
secret.key

# 忽略目录
build/
temp/

# 忽略特定目录下的特定文件
docs/*.tmp

# 不忽略特定文件（即使符合忽略规则）
!important.log

# 注释
# 这是注释行

# 使用模式匹配
*.a       # 忽略所有 .a 结尾的文件
!lib.a    # 但 lib.a 除外
/TODO     # 仅仅忽略项目根目录下的 TODO 文件
build/    # 忽略 build/ 目录下的所有文件
doc/*.txt # 忽略 doc/notes.txt 但不包括 doc/server/arch.txt
```

### 6.3 查找特定提交
```bash
# 查看文件的修改历史
git log --oneline --graph --decorate --all

# 搜索提交信息
git log --grep="搜索内容"

# 搜索代码修改
git log -S"搜索内容"

# 查看特定时间段的提交
git log --since="2 weeks ago" --until="1 week ago"

# 查看特定作者的提交
git log --author="作者名"

# 查看特定文件的提交历史
git log -- filename.txt

# 查看提交的统计信息
git log --stat

# 查看提交的详细差异
git log -p

# 使用自定义格式显示提交
git log --pretty=format:"%h - %an, %ar : %s"
```

### 6.4 使用stash临时保存工作
```bash
# 保存当前工作进度
git stash

# 保存进度并添加说明
git stash save "工作进度说明"

# 保存包括未跟踪的文件
git stash -u

# 保存包括未跟踪和忽略的文件
git stash -a

# 查看所有保存的进度
git stash list

# 恢复最新的进度
git stash pop

# 恢复指定的进度
git stash pop stash@{1}

# 应用进度但不删除
git stash apply

# 应用指定的进度但不删除
git stash apply stash@{1}

# 查看stash的详细内容
git stash show -p stash@{0}

# 删除指定的进度
git stash drop stash@{1}

# 清空所有进度
git stash clear

# 从stash创建分支
git stash branch new-branch-name stash@{0}
```

### 6.5 子模块管理
```bash
# 添加子模块
git submodule add https://github.com/user/repo.git path/to/submodule

# 初始化子模块
git submodule init

# 更新子模块
git submodule update

# 克隆包含子模块的项目
git clone --recursive https://github.com/user/main-project.git

# 查看子模块状态
git submodule status

# 删除子模块
git submodule deinit path/to/submodule
git rm path/to/submodule
```

### 6.6 打包与归档
```bash
# 创建归档文件
git archive --format=zip --output=archive.zip HEAD

# 创建特定提交的归档
git archive --format=tar.gz --output=archive.tar.gz commit_id

# 只归档特定路径
git archive --format=zip HEAD -- path/to/directory

# 创建带前缀的归档
git archive --format=tar.gz --prefix=project/ HEAD
```

### 6.7 清理仓库
```bash
# 清理未跟踪的文件
git clean -f

# 清理未跟踪的文件和目录
git clean -fd

# 预览将要清理的文件
git clean -n

# 清理未跟踪的文件和忽略的文件
git clean -fdX

# 清理过期的分支
git remote prune origin

# 清理无效的引用
git gc --prune=now
```
