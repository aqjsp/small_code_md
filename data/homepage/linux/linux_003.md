# 第3章：Linux基本概念

## 1 Linux文件系统结构

### 1.1 文件系统层次结构标准(FHS)

Linux文件系统遵循文件系统层次结构标准(Filesystem Hierarchy Standard, FHS)，这是一个定义了Linux系统中目录和文件布局的规范。了解这个结构对于理解Linux系统至关重要。

Linux文件系统采用树形结构，根目录用"/"表示，所有其他目录和文件都挂载在根目录下。

### 1.2 主要目录及其用途

以下是Linux系统中最重要的目录及其用途：

```
/
├── bin/        # 基本命令二进制文件
├── sbin/       # 系统管理员使用的二进制文件
├── etc/        # 系统配置文件
├── dev/        # 设备文件
├── proc/       # 进程信息虚拟文件系统
├── var/        # 变量文件，如日志、缓存等
├── tmp/        # 临时文件
├── usr/        # 用户程序和数据
├── home/       # 用户主目录
├── boot/       # 启动加载文件
├── lib/        # 系统库文件
├── opt/        # 可选软件包
├── mnt/        # 临时挂载点
├── media/      # 可移动媒体挂载点
├── srv/        # 服务数据
├── sys/        # 系统信息虚拟文件系统
└── root/       # root用户主目录
```

#### 详细说明

1. **/bin** - 基本命令二进制文件
   - 包含所有用户可使用的基本命令，如ls、cp、mv等
   - 这些命令在单用户模式下也需要使用
   - 不包含子目录

2. **/sbin** - 系统管理员二进制文件
   - 包含系统管理员使用的命令，如fdisk、ifconfig等
   - 通常需要root权限执行
   - 这些命令在系统启动和维护时需要

3. **/etc** - 系统配置文件
   - 包含系统和应用程序的配置文件
   - 如/etc/passwd（用户信息）、/etc/group（组信息）
   - 不包含二进制文件

4. **/dev** - 设备文件
   - 包含所有设备文件
   - Linux将所有设备视为文件
   - 如/dev/sda（第一块硬盘）、/dev/tty（终端）

5. **/proc** - 进程信息虚拟文件系统
   - 虚拟文件系统，不占用磁盘空间
   - 包含系统和进程信息
   - 如/proc/cpuinfo（CPU信息）、/proc/meminfo（内存信息）

6. **/var** - 变量文件
   - 包含经常变化的文件
   - 如/var/log（日志文件）、/var/cache（缓存）
   - /var/www（Web服务器文件）

7. **/tmp** - 临时文件
   - 存放临时文件
   - 系统重启时可能清空
   - 所有用户都有写入权限

8. **/usr** - 用户程序和数据
   - 包含用户安装的程序和文件
   - /usr/bin（用户命令）
   - /usr/lib（库文件）
   - /usr/share（共享数据）
   - /usr/local（本地安装的软件）

9. **/home** - 用户主目录
   - 包含普通用户的个人目录
   - 如/home/username（用户username的主目录）
   - 存放用户的个人文件和配置

10. **/boot** - 启动加载文件
    - 包含系统启动所需的文件
    - 如Linux内核(vmlinuz)、引导加载程序(grub)
    - 通常单独分区

11. **/lib** - 系统库文件
    - 包含系统和/bin、/sbin中命令所需的共享库
    - 如/lib/modules（内核模块）

12. **/opt** - 可选软件包
    - 用于安装可选的软件包
    - 如Google Chrome安装在/opt/google/chrome

13. **/mnt** - 临时挂载点
    - 用于临时挂载文件系统
    - 如挂载U盘、CD-ROM等

14. **/media** - 可移动媒体挂载点
    - 用于挂载可移动媒体
    - 自动挂载U盘、CD-ROM等

15. **/srv** - 服务数据
    - 包含服务提供的数据
    - 如/srv/www（Web服务数据）、/srv/ftp（FTP服务数据）

16. **/sys** - 系统信息虚拟文件系统
    - 虚拟文件系统，不占用磁盘空间
    - 包含内核、驱动和设备信息
    - 类似/proc，但更结构化

17. **/root** - root用户主目录
    - root用户的个人目录
    - 类似/home，但专用于root用户

### 1.3 文件系统类型

Linux支持多种文件系统类型：

1. **ext4** - 第四代扩展文件系统
   - 大多数Linux发行版的默认文件系统
   - 支持大文件和大容量分区
   - 日志文件系统，提高可靠性

2. **xfs** - 高性能日志文件系统
   - 适合大文件和高并发环境
   - SUSE和CentOS的默认文件系统

3. **btrfs** - B树文件系统
   - 现代文件系统，支持快照、压缩等功能
   - 仍处于发展阶段

4. **zfs** - Z文件系统
   - 高级文件系统，支持快照、压缩、数据完整性检查
   - 原为Solaris开发，现在Linux也有支持

## 2 用户与权限概念

### 2.1 用户类型

Linux系统中有三种类型的用户：

1. **root用户（超级用户）**
   - 用户ID为0
   - 拥有系统的最高权限
   - 可以执行任何操作
   - 通常用于系统管理任务

2. **系统用户**
   - 用于运行系统服务和应用程序
   - 通常没有登录权限
   - 用户ID通常较低（如1-999）
   - 如www-data、nobody等

3. **普通用户**
   - 用于日常操作
   - 用户ID通常较高（如1000以上）
   - 权限受限
   - 可以通过sudo获取临时权限

### 2.2 用户组

用户组是用户的集合，用于简化权限管理：

1. **主要组** - 每个用户都有一个主要组
2. **附加组** - 用户可以属于多个附加组

常见的系统组：
- **root** - root用户组
- **wheel** - 可以使用sudo的用户组（某些发行版）
- **sudo** - 可以使用sudo的用户组（Ubuntu等）
- **adm** - 可以查看系统日志的用户组
- **cdrom** - 可以使用光驱的用户组
- **audio** - 可以使用音频设备的用户组
- **video** - 可以使用视频设备的用户组

### 2.3 文件权限

Linux使用权限位来控制对文件和目录的访问：

#### 权限位

每个文件或目录有9个权限位，分为三组：
- **所有者权限** - 文件所有者的权限
- **组权限** - 文件所属组的权限
- **其他用户权限** - 其他所有用户的权限

每组权限包含三个位：
- **r** - 读权限
- **w** - 写权限
- **x** - 执行权限

#### 权限表示

权限可以用两种方式表示：

1. **符号表示** - 如rwxr-xr--
2. **八进制表示** - 如750

权限对应关系：
- r = 4
- w = 2
- x = 1
- - = 0

示例：
- rwxr-xr-- = 764
- rwxrwxrwx = 777
- rw-r--r-- = 644

#### 特殊权限

除了基本权限外，Linux还有三种特殊权限：

1. **SUID (Set User ID)**
   - 设置在可执行文件上
   - 执行时以文件所有者身份运行
   - 八进制表示：4000
   - 符号表示：s

2. **SGID (Set Group ID)**
   - 设置在可执行文件或目录上
   - 文件：执行时以文件所属组身份运行
   - 目录：在该目录下创建的文件继承目录的组
   - 八进制表示：2000
   - 符号表示：s

3. **Sticky Bit**
   - 设置在目录上
   - 目录中的文件只有所有者才能删除
   - 常用于/tmp目录
   - 八进制表示：1000
   - 符号表示：t

### 2.4 权限管理命令

常用的权限管理命令：

1. **chmod** - 修改文件权限
   ```bash
   # 符号方式
   chmod u+x file      # 给所有者添加执行权限
   chmod g-w file      # 移除组的写权限
   chmod o=r file      # 设置其他用户的权限为只读
   
   # 八进制方式
   chmod 755 file      # 设置权限为rwxr-xr-x
   chmod 644 file      # 设置权限为rw-r--r--
   ```

2. **chown** - 修改文件所有者
   ```bash
   # 修改所有者
   chown user file
   # 同时修改所有者和组
   chown user:group file
   # 递归修改目录及其内容
   chown -R user:group directory
   ```

3. **chgrp** - 修改文件所属组
   ```bash
   chgrp group file
   chgrp -R group directory
   ```

## 3 Shell简介

### 3.1 什么是Shell

Shell是Linux系统的命令解释器，是用户与内核交互的桥梁。它接收用户输入的命令，解释并执行这些命令，然后将结果返回给用户。

Shell的主要功能：
- 命令解释和执行
- 程序设计（Shell脚本）
- 环境变量管理
- 进程控制
- 输入输出重定向
- 管道连接

### 3.2 常见Shell类型

Linux系统中有多种Shell类型：

1. **Bash (Bourne Again Shell)**
   - 最流行的Shell
   - 大多数Linux发行版的默认Shell
   - 兼容Bourne Shell (sh)
   - 功能丰富，扩展性强

2. **sh (Bourne Shell)**
   - 最早的Unix Shell
   - 语法简单
   - 所有Linux系统都支持

3. **csh (C Shell)**
   - 语法类似C语言
   - 适合C程序员
   - 功能不如Bash

4. **tcsh (TENEX C Shell)**
   - csh的增强版
   - 支持命令补全和编辑

5. **ksh (Korn Shell)**
   - 结合了sh和csh的优点
   - 适合编程

6. **zsh (Z Shell)**
   - 功能最强大的Shell
   - 高度可定制
   - 支持丰富的插件

7. **fish (Friendly Interactive Shell)**
   - 用户友好的Shell
   - 智能命令补全
   - 语法高亮

### 3.3 Shell的基本功能

1. **命令执行**
   ```bash
   # 执行命令
   ls -l /home
   date
   whoami
   ```

2. **通配符扩展**
   ```bash
   # 列出所有.txt文件
   ls *.txt
   
   # 列出以a开头的文件
   ls a*
   
   # 列出包含数字的文件
   ls *[0-9]*
   ```

3. **命令历史**
   ```bash
   # 查看命令历史
   history
   
   # 执行历史命令
   !!
   !n    # 执行历史中第n条命令
   !ls   # 执行最近以ls开头的命令
   ```

4. **命令别名**
   ```bash
   # 创建别名
   alias ll='ls -al'
   alias rm='rm -i'
   
   # 查看别名
   alias
   
   # 删除别名
   unalias ll
   ```

5. **输入输出重定向**
   ```bash
   # 输出重定向
   ls > file.txt      # 覆盖
   ls >> file.txt     # 追加
   
   # 输入重定向
   wc -l < file.txt
   
   # 错误重定向
   command 2> error.log
   command &> all.log    # 同时重定向标准输出和错误输出
   ```

6. **管道**
   ```bash
   # 管道连接命令
   ls -l | grep ".txt"
   ps aux | grep "nginx"
   history | grep "ssh"
   ```

### 3.4 Shell环境变量

环境变量是Shell中存储配置信息的变量：

1. **常见环境变量**
   - **PATH** - 命令搜索路径
   - **HOME** - 用户主目录
   - **USER** - 当前用户名
   - **SHELL** - 当前使用的Shell
   - **LANG** - 语言和地区设置
   - **PWD** - 当前工作目录
   - **OLDPWD** - 上一个工作目录

2. **环境变量操作**
   ```bash
   # 查看环境变量
   echo $PATH
   printenv PATH
   
   # 设置环境变量
   export VAR=value
   VAR=value
   export VAR
   
   # 删除环境变量
   unset VAR
   
   # 查看所有环境变量
   env
   printenv
   ```

## 4 命令行基础

### 4.1 命令的基本结构

Linux命令的基本结构：

```
命令 [选项] [参数]
```

- **命令** - 要执行的程序名称
- **选项** - 修改命令行为的标志
- **参数** - 命令操作的对象

选项的两种形式：
- **短选项** - 单个字符，前加`-`，如`-l`
- **长选项** - 完整单词，前加`--`，如`--long`

### 4.2 常用命令

1. **系统信息命令**
   ```bash
   # 查看系统信息
   uname -a          # 显示所有系统信息
   uname -r          # 显示内核版本
   lsb_release -a    # 显示发行版信息
   
   # 查看硬件信息
   lscpu             # CPU信息
   free -h           # 内存信息
   df -h             # 磁盘使用情况
   lsblk             # 块设备信息
   lspci             # PCI设备信息
   lsusb             # USB设备信息
   ```

2. **用户信息命令**
   ```bash
   whoami            # 当前用户名
   id                # 用户ID和组信息
   who               # 当前登录用户
   w                 # 当前登录用户及其活动
   last              # 最近登录记录
   ```

3. **帮助命令**
   ```bash
   # 查看命令帮助
   command --help
   man command       # 查看手册页
   info command      # 查看信息页
   whatis command    # 简短描述
   whereis command   # 命令位置
   which command     # 命令路径
   ```

4. **时间日期命令**
   ```bash
   date              # 当前日期和时间
   cal               # 日历
   uptime            # 系统运行时间
   ```

### 4.3 命令行技巧

1. **命令补全**
   - 使用Tab键自动补全命令和文件名
   - 连按两次Tab键显示所有可能选项

2. **命令历史**
   - 使用上下箭头浏览历史命令
   - 使用Ctrl+R搜索历史命令

3. **快捷键**
   - **Ctrl+C** - 终止当前命令
   - **Ctrl+Z** - 暂停当前命令
   - **Ctrl+D** - 结束输入或退出Shell
   - **Ctrl+L** - 清屏
   - **Ctrl+A** - 移动到行首
   - **Ctrl+E** - 移动到行尾
   - **Ctrl+U** - 删除到行首
   - **Ctrl+K** - 删除到行尾

4. **命令组合**
   ```bash
   # 命令分隔
   command1; command2    # 顺序执行
   command1 && command2   # 前一个成功才执行后一个
   command1 || command2   # 前一个失败才执行后一个
   
   # 命令组合
   (command1; command2)   # 在子Shell中执行
   { command1; command2; }# 在当前Shell中执行
   ```

### 4.4 文件类型

Linux中一切皆文件，常见文件类型：

1. **普通文件 (-)**
   - 文本文件、二进制文件、数据文件等

2. **目录文件 (d)**
   - 包含其他文件和目录的文件

3. **设备文件**
   - **块设备 (b)** - 如硬盘、CD-ROM
   - **字符设备 (c)** - 如终端、键盘

4. **链接文件**
   - **硬链接** - 指向同一inode的文件
   - **符号链接 (l)** - 指向另一个文件的指针

5. **其他文件类型**
   - **套接字文件 (s)** - 进程间通信
   - **管道文件 (p)** - 进程间通信

查看文件类型：
```bash
file filename
ls -l
```

## 5 本章小结

本章介绍了Linux的基本概念，包括文件系统结构、用户与权限概念、Shell简介和命令行基础。这些概念是理解和使用Linux系统的基础，掌握这些内容对于后续学习Linux命令和系统管理至关重要。

Linux的文件系统采用层次结构，每个目录都有特定的用途。用户和权限机制保证了系统的安全性。Shell作为用户与系统的交互界面，提供了强大的命令执行和脚本编程能力。命令行是Linux系统的主要操作方式，掌握基本的命令和技巧可以提高工作效率。
