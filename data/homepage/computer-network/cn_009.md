## 1. 网络编程概述

### 1.1 网络编程基本概念

网络编程是指编写能够在不同计算机之间通过网络进行通信的程序。它涉及客户端/服务器模型、协议栈、套接字编程等概念。网络编程的核心是使用操作系统提供的网络API来实现数据的发送和接收。

#### 1.1.1 客户端/服务器模型

客户端/服务器模型是网络应用中最常见的架构模式：

1. **服务器**：提供服务的程序，被动等待客户端的连接请求
2. **客户端**：请求服务的程序，主动发起连接请求
3. **通信协议**：客户端和服务器之间交换数据的规则和格式

#### 1.1.2 网络协议栈

网络协议栈是网络通信的基础，通常遵循OSI或TCP/IP模型：

1. **应用层**：提供特定应用服务，如HTTP、FTP、SMTP等
2. **传输层**：提供端到端的数据传输服务，如TCP、UDP
3. **网络层**：负责数据包的路由和转发，如IP协议
4. **链路层**：处理物理网络上的数据传输
5. **物理层**：定义物理介质上的比特流传输

#### 1.1.3 套接字(Socket)

套接字是网络编程的基础，它是网络通信的端点：

1. **IP地址**：标识网络中的主机
2. **端口号**：标识主机上的特定进程
3. **协议类型**：指定通信协议，如TCP或UDP

### 1.2 网络编程模型

#### 1.2.1 阻塞I/O模型

阻塞I/O是最简单的网络编程模型，当执行I/O操作时，进程会被阻塞直到操作完成：

- **优点**：编程简单，逻辑清晰
- **缺点**：效率低，无法处理并发连接

#### 1.2.2 非阻塞I/O模型

非阻塞I/O模型中，I/O操作不会阻塞进程，而是立即返回：

- **优点**：可以处理多个连接
- **缺点**：需要轮询检查I/O状态，CPU占用率高

#### 1.2.3 I/O多路复用模型

I/O多路复用通过select、poll、epoll等机制同时监控多个I/O事件：

- **优点**：高效处理大量并发连接
- **缺点**：编程复杂度高

#### 1.2.4 信号驱动I/O模型

信号驱动I/O通过信号通知进程I/O事件：

- **优点**：异步通知，减少轮询
- **缺点**：信号处理复杂，可移植性差

#### 1.2.5 异步I/O模型

异步I/O模型中，操作系统完成I/O操作后通知应用程序：

- **优点**：真正的异步，最高效
- **缺点**：实现复杂，支持有限

## 2. Socket编程基础

### 2.1 Socket基本概念

Socket（套接字）是网络编程的基础，它是网络通信的端点，用于在不同主机之间发送和接收数据。Socket提供了统一的编程接口，屏蔽了底层网络协议的复杂性。

#### 2.1.1 Socket类型

根据通信协议和特性，Socket可以分为以下几种类型：

1. **流式套接字(SOCK_STREAM)**：
   - 基于TCP协议
   - 提供可靠的、面向连接的通信
   - 保证数据顺序和完整性
   - 适用于文件传输、远程登录等场景

2. **数据报套接字(SOCK_DGRAM)**：
   - 基于UDP协议
   - 提供不可靠的、无连接的通信
   - 不保证数据顺序和完整性
   - 适用于视频流、在线游戏等场景

3. **原始套接字(SOCK_RAW)**：
   - 直接访问底层协议
   - 可以构造自定义协议包
   - 需要管理员权限
   - 适用于网络监控、协议分析等场景

#### 2.1.2 Socket地址结构

Socket地址用于标识网络中的通信端点：

1. **IPv4地址结构**：
   ```cpp
   struct sockaddr_in {
       sa_family_t sin_family;    // 地址族，AF_INET
       in_port_t sin_port;        // 端口号
       struct in_addr sin_addr;   // IP地址
   };
   ```

2. **IPv6地址结构**：
   ```cpp
   struct sockaddr_in6 {
       sa_family_t sin6_family;   // 地址族，AF_INET6
       in_port_t sin6_port;       // 端口号
       struct in6_addr sin6_addr;  // IPv6地址
   };
   ```

### 2.2 Socket基本操作

#### 2.2.1 创建Socket

使用`socket()`函数创建Socket：

```cpp
#include <sys/socket.h>

int socket(int domain, int type, int protocol);
```

参数说明：
- `domain`：地址族，如AF_INET（IPv4）、AF_INET6（IPv6）
- `type`：Socket类型，如SOCK_STREAM（TCP）、SOCK_DGRAM（UDP）
- `protocol`：协议类型，通常设为0（自动选择）

返回值：
- 成功：返回Socket描述符（非负整数）
- 失败：返回-1，设置errno

#### 2.2.2 绑定地址

使用`bind()`函数将Socket与地址绑定：

```cpp
#include <sys/socket.h>

int bind(int sockfd, const struct sockaddr *addr, socklen_t addrlen);
```

参数说明：
- `sockfd`：Socket描述符
- `addr`：指向地址结构的指针
- `addrlen`：地址结构的长度

返回值：
- 成功：返回0
- 失败：返回-1，设置errno

#### 2.2.3 监听连接

使用`listen()`函数将Socket设置为监听模式：

```cpp
#include <sys/socket.h>

int listen(int sockfd, int backlog);
```

参数说明：
- `sockfd`：Socket描述符
- `backlog`：等待连接队列的最大长度

返回值：
- 成功：返回0
- 失败：返回-1，设置errno

#### 2.2.4 接受连接

使用`accept()`函数接受客户端连接：

```cpp
#include <sys/socket.h>

int accept(int sockfd, struct sockaddr *addr, socklen_t *addrlen);
```

参数说明：
- `sockfd`：Socket描述符
- `addr`：用于存储客户端地址的缓冲区
- `addrlen`：地址缓冲区的长度

返回值：
- 成功：返回新的Socket描述符
- 失败：返回-1，设置errno

#### 2.2.5 发起连接

使用`connect()`函数发起连接：

```cpp
#include <sys/socket.h>

int connect(int sockfd, const struct sockaddr *addr, socklen_t addrlen);
```

参数说明：
- `sockfd`：Socket描述符
- `addr`：服务器地址
- `addrlen`：地址结构的长度

返回值：
- 成功：返回0
- 失败：返回-1，设置errno

#### 2.2.6 发送数据

使用`send()`或`sendto()`函数发送数据：

```cpp
#include <sys/socket.h>

ssize_t send(int sockfd, const void *buf, size_t len, int flags);
ssize_t sendto(int sockfd, const void *buf, size_t len, int flags,
               const struct sockaddr *dest_addr, socklen_t addrlen);
```

参数说明：
- `sockfd`：Socket描述符
- `buf`：要发送的数据缓冲区
- `len`：数据长度
- `flags`：发送标志
- `dest_addr`：目标地址（仅用于sendto）
- `addrlen`：地址长度（仅用于sendto）

返回值：
- 成功：返回发送的字节数
- 失败：返回-1，设置errno

#### 2.2.7 接收数据

使用`recv()`或`recvfrom()`函数接收数据：

```cpp
#include <sys/socket.h>

ssize_t recv(int sockfd, void *buf, size_t len, int flags);
ssize_t recvfrom(int sockfd, void *buf, size_t len, int flags,
                 struct sockaddr *src_addr, socklen_t *addrlen);
```

参数说明：
- `sockfd`：Socket描述符
- `buf`：接收数据的缓冲区
- `len`：缓冲区长度
- `flags`：接收标志
- `src_addr`：源地址（仅用于recvfrom）
- `addrlen`：地址长度（仅用于recvfrom）

返回值：
- 成功：返回接收的字节数
- 失败：返回-1，设置errno
- 连接关闭：返回0

#### 2.2.8 关闭Socket

使用`close()`函数关闭Socket：

```cpp
#include <unistd.h>

int close(int fd);
```

参数说明：
- `fd`：要关闭的文件描述符

返回值：
- 成功：返回0
- 失败：返回-1，设置errno

## 3. TCP编程实践

### 3.1 TCP服务器实现

#### 3.1.1 基本TCP服务器

下面是一个基本的TCP服务器实现，使用C++编写：

```cpp
#include <iostream>
#include <sys/socket.h>
#include <netinet/in.h>
#include <unistd.h>
#include <string>
#include <thread>
#include <vector>

class TCPServer {
private:
    std::string host;
    int port;
    int server_socket;
    bool running;
    std::vector<std::thread> client_threads;

public:
    TCPServer(std::string host = "0.0.0.0", int port = 8080) 
        : host(host), port(port), server_socket(-1), running(false) {}
    
    ~TCPServer() {
        stop();
    }
    
    void start() {
        try {
            // 创建TCP套接字
            server_socket = socket(AF_INET, SOCK_STREAM, 0);
            if (server_socket < 0) {
                throw std::runtime_error("创建套接字失败");
            }
            
            // 设置地址重用
            int opt = 1;
            if (setsockopt(server_socket, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt)) < 0) {
                throw std::runtime_error("设置套接字选项失败");
            }
            
            // 绑定地址
            struct sockaddr_in server_addr;
            server_addr.sin_family = AF_INET;
            server_addr.sin_addr.s_addr = INADDR_ANY;
            server_addr.sin_port = htons(port);
            
            if (bind(server_socket, (struct sockaddr*)&server_addr, sizeof(server_addr)) < 0) {
                throw std::runtime_error("绑定地址失败");
            }
            
            // 开始监听
            if (listen(server_socket, 5) < 0) {
                throw std::runtime_error("监听失败");
            }
            
            running = true;
            std::cout << "服务器启动，监听 " << host << ":" << port << std::endl;
            
            // 接受客户端连接
            while (running) {
                struct sockaddr_in client_addr;
                socklen_t client_len = sizeof(client_addr);
                
                int client_socket = accept(server_socket, (struct sockaddr*)&client_addr, &client_len);
                if (client_socket < 0) {
                    if (running) {
                        std::cerr << "接受连接失败" << std::endl;
                    }
                    continue;
                }
                
                char client_ip[INET_ADDRSTRLEN];
                inet_ntop(AF_INET, &client_addr.sin_addr, client_ip, INET_ADDRSTRLEN);
                std::cout << "接受来自 " << client_ip << ":" << ntohs(client_addr.sin_port) << " 的连接" << std::endl;
                
                // 为每个客户端创建新线程
                client_threads.emplace_back(&TCPServer::handle_client, this, client_socket, client_ip, ntohs(client_addr.sin_port));
            }
        } catch (const std::exception& e) {
            std::cerr << "服务器启动失败: " << e.what() << std::endl;
            stop();
        }
    }
    
    void stop() {
        running = false;
        
        if (server_socket >= 0) {
            close(server_socket);
            server_socket = -1;
        }
        
        // 等待所有客户端线程结束
        for (auto& thread : client_threads) {
            if (thread.joinable()) {
                thread.join();
            }
        }
        
        std::cout << "服务器已停止" << std::endl;
    }
    
private:
    void handle_client(int client_socket, std::string client_ip, int client_port) {
        try {
            char buffer[1024];
            
            while (running) {
                // 接收数据
                ssize_t bytes_received = recv(client_socket, buffer, sizeof(buffer) - 1, 0);
                if (bytes_received <= 0) {
                    break;
                }
                
                buffer[bytes_received] = '\0';
                std::string message(buffer);
                
                // 处理数据
                std::cout << "来自 " << client_ip << ":" << client_port << " 的消息: " << message << std::endl;
                
                // 发送响应
                std::string response = "服务器收到: " + message;
                send(client_socket, response.c_str(), response.length(), 0);
            }
        } catch (const std::exception& e) {
            std::cerr << "处理客户端 " << client_ip << ":" << client_port << " 时出错: " << e.what() << std::endl;
        }
        
        close(client_socket);
        std::cout << "客户端 " << client_ip << ":" << client_port << " 连接已关闭" << std::endl;
    }
};

// 使用示例
int main() {
    TCPServer server;
    try {
        server.start();
    } catch (...) {
        server.stop();
    }
    return 0;
}
```

## 4. 多线程与并发网络编程

多线程与并发网络编程是提高网络应用程序性能和响应能力的重要技术。通过使用多线程，服务器可以同时处理多个客户端请求，提高系统吞吐量。

### 4.1 多线程服务器模型

#### 4.1.1 线程池模型

线程池是一种常用的并发服务器模型，它预先创建一组工作线程，避免频繁创建和销毁线程的开销：

```cpp
#include <iostream>
#include <thread>
#include <vector>
#include <queue>
#include <mutex>
#include <condition_variable>
#include <functional>
#include <atomic>
#include <sys/socket.h>
#include <netinet/in.h>
#include <unistd.h>

class ThreadPool {
private:
    std::vector<std::thread> workers;
    std::queue<std::function<void()>> tasks;
    std::mutex queue_mutex;
    std::condition_variable condition;
    std::atomic<bool> stop;
    
public:
    ThreadPool(size_t threads) : stop(false) {
        for (size_t i = 0; i < threads; ++i) {
            workers.emplace_back([this] {
                while (true) {
                    std::function<void()> task;
                    
                    {
                        std::unique_lock<std::mutex> lock(this->queue_mutex);
                        this->condition.wait(lock, [this] { 
                            return this->stop || !this->tasks.empty(); 
                        });
                        
                        if (this->stop && this->tasks.empty()) {
                            return;
                        }
                        
                        task = std::move(this->tasks.front());
                        this->tasks.pop();
                    }
                    
                    task();
                }
            });
        }
    }
    
    template<class F, class... Args>
    void enqueue(F&& f, Args&&... args) {
        auto task = std::bind(std::forward<F>(f), std::forward<Args>(args)...);
        
        {
            std::unique_lock<std::mutex> lock(queue_mutex);
            if (stop) {
                throw std::runtime_error("enqueue on stopped ThreadPool");
            }
            
            tasks.emplace([task]() { task(); });
        }
        
        condition.notify_one();
    }
    
    ~ThreadPool() {
        {
            std::unique_lock<std::mutex> lock(queue_mutex);
            stop = true;
        }
        
        condition.notify_all();
        
        for (std::thread &worker : workers) {
            worker.join();
        }
    }
};

class ThreadedServer {
private:
    int server_socket;
    int port;
    bool running;
    ThreadPool thread_pool;
    
public:
    ThreadedServer(int port = 8080, size_t pool_size = 4) 
        : port(port), running(false), thread_pool(pool_size) {
    }
    
    void start() {
        try {
            // 创建TCP套接字
            server_socket = socket(AF_INET, SOCK_STREAM, 0);
            if (server_socket < 0) {
                throw std::runtime_error("创建套接字失败");
            }
            
            // 设置地址重用
            int opt = 1;
            if (setsockopt(server_socket, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt)) < 0) {
                throw std::runtime_error("设置套接字选项失败");
            }
            
            // 绑定地址
            struct sockaddr_in server_addr;
            memset(&server_addr, 0, sizeof(server_addr));
            server_addr.sin_family = AF_INET;
            server_addr.sin_addr.s_addr = INADDR_ANY;
            server_addr.sin_port = htons(port);
            
            if (bind(server_socket, (struct sockaddr*)&server_addr, sizeof(server_addr)) < 0) {
                throw std::runtime_error("绑定地址失败");
            }
            
            // 开始监听
            if (listen(server_socket, 10) < 0) {
                throw std::runtime_error("监听失败");
            }
            
            running = true;
            std::cout << "多线程服务器启动，监听端口 " << port << std::endl;
            
            // 接受客户端连接
            while (running) {
                struct sockaddr_in client_addr;
                socklen_t client_len = sizeof(client_addr);
                
                int client_socket = accept(server_socket, (struct sockaddr*)&client_addr, &client_len);
                if (client_socket < 0) {
                    if (running) {
                        std::cerr << "接受连接失败" << std::endl;
                    }
                    continue;
                }
                
                // 将客户端处理任务提交到线程池
                thread_pool.enqueue([this, client_socket, client_addr]() {
                    this->handle_client(client_socket, client_addr);
                });
            }
        } catch (const std::exception& e) {
            std::cerr << "服务器启动失败: " << e.what() << std::endl;
        }
    }
    
    void stop() {
        running = false;
        
        if (server_socket >= 0) {
            close(server_socket);
            server_socket = -1;
        }
        
        std::cout << "多线程服务器已停止" << std::endl;
    }
    
private:
    void handle_client(int client_socket, struct sockaddr_in client_addr) {
        try {
            char buffer[1024];
            ssize_t bytes_received;
            
            // 接收客户端数据
            bytes_received = recv(client_socket, buffer, sizeof(buffer) - 1, 0);
            if (bytes_received <= 0) {
                close(client_socket);
                return;
            }
            
            buffer[bytes_received] = '\0';
            std::cout << "收到来自 " << inet_ntoa(client_addr.sin_addr) 
                      << ":" << ntohs(client_addr.sin_port) << " 的数据: " << buffer << std::endl;
            
            // 处理请求并返回响应
            std::string response = "HTTP/1.1 200 OK\r\n"
                                   "Content-Type: text/plain\r\n"
                                   "Connection: close\r\n"
                                   "\r\n"
                                   "Hello from threaded server!";
            
            send(client_socket, response.c_str(), response.length(), 0);
        } catch (const std::exception& e) {
            std::cerr << "处理客户端时出错: " << e.what() << std::endl;
        }
        
        close(client_socket);
    }
};

int main() {
    ThreadedServer server(8080, 8); // 使用8个工作线程
    
    try {
```

#### 4.1.2 Reactor模式

Reactor模式是一种事件驱动的并发模型，通过I/O多路复用机制监听多个事件：

```cpp
#include <iostream>
#include <sys/epoll.h>
#include <vector>
#include <unordered_map>
#include <functional>
#include <thread>
#include <mutex>
#include <sys/socket.h>
#include <netinet/in.h>
#include <unistd.h>
#include <fcntl.h>

class Reactor {
private:
    int epoll_fd;
    std::unordered_map<int, std::function<void()>> handlers;
    std::mutex handlers_mutex;
    bool running;
    std::thread reactor_thread;
    
public:
    Reactor() : epoll_fd(-1), running(false) {
        epoll_fd = epoll_create1(0);
        if (epoll_fd == -1) {
            throw std::runtime_error("创建epoll实例失败");
        }
    }
    
    ~Reactor() {
        stop();
        
        if (epoll_fd != -1) {
            close(epoll_fd);
        }
    }
    
    void register_handler(int fd, std::function<void()> handler, uint32_t events = EPOLLIN) {
        {
            std::lock_guard<std::mutex> lock(handlers_mutex);
            handlers[fd] = handler;
        }
        
        struct epoll_event event;
        event.events = events;
        event.data.fd = fd;
        
        if (epoll_ctl(epoll_fd, EPOLL_CTL_ADD, fd, &event) == -1) {
            throw std::runtime_error("注册事件处理器失败");
        }
    }
    
    void unregister_handler(int fd) {
        {
            std::lock_guard<std::mutex> lock(handlers_mutex);
            handlers.erase(fd);
        }
        
        if (epoll_ctl(epoll_fd, EPOLL_CTL_DEL, fd, nullptr) == -1) {
            std::cerr << "注销事件处理器失败" << std::endl;
        }
    }
    
    void start() {
        running = true;
        reactor_thread = std::thread([this] { this->event_loop(); });
    }
    
    void stop() {
        running = false;
        
        if (reactor_thread.joinable()) {
            reactor_thread.join();
        }
    }
    
private:
    void event_loop() {
        const int MAX_EVENTS = 64;
        struct epoll_event events[MAX_EVENTS];
        
        while (running) {
            int nfds = epoll_wait(epoll_fd, events, MAX_EVENTS, 1000);
            
            if (nfds == -1) {
                if (errno == EINTR) {
                    continue;
                }
                std::cerr << "epoll_wait失败" << std::endl;
                break;
            }
            
            for (int i = 0; i < nfds; ++i) {
                int fd = events[i].data.fd;
                
                std::function<void()> handler;
                {
                    std::lock_guard<std::mutex> lock(handlers_mutex);
                    auto it = handlers.find(fd);
                    if (it != handlers.end()) {
                        handler = it->second;
                    }
                }
                
                if (handler) {
                    try {
                        handler();
                    } catch (const std::exception& e) {
                        std::cerr << "事件处理器异常: " << e.what() << std::endl;
                    }
                }
            }
        }
    }
};

class ReactorServer {
private:
    int server_socket;
    int port;
    bool running;
    Reactor reactor;
    
public:
    ReactorServer(int port = 8080) : port(port), running(false) {
    }
    
    void start() {
        try {
            // 创建TCP套接字
            server_socket = socket(AF_INET, SOCK_STREAM, 0);
            if (server_socket < 0) {
                throw std::runtime_error("创建套接字失败");
            }
            
            // 设置地址重用
            int opt = 1;
            if (setsockopt(server_socket, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt)) < 0) {
                throw std::runtime_error("设置套接字选项失败");
            }
            
            // 设置非阻塞模式
            int flags = fcntl(server_socket, F_GETFL, 0);
            if (flags == -1) {
                throw std::runtime_error("获取套接字标志失败");
            }
            if (fcntl(server_socket, F_SETFL, flags | O_NONBLOCK) == -1) {
                throw std::runtime_error("设置非阻塞模式失败");
            }
            
            // 绑定地址
            struct sockaddr_in server_addr;
            memset(&server_addr, 0, sizeof(server_addr));
            server_addr.sin_family = AF_INET;
            server_addr.sin_addr.s_addr = INADDR_ANY;
            server_addr.sin_port = htons(port);
            
            if (bind(server_socket, (struct sockaddr*)&server_addr, sizeof(server_addr)) < 0) {
                throw std::runtime_error("绑定地址失败");
            }
            
            // 开始监听
            if (listen(server_socket, 10) < 0) {
                throw std::runtime_error("监听失败");
            }
            
            running = true;
            std::cout << "Reactor服务器启动，监听端口 " << port << std::endl;
            
            // 注册服务器套接字到Reactor
            reactor.register_handler(server_socket, [this]() {
                this->accept_connection();
            });
            
            // 启动Reactor事件循环
            reactor.start();
        } catch (const std::exception& e) {
            std::cerr << "服务器启动失败: " << e.what() << std::endl;
        }
    }
    
    void stop() {
        running = false;
        reactor.stop();
        
        if (server_socket >= 0) {
            close(server_socket);
            server_socket = -1;
        }
        
        std::cout << "Reactor服务器已停止" << std::endl;
    }
    
private:
    void accept_connection() {
        struct sockaddr_in client_addr;
        socklen_t client_len = sizeof(client_addr);
        
        int client_socket = accept(server_socket, (struct sockaddr*)&client_addr, &client_len);
        if (client_socket < 0) {
            if (errno != EAGAIN && errno != EWOULDBLOCK) {
                std::cerr << "接受连接失败" << std::endl;
            }
            return;
        }
        
        // 设置客户端套接字为非阻塞模式
        int flags = fcntl(client_socket, F_GETFL, 0);
        if (flags == -1) {
            close(client_socket);
            return;
        }
        if (fcntl(client_socket, F_SETFL, flags | O_NONBLOCK) == -1) {
            close(client_socket);
            return;
        }
        
        std::cout << "接受来自 " << inet_ntoa(client_addr.sin_addr) 
                  << ":" << ntohs(client_addr.sin_port) << " 的连接" << std::endl;
        
        // 注册客户端套接字到Reactor
        reactor.register_handler(client_socket, [this, client_socket, client_addr]() {
            this->handle_client(client_socket, client_addr);
        });
    }
    
    void handle_client(int client_socket, struct sockaddr_in client_addr) {
        char buffer[1024];
        ssize_t bytes_received = recv(client_socket, buffer, sizeof(buffer) - 1, 0);
        
        if (bytes_received <= 0) {
            if (bytes_received == 0) {
                std::cout << "客户端 " << inet_ntoa(client_addr.sin_addr) 
                          << ":" << ntohs(client_addr.sin_port) << " 断开连接" << std::endl;
            } else if (errno != EAGAIN && errno != EWOULDBLOCK) {
                std::cerr << "接收数据失败" << std::endl;
            }
            
            reactor.unregister_handler(client_socket);
            close(client_socket);
            return;
        }
        
        buffer[bytes_received] = '\0';
        std::cout << "收到来自 " << inet_ntoa(client_addr.sin_addr) 
                  << ":" << ntohs(client_addr.sin_port) << " 的数据: " << buffer << std::endl;
        
        // 处理请求并返回响应
        std::string response = "HTTP/1.1 200 OK\r\n"
                               "Content-Type: text/plain\r\n"
                               "Connection: close\r\n"
                               "\r\n"
                               "Hello from Reactor server!";
        
        send(client_socket, response.c_str(), response.length(), 0);
        
        reactor.unregister_handler(client_socket);
        close(client_socket);
    }
};

int main() {
    ReactorServer server(8080);
    
    try {
        server.start();
    } catch (const std::exception& e) {
        std::cerr << "程序异常: " << e.what() << std::endl;
        server.stop();
    }
    
    return 0;
}
```

### 4.2 并发控制与同步

#### 4.2.1 互斥锁与条件变量

互斥锁和条件变量是线程同步的基本工具：

```cpp
#include <iostream>
#include <thread>
#include <mutex>
#include <condition_variable>
#include <queue>
#include <chrono>

class ThreadSafeQueue {
private:
    std::queue<int> data_queue;
    mutable std::mutex mtx;
    std::condition_variable cond;
    
public:
    void push(int value) {
        std::lock_guard<std::mutex> lock(mtx);
        data_queue.push(value);
        cond.notify_one();
    }
    
    bool wait_and_pop(int& value) {
        std::unique_lock<std::mutex> lock(mtx);
        cond.wait(lock, [this] { return !data_queue.empty(); });
        
        if (data_queue.empty()) {
            return false;
        }
        
        value = data_queue.front();
        data_queue.pop();
        return true;
    }
    
    bool try_pop(int& value) {
        std::lock_guard<std::mutex> lock(mtx);
        
        if (data_queue.empty()) {
            return false;
        }
        
        value = data_queue.front();
        data_queue.pop();
        return true;
    }
    
    bool empty() const {
        std::lock_guard<std::mutex> lock(mtx);
        return data_queue.empty();
    }
};

// 生产者-消费者示例
void producer(ThreadSafeQueue& queue, int id) {
    for (int i = 0; i < 10; ++i) {
        int value = id * 100 + i;
        queue.push(value);
        std::cout << "生产者 " << id << " 生产了 " << value << std::endl;
        std::this_thread::sleep_for(std::chrono::milliseconds(100));
    }
}

void consumer(ThreadSafeQueue& queue, int id) {
    int value;
    while (true) {
        if (queue.wait_and_pop(value)) {
            std::cout << "消费者 " << id << " 消费了 " << value << std::endl;
        } else {
            break;
        }
        std::this_thread::sleep_for(std::chrono::milliseconds(150));
    }
}

int main() {
    ThreadSafeQueue queue;
    
    // 创建生产者线程
    std::thread producer1(producer, std::ref(queue), 1);
    std::thread producer2(producer, std::ref(queue), 2);
    
    // 创建消费者线程
    std::thread consumer1(consumer, std::ref(queue), 1);
    std::thread consumer2(consumer, std::ref(queue), 2);
    
    // 等待所有线程完成
    producer1.join();
    producer2.join();
    
    // 等待队列被清空
    while (!queue.empty()) {
        std::this_thread::sleep_for(std::chrono::milliseconds(100));
    }
    
    // 添加终止信号
    queue.push(-1);
    queue.push(-1);
    
    consumer1.join();
    consumer2.join();
    
    return 0;
}
```

#### 4.2.2 读写锁

读写锁允许多个线程同时读取共享数据，但只允许一个线程写入：

```cpp
#include <iostream>
#include <thread>
#include <shared_mutex>
#include <vector>
#include <random>

class ThreadSafeVector {
private:
    std::vector<int> data;
    mutable std::shared_mutex mtx;
    
public:
    void add(int value) {
        std::unique_lock<std::shared_mutex> lock(mtx);
        data.push_back(value);
        std::cout << "添加了 " << value << "，当前大小: " << data.size() << std::endl;
    }
    
    bool contains(int value) const {
        std::shared_lock<std::shared_mutex> lock(mtx);
        return std::find(data.begin(), data.end(), value) != data.end();
    }
    
    size_t size() const {
        std::shared_lock<std::shared_mutex> lock(mtx);
        return data.size();
    }
    
    void print() const {
        std::shared_lock<std::shared_mutex> lock(mtx);
        std::cout << "数据: [";
        for (size_t i = 0; i < data.size(); ++i) {
            if (i > 0) {
                std::cout << ", ";
            }
            std::cout << data[i];
        }
        std::cout << "]" << std::endl;
    }
};

void writer(ThreadSafeVector& vec, int id, int count) {
    std::random_device rd;
    std::mt19937 gen(rd());
    std::uniform_int_distribution<> dis(1, 1000);
    
    for (int i = 0; i < count; ++i) {
        int value = dis(gen);
        vec.add(value);
        std::this_thread::sleep_for(std::chrono::milliseconds(50));
    }
    
    std::cout << "写入线程 " << id << " 完成" << std::endl;
}

void reader(ThreadSafeVector& vec, int id, int count) {
    std::random_device rd;
    std::mt19937 gen(rd());
    std::uniform_int_distribution<> dis(1, 1000);
    
    for (int i = 0; i < count; ++i) {
        int value = dis(gen);
        bool found = vec.contains(value);
        std::cout << "读取线程 " << id << " 查找 " << value 
                  << (found ? " 找到" : " 未找到") << "，当前大小: " << vec.size() << std::endl;
        
        std::this_thread::sleep_for(std::chrono::milliseconds(30));
    }
    
    std::cout << "读取线程 " << id << " 完成" << std::endl;
}

int main() {
    ThreadSafeVector vec;
    
    // 创建写入线程
    std::thread writer1(writer, std::ref(vec), 1, 10);
    std::thread writer2(writer, std::ref(vec), 2, 10);
    
    // 创建读取线程
    std::thread reader1(reader, std::ref(vec), 1, 20);
    std::thread reader2(reader, std::ref(vec), 2, 20);
    std::thread reader3(reader, std::ref(vec), 3, 20);
    
    // 等待所有线程完成
    writer1.join();
    writer2.join();
    reader1.join();
    reader2.join();
    reader3.join();
    
    std::cout << "最终结果: ";
    vec.print();
    
    return 0;
}
```

### 4.3 线程安全的网络编程

#### 4.3.1 线程安全的连接池

连接池是一种常用的资源管理技术，可以避免频繁创建和销毁连接的开销：

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <mutex>
#include <condition_variable>
#include <memory>
#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>
#include <unistd.h>
#include <stdexcept>

class Connection {
private:
    int socket_fd;
    std::string host;
    int port;
    bool connected;
    
public:
    Connection(const std::string& host, int port) 
        : socket_fd(-1), host(host), port(port), connected(false) {
    }
    
    ~Connection() {
        disconnect();
    }
    
    bool connect() {
        if (connected) {
            return true;
        }
        
        try {
            // 创建TCP套接字
            socket_fd = socket(AF_INET, SOCK_STREAM, 0);
            if (socket_fd < 0) {
                throw std::runtime_error("创建套接字失败");
            }
            
            // 设置服务器地址
            struct sockaddr_in server_addr;
            memset(&server_addr, 0, sizeof(server_addr));
            server_addr.sin_family = AF_INET;
            server_addr.sin_port = htons(port);
            
            if (inet_pton(AF_INET, host.c_str(), &server_addr.sin_addr) <= 0) {
                throw std::runtime_error("无效的IP地址");
            }
            
            // 连接到服务器
            if (::connect(socket_fd, (struct sockaddr*)&server_addr, sizeof(server_addr)) < 0) {
                throw std::runtime_error("连接失败");
            }
            
            connected = true;
            return true;
        } catch (const std::exception& e) {
            std::cerr << "连接失败: " << e.what() << std::endl;
            if (socket_fd >= 0) {
                close(socket_fd);
                socket_fd = -1;
            }
            return false;
        }
    }
    
    void disconnect() {
        if (connected && socket_fd >= 0) {
            close(socket_fd);
            socket_fd = -1;
            connected = false;
        }
    }
    
    bool is_connected() const {
        return connected;
    }
    
    bool send_data(const std::string& data) {
        if (!connected || socket_fd < 0) {
            return false;
        }
        
        ssize_t bytes_sent = send(socket_fd, data.c_str(), data.length(), 0);
        return bytes_sent == static_cast<ssize_t>(data.length());
    }
    
    bool receive_data(std::string& data, size_t max_size = 1024) {
        if (!connected || socket_fd < 0) {
            return false;
        }
        
        char buffer[max_size];
        ssize_t bytes_received = recv(socket_fd, buffer, max_size - 1, 0);
        
        if (bytes_received <= 0) {
            connected = false;
            return false;
        }
        
        buffer[bytes_received] = '\0';
        data = buffer;
        return true;
    }
    
    void reset() {
        disconnect();
    }
};

class ConnectionPool {
private:
    std::string host;
    int port;
    size_t max_size;
    std::queue<std::shared_ptr<Connection>> pool;
    std::mutex pool_mutex;
    std::condition_variable pool_condition;
    
public:
    ConnectionPool(const std::string& host, int port, size_t max_size = 10) 
        : host(host), port(port), max_size(max_size) {
    }
    
    std::shared_ptr<Connection> get_connection() {
        std::unique_lock<std::mutex> lock(pool_mutex);
        
        // 等待直到有可用连接或可以创建新连接
        pool_condition.wait(lock, [this] { 
            return !pool.empty() || pool.size() < max_size; 
        });
        
        std::shared_ptr<Connection> conn;
        
        if (!pool.empty()) {
            conn = pool.front();
            pool.pop();
            
            // 检查连接是否仍然有效
            if (!conn->is_connected()) {
                conn->connect();
            }
        } else {
            // 创建新连接
            conn = std::make_shared<Connection>(host, port);
            conn->connect();
        }
        
        return conn;
    }
    
    void return_connection(std::shared_ptr<Connection> conn) {
        if (!conn) {
            return;
        }
        
        std::lock_guard<std::mutex> lock(pool_mutex);
        
        // 如果连接仍然有效且池未满，则放回池中
        if (conn->is_connected() && pool.size() < max_size) {
            pool.push(conn);
        } else {
            // 否则关闭连接
            conn->disconnect();
        }
        
        pool_condition.notify_one();
    }
    
    size_t size() const {
        std::lock_guard<std::mutex> lock(pool_mutex);
        return pool.size();
    }
    
    void clear() {
        std::lock_guard<std::mutex> lock(pool_mutex);
        
        while (!pool.empty()) {
            auto conn = pool.front();
            pool.pop();
            conn->disconnect();
        }
    }
};

// 使用示例
void worker(ConnectionPool& pool, int id) {
    try {
        // 从池中获取连接
        auto conn = pool.get_connection();
        
        std::cout << "工作线程 " << id << " 获取了连接" << std::endl;
        
        // 使用连接发送数据
        std::string request = "Hello from worker " + std::to_string(id);
        if (conn->send_data(request)) {
            std::cout << "工作线程 " << id << " 发送了数据" << std::endl;
            
            // 接收响应
            std::string response;
            if (conn->receive_data(response)) {
                std::cout << "工作线程 " << id << " 收到响应: " << response << std::endl;
            }
        }
        
        // 将连接返回到池中
        pool.return_connection(conn);
        std::cout << "工作线程 " << id << " 返回了连接" << std::endl;
    } catch (const std::exception& e) {
        std::cerr << "工作线程 " << id << " 异常: " << e.what() << std::endl;
    }
}

int main() {
    // 创建连接池
    ConnectionPool pool("localhost", 8080, 5);
    
    // 创建工作线程
    std::vector<std::thread> workers;
    for (int i = 1; i <= 10; ++i) {
        workers.emplace_back(worker, std::ref(pool), i);
    }
    
    // 等待所有工作线程完成
    for (auto& worker : workers) {
        worker.join();
    }
    
    // 清理连接池
    pool.clear();
    
    return 0;
}
```

## 5. 异步网络编程

异步网络编程是一种高效的并发模型，它允许应用程序在等待I/O操作完成时执行其他任务，从而提高系统吞吐量和响应速度。

### 5.1 异步I/O模型

#### 5.1.1 基于回调的异步I/O

回调函数是异步编程中最常见的模式，当I/O操作完成时，系统会调用预先注册的回调函数：

```cpp
#include <iostream>
#include <functional>
#include <vector>
#include <queue>
#include <thread>
#include <mutex>
#include <condition_variable>
#include <sys/epoll.h>
#include <sys/socket.h>
#include <netinet/in.h>
#include <unistd.h>
#include <fcntl.h>
#include <map>

class AsyncIOManager {
private:
    int epoll_fd;
    std::map<int, std::function<void(int, uint32_t)>> handlers;
    std::mutex handlers_mutex;
    std::thread io_thread;
    bool running;
    
public:
    AsyncIOManager() : epoll_fd(-1), running(false) {
        epoll_fd = epoll_create1(0);
        if (epoll_fd == -1) {
            throw std::runtime_error("创建epoll实例失败");
        }
    }
    
    ~AsyncIOManager() {
        stop();
        
        if (epoll_fd != -1) {
            close(epoll_fd);
        }
    }
    
    void register_handler(int fd, std::function<void(int, uint32_t)> handler, uint32_t events = EPOLLIN) {
        {
            std::lock_guard<std::mutex> lock(handlers_mutex);
            handlers[fd] = handler;
        }
        
        struct epoll_event event;
        event.events = events;
        event.data.fd = fd;
        
        if (epoll_ctl(epoll_fd, EPOLL_CTL_ADD, fd, &event) == -1) {
            throw std::runtime_error("注册事件处理器失败");
        }
    }
    
    void unregister_handler(int fd) {
        {
            std::lock_guard<std::mutex> lock(handlers_mutex);
            handlers.erase(fd);
        }
        
        if (epoll_ctl(epoll_fd, EPOLL_CTL_DEL, fd, nullptr) == -1) {
            std::cerr << "注销事件处理器失败" << std::endl;
        }
    }
    
    void start() {
        running = true;
        io_thread = std::thread([this] { this->event_loop(); });
    }
    
    void stop() {
        running = false;
        
        if (io_thread.joinable()) {
            io_thread.join();
        }
    }
    
private:
    void event_loop() {
        const int MAX_EVENTS = 64;
        struct epoll_event events[MAX_EVENTS];
        
        while (running) {
            int nfds = epoll_wait(epoll_fd, events, MAX_EVENTS, 1000);
            
            if (nfds == -1) {
                if (errno == EINTR) {
                    continue;
                }
                std::cerr << "epoll_wait失败" << std::endl;
                break;
            }
            
            for (int i = 0; i < nfds; ++i) {
                int fd = events[i].data.fd;
                uint32_t event_type = events[i].events;
                
                std::function<void(int, uint32_t)> handler;
                {
                    std::lock_guard<std::mutex> lock(handlers_mutex);
                    auto it = handlers.find(fd);
                    if (it != handlers.end()) {
                        handler = it->second;
                    }
                }
                
                if (handler) {
                    try {
                        handler(fd, event_type);
                    } catch (const std::exception& e) {
                        std::cerr << "事件处理器异常: " << e.what() << std::endl;
                    }
                }
            }
        }
    }
};

class AsyncTCPServer {
private:
    int server_socket;
    int port;
    bool running;
    AsyncIOManager io_manager;
    
public:
    AsyncTCPServer(int port = 8080) : port(port), running(false) {
    }
    
    void start() {
        try {
            // 创建TCP套接字
            server_socket = socket(AF_INET, SOCK_STREAM, 0);
            if (server_socket < 0) {
                throw std::runtime_error("创建套接字失败");
            }
            
            // 设置地址重用
            int opt = 1;
            if (setsockopt(server_socket, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt)) < 0) {
                throw std::runtime_error("设置套接字选项失败");
            }
            
            // 设置非阻塞模式
            int flags = fcntl(server_socket, F_GETFL, 0);
            if (flags == -1) {
                throw std::runtime_error("获取套接字标志失败");
            }
            if (fcntl(server_socket, F_SETFL, flags | O_NONBLOCK) == -1) {
                throw std::runtime_error("设置非阻塞模式失败");
            }
            
            // 绑定地址
            struct sockaddr_in server_addr;
            memset(&server_addr, 0, sizeof(server_addr));
            server_addr.sin_family = AF_INET;
            server_addr.sin_addr.s_addr = INADDR_ANY;
            server_addr.sin_port = htons(port);
            
            if (bind(server_socket, (struct sockaddr*)&server_addr, sizeof(server_addr)) < 0) {
                throw std::runtime_error("绑定地址失败");
            }
            
            // 开始监听
            if (listen(server_socket, 10) < 0) {
                throw std::runtime_error("监听失败");
            }
            
            running = true;
            std::cout << "异步TCP服务器启动，监听端口 " << port << std::endl;
            
            // 注册服务器套接字到异步I/O管理器
            io_manager.register_handler(server_socket, [this](int fd, uint32_t events) {
                this->handle_accept(fd, events);
            });
            
            // 启动异步I/O管理器
            io_manager.start();
        } catch (const std::exception& e) {
            std::cerr << "服务器启动失败: " << e.what() << std::endl;
        }
    }
    
    void stop() {
        running = false;
        io_manager.stop();
        
        if (server_socket >= 0) {
            close(server_socket);
            server_socket = -1;
        }
        
        std::cout << "异步TCP服务器已停止" << std::endl;
    }
    
private:
    void handle_accept(int fd, uint32_t events) {
        struct sockaddr_in client_addr;
        socklen_t client_len = sizeof(client_addr);
        
        int client_socket = accept(fd, (struct sockaddr*)&client_addr, &client_len);
        if (client_socket < 0) {
            if (errno != EAGAIN && errno != EWOULDBLOCK) {
                std::cerr << "接受连接失败" << std::endl;
            }
            return;
        }
        
        // 设置客户端套接字为非阻塞模式
        int flags = fcntl(client_socket, F_GETFL, 0);
        if (flags == -1) {
            close(client_socket);
            return;
        }
        if (fcntl(client_socket, F_SETFL, flags | O_NONBLOCK) == -1) {
            close(client_socket);
            return;
        }
        
        std::cout << "接受来自 " << inet_ntoa(client_addr.sin_addr) 
                  << ":" << ntohs(client_addr.sin_port) << " 的连接" << std::endl;
        
        // 注册客户端套接字到异步I/O管理器
        io_manager.register_handler(client_socket, [this, client_socket, client_addr](int fd, uint32_t events) {
            this->handle_client(fd, events, client_socket, client_addr);
        });
    }
    
    void handle_client(int fd, uint32_t events, int client_socket, struct sockaddr_in client_addr) {
        if (events & (EPOLLERR | EPOLLHUP)) {
            std::cout << "客户端 " << inet_ntoa(client_addr.sin_addr) 
                      << ":" << ntohs(client_addr.sin_port) << " 断开连接" << std::endl;
            io_manager.unregister_handler(client_socket);
            close(client_socket);
            return;
        }
        
        if (events & EPOLLIN) {
            char buffer[1024];
            ssize_t bytes_received = recv(client_socket, buffer, sizeof(buffer) - 1, 0);
            
            if (bytes_received <= 0) {
                if (bytes_received == 0) {
                    std::cout << "客户端 " << inet_ntoa(client_addr.sin_addr) 
                              << ":" << ntohs(client_addr.sin_port) << " 断开连接" << std::endl;
                } else if (errno != EAGAIN && errno != EWOULDBLOCK) {
                    std::cerr << "接收数据失败" << std::endl;
                }
                
                io_manager.unregister_handler(client_socket);
                close(client_socket);
                return;
            }
            
            buffer[bytes_received] = '\0';
            std::cout << "收到来自 " << inet_ntoa(client_addr.sin_addr) 
                      << ":" << ntohs(client_addr.sin_port) << " 的数据: " << buffer << std::endl;

            std::string response = "HTTP/1.1 200 OK\r\n"
                                   "Content-Type: text/plain\r\n"
                                   "Connection: close\r\n"
                                   "\r\n"
                                   "Hello from async server!";
            
            send(client_socket, response.c_str(), response.length(), 0);
            
            io_manager.unregister_handler(client_socket);
            close(client_socket);
        }
    }
```

```cpp
                result->set_exception(e);
            }
        }).detach();

    }
```

```cpp
template<typename T>
struct CoroutineTask {
    struct promise_type {
        CoroutineTask get_return_object() {
            return CoroutineTask{std::coroutine_handle<promise_type>::from_promise(*this)};
        }

            return {};

    }

class AsyncCoroutineSocket {
private:
    int socket_fd;
    
public:
    AsyncCoroutineSocket() : socket_fd(-1) {}
    
    ~AsyncCoroutineSocket() {
        if (socket_fd >= 0) {
            close(socket_fd);
        }
    }
    
    bool connect(const std::string& host, int port) {
        try {
            // 创建TCP套接字
            socket_fd = socket(AF_INET, SOCK_STREAM, 0);
            if (socket_fd < 0) {
                throw std::runtime_error("创建套接字失败");
            }
            
            // 设置非阻塞模式
            int flags = fcntl(socket_fd, F_GETFL, 0);
            if (flags == -1) {
                throw std::runtime_error("获取套接字标志失败");
            }
            if (fcntl(socket_fd, F_SETFL, flags | O_NONBLOCK) == -1) {
                throw std::runtime_error("设置非阻塞模式失败");
            }
            
            // 设置服务器地址
            struct sockaddr_in server_addr;
            memset(&server_addr, 0, sizeof(server_addr));
            server_addr.sin_family = AF_INET;
            server_addr.sin_port = htons(port);
            
            if (inet_pton(AF_INET, host.c_str(), &server_addr.sin_addr) <= 0) {
                throw std::runtime_error("无效的IP地址");
            }
            
            // 尝试连接
            int result = ::connect(socket_fd, (struct sockaddr*)&server_addr, sizeof(server_addr));
            if (result < 0) {
                if (errno != EINPROGRESS) {
                    throw std::runtime_error("连接失败");
                }
                
                // 等待连接完成
                fd_set write_fds;
                FD_ZERO(&write_fds);
                FD_SET(socket_fd, &write_fds);
                
                struct timeval timeout;
                timeout.tv_sec = 5;  // 5秒超时
                timeout.tv_usec = 0;
                
                result = select(socket_fd + 1, nullptr, &write_fds, nullptr, &timeout);
                if (result <= 0) {
                    throw std::runtime_error("连接超时");
                }
                
                // 检查连接是否成功
                int error = 0;
                socklen_t len = sizeof(error);
                if (getsockopt(socket_fd, SOL_SOCKET, SO_ERROR, &error, &len) < 0 || error) {
                    throw std::runtime_error("连接失败");
                }
            }
            
            return true;
        } catch (const std::exception& e) {
            std::cerr << "连接异常: " << e.what() << std::endl;
            if (socket_fd >= 0) {
                close(socket_fd);
                socket_fd = -1;
            }
            return false;
        }
    }
    
    CoroutineTask<std::string> receive_coroutine(size_t max_size = 1024) {
        char buffer[max_size];
        ssize_t bytes_received = recv(socket_fd, buffer, max_size - 1, 0);
        
        if (bytes_received < 0) {
            if (errno == EAGAIN || errno == EWOULDBLOCK) {
                // 等待数据可读
                co_await IOAwaiter(socket_fd, EPOLLIN);
                
                // 再次尝试接收
                bytes_received = recv(socket_fd, buffer, max_size - 1, 0);
                if (bytes_received < 0) {
                    throw std::runtime_error("接收数据失败");
                }
            } else {
                throw std::runtime_error("接收数据失败");
            }
        }
        
        buffer[bytes_received] = '\0';
        co_return std::string(buffer);
    }
    
    CoroutineTask<bool> send_coroutine(const std::string& data) {
        ssize_t bytes_sent = send(socket_fd, data.c_str(), data.length(), 0);
        
        if (bytes_sent < 0) {
            if (errno == EAGAIN || errno == EWOULDBLOCK) {
                // 等待可写
                co_await IOAwaiter(socket_fd, EPOLLOUT);
                
                // 再次尝试发送
                bytes_sent = send(socket_fd, data.c_str(), data.length(), 0);
                if (bytes_sent < 0) {
                    throw std::runtime_error("发送数据失败");
                }
            } else {
                throw std::runtime_error("发送数据失败");
            }
        }
        
        if (bytes_sent != static_cast<ssize_t>(data.length())) {
            throw std::runtime_error("数据未完全发送");
        }
        
        co_return true;
    }
};
```

#### 5.3.1 异步HTTP客户端

```cpp

class AsyncHTTPClient {
private:
    std::string host;
    int port;
    std::map<std::string, std::string> default_headers;
    
public:
    AsyncHTTPClient(const std::string& host, int port = 80) 
        : host(host), port(port) {
        // 设置默认请求头
        default_headers["User-Agent"] = "AsyncHTTPClient/1.0";
        default_headers["Connection"] = "close";
        default_headers["Accept"] = "*/*";
    }
    
    void set_header(const std::string& name, const std::string& value) {
        default_headers[name] = value;
    }
    
    std::future<std::string> get_async(const std::string& path) {
        return request_async("GET", path, "");
    }
    
    std::future<std::string> post_async(const std::string& path, const std::string& body) {
        return request_async("POST", path, body);
    }
    
private:
    std::future<std::string> request_async(const std::string& method, const std::string& path, const std::string& body) {
        return std::async(std::launch::async, [this, method, path, body]() {
            try {
                // 解析主机名
                struct hostent* server = gethostbyname(host.c_str());
                if (server == nullptr) {
                    throw std::runtime_error("无法解析主机名");
                }
                
                // 创建TCP套接字
                int sockfd = socket(AF_INET, SOCK_STREAM, 0);
                if (sockfd < 0) {
                    throw std::runtime_error("创建套接字失败");
                }
                
                // 设置服务器地址
                struct sockaddr_in server_addr;
                memset(&server_addr, 0, sizeof(server_addr));
                server_addr.sin_family = AF_INET;
                server_addr.sin_port = htons(port);
                memcpy(&server_addr.sin_addr.s_addr, server->h_addr, server->h_length);
                
                // 连接到服务器
                if (connect(sockfd, (struct sockaddr*)&server_addr, sizeof(server_addr)) < 0) {
                    close(sockfd);
                    throw std::runtime_error("连接失败");
                }
                
                // 构建HTTP请求
                std::stringstream request;
                request << method << " " << path << " HTTP/1.1\r\n";
                request << "Host: " << host << "\r\n";
                
                // 添加请求头
                for (const auto& header : default_headers) {
                    request << header.first << ": " << header.second << "\r\n";
                }
                
                // 如果有请求体，添加Content-Length
                if (!body.empty()) {
                    request << "Content-Length: " << body.length() << "\r\n";
                }
                
                request << "\r\n";
                
                // 如果有请求体，添加到请求中
                if (!body.empty()) {
                    request << body;
                }
                
                std::string request_str = request.str();
                
                // 发送请求
                if (send(sockfd, request_str.c_str(), request_str.length(), 0) < 0) {
                    close(sockfd);
                    throw std::runtime_error("发送请求失败");
                }
                
                // 接收响应
                std::string response;
                char buffer[4096];
                ssize_t bytes_received;
                
                while ((bytes_received = recv(sockfd, buffer, sizeof(buffer) - 1, 0)) > 0) {
                    buffer[bytes_received] = '\0';
                    response += buffer;
                }
                
                if (bytes_received < 0) {
                    close(sockfd);
                    throw std::runtime_error("接收响应失败");
                }
                
                close(sockfd);
                
                // 解析响应，只返回响应体
                std::regex body_regex("\\r\\n\\r\\n(.*)");
                std::smatch match;
                
                if (std::regex_search(response, match, body_regex)) {
                    return match[1].str();
                } else {
                    return response;  // 如果没有找到响应体，返回整个响应
                }
            } catch (const std::exception& e) {
                std::cerr << "HTTP请求失败: " << e.what() << std::endl;
                return "";
            }
        });
    }
};
```

```cpp
                      << ":" << ntohs(client_addr.sin_port) << " 的连接" << std::endl;

            {
                std::lock_guard<std::mutex> lock(client_mutex);
                client_sockets.push_back(client_socket);

            // 发送欢迎消息

                                     std::to_string(client_sockets.size()) + "\n";
            send(client_socket, welcome_msg.c_str(), welcome_msg.length(), 0);
            
            // 通知其他客户端有新用户加入

            std::thread client_thread(&ChatRoomServer::handle_client, this, client_socket, client_addr);

        char buffer[1024];
        std::string client_name = "用户" + std::to_string(client_socket);
        
        // 接收客户端名称
        ssize_t bytes_received = recv(client_socket, buffer, sizeof(buffer) - 1, 0);
        if (bytes_received > 0) {
            buffer[bytes_received] = '\0';
            client_name = std::string(buffer);
            
            // 通知所有客户端用户名
            std::string name_msg = client_name + " 已加入聊天室\n";
            broadcast_message(-1, name_msg);
        }
        
        while (running) {
            memset(buffer, 0, sizeof(buffer));
            bytes_received = recv(client_socket, buffer, sizeof(buffer) - 1, 0);

                // 客户端断开连接
                std::cout << client_name << " 断开连接" << std::endl;

                {
                    std::lock_guard<std::mutex> lock(client_mutex);
                    client_sockets.erase(
                        std::remove(client_sockets.begin(), client_sockets.end(), client_socket),
                        client_sockets.end());
                }
                
                // 通知其他客户端
                std::string leave_msg = client_name + " 离开了聊天室，当前在线人数: " +

            // 广播消息给所有客户端
            broadcast_message(client_socket, message);
        }
    }

        std::lock_guard<std::mutex> lock(client_mutex);
        
        for (int client_socket : client_sockets) {
            if (client_socket != sender_socket) {
                send(client_socket, message.c_str(), message.length(), 0);
            }
        }
    }
```

```cpp
#include <iostream>
#include <string>
#include <thread>
#include <mutex>
#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>
#include <unistd.h>

class ChatRoomClient {
private:
    int client_socket;
    std::string server_ip;
    int server_port;
    std::string username;
    std::atomic<bool> connected;
    std::mutex output_mutex;
    
public:
    ChatRoomClient(const std::string& server_ip, int server_port) 
        : client_socket(-1), server_ip(server_ip), server_port(server_port), connected(false) {
    }
    
    ~ChatRoomClient() {
        disconnect();
    }
    
    bool connect(const std::string& username) {
        try {
            this->username = username;
            
            // 创建TCP套接字
            client_socket = socket(AF_INET, SOCK_STREAM, 0);
            if (client_socket < 0) {
                throw std::runtime_error("创建套接字失败");
            }
            
            // 设置服务器地址
            struct sockaddr_in server_addr;
            memset(&server_addr, 0, sizeof(server_addr));
            server_addr.sin_family = AF_INET;
            server_addr.sin_port = htons(server_port);
            
            if (inet_pton(AF_INET, server_ip.c_str(), &server_addr.sin_addr) <= 0) {
                throw std::runtime_error("无效的IP地址");
            }
            
            // 连接到服务器
            if (::connect(client_socket, (struct sockaddr*)&server_addr, sizeof(server_addr)) < 0) {
                throw std::runtime_error("连接失败");
            }
            
            connected = true;
            
            // 发送用户名
            send(client_socket, username.c_str(), username.length(), 0);
            
            // 启动接收消息的线程
            std::thread receive_thread(&ChatRoomClient::receive_messages, this);
            receive_thread.detach();
            
            return true;
        } catch (const std::exception& e) {
            std::cerr << "连接失败: " << e.what() << std::endl;
            if (client_socket >= 0) {
                close(client_socket);
                client_socket = -1;
            }
            return false;
        }
    }
    
    void disconnect() {
        if (connected) {
            connected = false;
            
            if (client_socket >= 0) {
                close(client_socket);
                client_socket = -1;
            }
            
            std::cout << "已断开与服务器的连接" << std::endl;
        }
    }
    
    void send_message(const std::string& message) {
        if (!connected) {
            std::cerr << "未连接到服务器" << std::endl;
            return;
        }
        
        if (send(client_socket, message.c_str(), message.length(), 0) < 0) {
            std::cerr << "发送消息失败" << std::endl;
            connected = false;
        }
    }
    
    void start_chat() {
        if (!connected) {
            std::cerr << "未连接到服务器" << std::endl;
            return;
        }
        
        std::cout << "开始聊天，输入'/quit'退出" << std::endl;
        
        std::string message;
        while (connected && std::getline(std::cin, message)) {
            if (message == "/quit") {
                break;
            }
            
            send_message(message);
        }
        
        disconnect();
    }
    
private:
    void receive_messages() {
        char buffer[1024];
        
        while (connected) {
            memset(buffer, 0, sizeof(buffer));
            ssize_t bytes_received = recv(client_socket, buffer, sizeof(buffer) - 1, 0);
            
            if (bytes_received <= 0) {
                std::cerr << "与服务器断开连接" << std::endl;
                connected = false;
                break;
            }
            
            buffer[bytes_received] = '\0';
            
            // 使用互斥锁保护输出，避免与用户输入混合
            {
                std::lock_guard<std::mutex> lock(output_mutex);
                std::cout << "\r" << buffer << std::endl;
                std::cout << username << ": ";
                std::cout.flush();
            }
        }
    }
};

    std::string server_ip = "127.0.0.1";

    // 解析命令行参数

        server_ip = argv[1];
    }
    
    if (argc > 2) {
        server_port = std::atoi(argv[2]);
    }
    
    // 获取用户名
    std::cout << "请输入您的用户名: ";
    std::getline(std::cin, username);
    
    if (username.empty()) {
        std::cerr << "用户名不能为空" << std::endl;
        return 1;
    }
    
    // 创建客户端并连接
    ChatRoomClient client(server_ip, server_port);
    
    if (!client.connect(username)) {
        std::cerr << "无法连接到服务器 " << server_ip << ":" << server_port << std::endl;
        return 1;
    }
    
    std::cout << "成功连接到聊天室服务器" << std::endl;
    
    // 开始聊天
    client.start_chat();
    
    return 0;
}
```

```cpp
        }

    void stop() {
        running = false;
        
        // 关闭服务器套接字
        if (server_socket >= 0) {
            close(server_socket);
            server_socket = -1;
        }
        
        std::cout << "文件传输服务器已停止" << std::endl;
    }
    
private:
    void accept_connections() {
        while (running) {
            struct sockaddr_in client_addr;
            socklen_t client_len = sizeof(client_addr);
            
            int client_socket = accept(server_socket, (struct sockaddr*)&client_addr, &client_len);
            if (client_socket < 0) {
                if (running) {
                    std::cerr << "接受连接失败" << std::endl;
                }
                continue;
            }
            
            std::cout << "接受来自 " << inet_ntoa(client_addr.sin_addr) 
                      << ":" << ntohs(client_addr.sin_port) << " 的连接" << std::endl;
            
            // 为每个客户端创建处理线程
            std::thread client_thread(&FileTransferServer::handle_client, this, client_socket, client_addr);
            client_thread.detach();
        }
    }
    
    void handle_client(int client_socket, struct sockaddr_in client_addr) {
        char buffer[4096];
        
        while (running) {
            memset(buffer, 0, sizeof(buffer));
            ssize_t bytes_received = recv(client_socket, buffer, sizeof(buffer) - 1, 0);
            
            if (bytes_received <= 0) {
                std::cout << "客户端断开连接" << std::endl;
                close(client_socket);
                break;
            }
            
            // 解析命令
            std::string command(buffer);
            std::istringstream iss(command);
            std::string cmd;
            iss >> cmd;
            
            if (cmd == "UPLOAD") {
                handle_upload(client_socket, iss);
            } else if (cmd == "DOWNLOAD") {
                handle_download(client_socket, iss);
            } else if (cmd == "LIST") {
                handle_list(client_socket);
            } else if (cmd == "QUIT") {
                std::cout << "客户端请求断开连接" << std::endl;
                close(client_socket);
                break;
            } else {
                std::string response = "ERROR: 未知命令\n";
                send(client_socket, response.c_str(), response.length(), 0);
            }
        }
    }
    
    void handle_upload(int client_socket, std::istringstream& iss) {
        std::string filename;
        long file_size;
        
        iss >> filename >> file_size;
        
        if (filename.empty() || file_size <= 0) {
            std::string response = "ERROR: 无效的文件信息\n";
            send(client_socket, response.c_str(), response.length(), 0);
            return;
        }
        
        // 构建文件路径
        std::string filepath = base_directory + "/" + filename;
        
        // 检查文件是否已存在
        if (std::filesystem::exists(filepath)) {
            std::string response = "ERROR: 文件已存在\n";
            send(client_socket, response.c_str(), response.length(), 0);
            return;
        }
        
        // 发送确认消息
        std::string response = "OK\n";
        send(client_socket, response.c_str(), response.length(), 0);
        
        // 接收文件内容
        std::ofstream file(filepath, std::ios::binary);
        if (!file) {
            std::string error_response = "ERROR: 无法创建文件\n";
            send(client_socket, error_response.c_str(), error_response.length(), 0);
            return;
        }
        
        long total_received = 0;
        char buffer[4096];
        
        while (total_received < file_size) {
            memset(buffer, 0, sizeof(buffer));
            ssize_t bytes_received = recv(client_socket, buffer, sizeof(buffer), 0);
            
            if (bytes_received <= 0) {
                std::cerr << "接收文件数据失败" << std::endl;
                file.close();
                std::filesystem::remove(filepath);
                return;
            }
            
            file.write(buffer, bytes_received);
            total_received += bytes_received;
        }
        
        file.close();
        
        std::cout << "文件上传完成: " << filename << " (" << file_size << " 字节)" << std::endl;
        
        // 发送完成消息
        std::string complete_response = "UPLOAD_COMPLETE\n";
        send(client_socket, complete_response.c_str(), complete_response.length(), 0);
    }
    
    void handle_download(int client_socket, std::istringstream& iss) {
        std::string filename;
        iss >> filename;
        
        if (filename.empty()) {
            std::string response = "ERROR: 无效的文件名\n";
            send(client_socket, response.c_str(), response.length(), 0);
            return;
        }
        
        // 构建文件路径
        std::string filepath = base_directory + "/" + filename;
        
        // 检查文件是否存在
        if (!std::filesystem::exists(filepath)) {
            std::string response = "ERROR: 文件不存在\n";
            send(client_socket, response.c_str(), response.length(), 0);
            return;
        }
        
        // 获取文件大小
        struct stat file_stat;
        if (stat(filepath.c_str(), &file_stat) != 0) {
            std::string response = "ERROR: 无法获取文件信息\n";
            send(client_socket, response.c_str(), response.length(), 0);
            return;
        }
        
        long file_size = file_stat.st_size;
        
        // 发送文件大小
        std::string size_response = "SIZE " + std::to_string(file_size) + "\n";
        send(client_socket, size_response.c_str(), size_response.length(), 0);
        
        // 等待客户端确认
        char buffer[256];
        memset(buffer, 0, sizeof(buffer));
        ssize_t bytes_received = recv(client_socket, buffer, sizeof(buffer) - 1, 0);
        if (bytes_received <= 0 || std::string(buffer) != "READY\n") {
            std::cerr << "客户端未准备好接收文件" << std::endl;
            return;
        }
        
        // 发送文件内容
        std::ifstream file(filepath, std::ios::binary);
        if (!file) {
            std::string error_response = "ERROR: 无法打开文件\n";
            send(client_socket, error_response.c_str(), error_response.length(), 0);
            return;
        }
        
        char file_buffer[4096];
        while (file.read(file_buffer, sizeof(file_buffer))) {
            send(client_socket, file_buffer, file.gcount(), 0);
        }
        
        // 发送剩余字节
        if (file.gcount() > 0) {
            send(client_socket, file_buffer, file.gcount(), 0);
        }
        
        file.close();
        
        std::cout << "文件下载完成: " << filename << " (" << file_size << " 字节)" << std::endl;
    }
    
    void handle_list(int client_socket) {
        std::string response = "FILES\n";
        
        try {
            for (const auto& entry : std::filesystem::directory_iterator(base_directory)) {
                if (entry.is_regular_file()) {
                    std::string filename = entry.path().filename().string();
```

```cpp
class EfficientBuffer {
private:
    char* buffer;
    size_t capacity;
    size_t size;
    size_t read_pos;
    size_t write_pos;
    
public:
    EfficientBuffer(size_t capacity = 8192) 
        : capacity(capacity), size(0), read_pos(0), write_pos(0) {
        buffer = new char[capacity];
    }
    
    ~EfficientBuffer() {
        delete[] buffer;
    }
    
    // 写入数据到缓冲区
    size_t write(const char* data, size_t len) {
        // 检查是否有足够空间
        if (available_space() < len) {
            // 尝试移动数据以释放空间
            compact();
            
            // 如果仍然没有足够空间，返回0
            if (available_space() < len) {
                return 0;
            }
        }
        
        // 写入数据
        memcpy(buffer + write_pos, data, len);
        write_pos += len;
        size += len;
        
        return len;
    }
    
    // 从缓冲区读取数据
    size_t read(char* data, size_t len) {
        size_t readable = available_read();
        size_t to_read = (readable < len) ? readable : len;
        
        if (to_read > 0) {
            memcpy(data, buffer + read_pos, to_read);
            read_pos += to_read;
            size -= to_read;
        }
        
        return to_read;
    }
    
    // 获取可读字节数
    size_t available_read() const {
        return size;
    }
    
    // 获取可用空间
    size_t available_space() const {
        return capacity - size;
    }
    
    // 压缩缓冲区，将未读数据移到缓冲区开始
    void compact() {
        if (read_pos > 0) {
            memmove(buffer, buffer + read_pos, size);
            write_pos -= read_pos;
            read_pos = 0;
        }
    }
    
    // 重置缓冲区
    void reset() {
        size = 0;
        read_pos = 0;
        write_pos = 0;
    }
    
    // 获取缓冲区指针（用于直接写入）
    char* get_write_ptr() {
        return buffer + write_pos;
    }
    
    // 更新写入位置
    void advance_write_pos(size_t len) {
        if (len <= available_space()) {
            write_pos += len;
            size += len;
        }
    }
};
```

```cpp
    static ssize_t zero_copy_file_transfer(int out_fd, const char* file_path) {
        int fd = open(file_path, O_RDONLY);
        if (fd < 0) {
            perror("打开文件失败");
            return -1;
        }
        
        // 获取文件大小
        struct stat file_stat;
        if (fstat(fd, &file_stat) < 0) {
            perror("获取文件信息失败");
            close(fd);
            return -1;
        }
        
        off_t offset = 0;
        ssize_t sent = 0;
        
        // 使用sendfile进行零拷贝传输
        while (offset < file_stat.st_size) {
            sent = sendfile(out_fd, fd, &offset, file_stat.st_size - offset);
            if (sent < 0) {
                perror("sendfile失败");
                close(fd);
                return -1;
            }
        }
        
        close(fd);
        return file_stat.st_size;
    }

    static ssize_t mmap_file_transfer(int out_fd, const char* file_path) {
        int fd = open(file_path, O_RDONLY);
        if (fd < 0) {
            perror("打开文件失败");
            return -1;
        }
        
        // 获取文件大小
        struct stat file_stat;
        if (fstat(fd, &file_stat) < 0) {
            perror("获取文件信息失败");
            close(fd);
            return -1;
        }
        
        // 映射文件到内存
        void* mapped = mmap(nullptr, file_stat.st_size, PROT_READ, MAP_PRIVATE, fd, 0);
        if (mapped == MAP_FAILED) {
            perror("mmap失败");
            close(fd);
            return -1;
        }
        
        // 发送数据
        ssize_t sent = send(out_fd, mapped, file_stat.st_size, 0);
        if (sent < 0) {
            perror("发送失败");
        }
        
        // 取消映射
        munmap(mapped, file_stat.st_size);
        close(fd);
        
        return sent;
    }

    static ssize_t vector_io(int fd, const std::vector<std::string>& chunks) {
        // 准备iovec结构体数组
        std::vector<iovec> iov;
        iov.reserve(chunks.size());
        
        for (const auto& chunk : chunks) {
            iovec item;
            item.iov_base = const_cast<char*>(chunk.c_str());
            item.iov_len = chunk.length();
            iov.push_back(item);
        }
        
        // 使用writev一次性发送所有数据块
        ssize_t total_sent = writev(fd, iov.data(), iov.size());
        if (total_sent < 0) {
            perror("writev失败");
        }
        
        return total_sent;
    }

    static ssize_t vector_read(int fd, std::vector<std::string>& buffers, size_t max_size = 4096) {
        // 准备iovec结构体数组
        std::vector<iovec> iov;
        std::vector<std::unique_ptr<char[]>> temp_buffers;
        
        for (auto& buffer : buffers) {
            buffer.resize(max_size);
            iovec item;
            item.iov_base = &buffer[0];
            item.iov_len = max_size;
            iov.push_back(item);
        }
        
        // 使用readv一次性读取数据到多个缓冲区
        ssize_t total_read = readv(fd, iov.data(), iov.size());
        if (total_read < 0) {
            perror("readv失败");
            return -1;
        }
        
        // 调整每个缓冲区的大小为实际读取的数据量
        size_t remaining = total_read;
        for (size_t i = 0; i < buffers.size() && remaining > 0; ++i) {
            size_t read_size = (remaining < max_size) ? remaining : max_size;
            buffers[i].resize(read_size);
            remaining -= read_size;
        }
        
        return total_read;
    }
};

                throw std::runtime_error("监听失败");

            std::cerr << "服务器启动失败: " << e.what() << std::endl;
```

```cpp
class Connection {

// 连接池类
class ConnectionPool {
private:
    std::string host;
    int port;
    size_t max_connections;
    size_t min_connections;
    std::queue<std::unique_ptr<Connection>> available_connections;
    std::vector<std::unique_ptr<Connection>> all_connections;
    std::mutex pool_mutex;
    std::condition_variable pool_condition;
    std::atomic<bool> shutdown;
    std::thread maintenance_thread;
    
public:
    ConnectionPool(const std::string& host, int port, size_t min_connections = 5, size_t max_connections = 20) 
        : host(host), port(port), min_connections(min_connections), max_connections(max_connections), shutdown(false) {
        
        // 创建初始连接
        for (size_t i = 0; i < min_connections; ++i) {
            auto conn = std::make_unique<Connection>(host, port);
            if (conn->is_connected()) {
                available_connections.push(std::move(conn));
                all_connections.push_back(std::make_unique<Connection>(host, port));
            }
        }
        
        // 启动维护线程
        maintenance_thread = std::thread(&ConnectionPool::maintenance_worker, this);
    }
    
    ~ConnectionPool() {
        shutdown = true;
        pool_condition.notify_all();
        
        if (maintenance_thread.joinable()) {
            maintenance_thread.join();
        }
        
        // 关闭所有连接
        std::lock_guard<std::mutex> lock(pool_mutex);
        all_connections.clear();
        while (!available_connections.empty()) {
            available_connections.pop();
        }
    }
    
    // 获取连接
    std::unique_ptr<Connection> get_connection(int timeout_ms = 5000) {
        std::unique_lock<std::mutex> lock(pool_mutex);
        
        // 等待可用连接或超时
        auto timeout = std::chrono::steady_clock::now() + std::chrono::milliseconds(timeout_ms);
        
        if (pool_condition.wait_until(lock, timeout, [this] { 
            return !available_connections.empty() || shutdown; 
        })) {
            if (shutdown) {
                return nullptr;
            }
            
            auto conn = std::move(available_connections.front());
            available_connections.pop();
            conn->set_in_use(true);
            return conn;
        }
        
        // 超时，尝试创建新连接
        if (all_connections.size() < max_connections) {
            auto new_conn = std::make_unique<Connection>(host, port);
            if (new_conn->is_connected()) {
                all_connections.push_back(std::make_unique<Connection>(host, port));
                new_conn->set_in_use(true);
                return new_conn;
            }
        }
        
        return nullptr;
    }
    
    // 归还连接
    void return_connection(std::unique_ptr<Connection> conn) {
        if (!conn) {
            return;
        }
        
        std::lock_guard<std::mutex> lock(pool_mutex);
        
        // 检查连接是否仍然有效
        if (conn->is_connected()) {
            conn->set_in_use(false);
            available_connections.push(std::move(conn));
        } else {
            // 连接无效，创建新连接替换
            auto new_conn = std::make_unique<Connection>(host, port);
            if (new_conn->is_connected()) {
                available_connections.push(std::move(new_conn));
            }
        }
        
        pool_condition.notify_one();
    }
    
    // 获取连接池状态
    struct PoolStatus {
        size_t total_connections;
        size_t available_connections;
        size_t in_use_connections;
    };
    
    PoolStatus get_status() const {
        std::lock_guard<std::mutex> lock(pool_mutex);
        
        PoolStatus status;
        status.total_connections = all_connections.size();
        status.available_connections = available_connections.size();
        status.in_use_connections = status.total_connections - status.available_connections;
        
        return status;
    }
    
private:
    // 维护工作线程
    void maintenance_worker() {
        while (!shutdown) {
            std::unique_lock<std::mutex> lock(pool_mutex);
            
            // 等待一段时间或直到关闭
            pool_condition.wait_for(lock, std::chrono::seconds(30), [this] { return shutdown; });
            
            if (shutdown) {
                break;
            }
            
            // 检查并关闭空闲时间过长的连接
            auto now = std::chrono::steady_clock::now();
            auto idle_threshold = std::chrono::minutes(5);
            
            std::queue<std::unique_ptr<Connection>> temp_queue;
            
            while (!available_connections.empty()) {
                auto conn = std::move(available_connections.front());
                available_connections.pop();
                
                // 如果连接空闲时间过长且总连接数大于最小连接数，则关闭
                if (now - conn->get_last_used() > idle_threshold && 
                    all_connections.size() > min_connections) {
                    // 连接将被自动关闭（析构函数）
                    std::cout << "关闭空闲连接" << std::endl;
                } else {
                    temp_queue.push(std::move(conn));
                }
            }
            
            // 将剩余连接放回队列
            available_connections = std::move(temp_queue);
            
            // 确保至少有最小数量的连接
            while (available_connections.size() < min_connections && 
                   all_connections.size() < max_connections) {
                auto new_conn = std::make_unique<Connection>(host, port);
                if (new_conn->is_connected()) {
                    available_connections.push(std::move(new_conn));
                    all_connections.push_back(std::make_unique<Connection>(host, port));
                } else {
                    break;
                }
            }
            
            lock.unlock();
            
            // 打印连接池状态
            auto status = get_status();
            std::cout << "连接池状态 - 总连接数: " << status.total_connections 
                      << ", 可用连接数: " << status.available_connections
                      << ", 使用中连接数: " << status.in_use_connections << std::endl;
        }
    }
};
```

```cpp
class PacketAnalyzer {
private:
    pcap_t* handle;
    char errbuf[PCAP_ERRBUF_SIZE];
    std::string device;
    
public:
    PacketAnalyzer(const std::string& device = "") : handle(nullptr), device(device) {
        if (device.empty()) {
            // 查找默认网络设备
            device = pcap_lookupdev(errbuf);

                return;

            return;

        std::cout << "开始监听设备: " << device << std::endl;
    }
    
    ~PacketAnalyzer() {
        if (handle) {
            pcap_close(handle);
        }
    }
    
    // 设置过滤器
    bool set_filter(const std::string& filter_expr) {
        struct bpf_program fp;
        
        // 编译过滤器
        if (pcap_compile(handle, &fp, filter_expr.c_str(), 1, PCAP_NETMASK_UNKNOWN) == -1) {
            std::cerr << "无法编译过滤器 '" << filter_expr << "': " << pcap_geterr(handle) << std::endl;
            return false;
        }
        
        // 设置过滤器
        if (pcap_setfilter(handle, &fp) == -1) {
            std::cerr << "无法设置过滤器: " << pcap_geterr(handle) << std::endl;
            pcap_freecode(&fp);
            return false;

        pcap_freecode(&fp);

        std::cout << "开始捕获数据包..." << std::endl;
        
        // 开始循环捕获
        pcap_loop(handle, packet_count, packet_handler, reinterpret_cast<u_char*>(this));
    }
    
    // 停止捕获
    void stop_capture() {
        pcap_breakloop(handle);
    }
    
private:
    // 数据包处理回调函数
    static void packet_handler(u_char* user_data, const struct pcap_pkthdr* pkthdr, const u_char* packet) {
        PacketAnalyzer* analyzer = reinterpret_cast<PacketAnalyzer*>(user_data);
        analyzer->process_packet(pkthdr, packet);
    }

    void process_packet(const struct pcap_pkthdr* pkthdr, const u_char* packet) {
        // 解析以太网帧
        const struct ether_header* ethernet_header;
        ethernet_header = reinterpret_cast<const struct ether_header*>(packet);
        
        // 获取以太网类型
        u_short ethernet_type = ntohs(ethernet_header->ether_type);
        
        // 打印基本信息
        std::cout << "[" << pkthdr->ts.tv_sec << "." << pkthdr->ts.tv_usec << "] ";
        std::cout << "长度: " << pkthdr->len << " 字节";
        
        // 解析源和目标MAC地址
        std::cout << ", 源MAC: " << mac_to_string(ethernet_header->ether_shost);
        std::cout << ", 目标MAC: " << mac_to_string(ethernet_header->ether_dhost);
        
        // 根据以太网类型解析上层协议
        if (ethernet_type == ETHERTYPE_IP) {
            // 解析IP数据包
            const struct ip* ip_header;
            ip_header = reinterpret_cast<const struct ip*>(packet + sizeof(struct ether_header));
            
            // 获取IP头长度
            int ip_header_len = ip_header->ip_hl * 4;
            
            // 打印IP信息
            std::cout << ", 源IP: " << inet_ntoa(ip_header->ip_src);
            std::cout << ", 目标IP: " << inet_ntoa(ip_header->ip_dst);
            
            // 根据IP协议类型解析传输层协议
            if (ip_header->ip_p == IPPROTO_TCP) {
                // 解析TCP段
                const struct tcphdr* tcp_header;
                tcp_header = reinterpret_cast<const struct tcphdr*>(
                    reinterpret_cast<const u_char*>(ip_header) + ip_header_len);
                
                std::cout << ", 协议: TCP";
                std::cout << ", 源端口: " << ntohs(tcp_header->th_sport);
                std::cout << ", 目标端口: " << ntohs(tcp_header->th_dport);
                
                // 检查TCP标志
                std::cout << ", 标志: ";
                if (tcp_header->th_flags & TH_FIN) std::cout << "FIN ";
                if (tcp_header->th_flags & TH_SYN) std::cout << "SYN ";
                if (tcp_header->th_flags & TH_RST) std::cout << "RST ";
                if (tcp_header->th_flags & TH_PUSH) std::cout << "PSH ";
                if (tcp_header->th_flags & TH_ACK) std::cout << "ACK ";
                if (tcp_header->th_flags & TH_URG) std::cout << "URG ";
                
            } else if (ip_header->ip_p == IPPROTO_UDP) {
                // 解析UDP数据报
                const struct udphdr* udp_header;
                udp_header = reinterpret_cast<const struct udphdr*>(

            } else {

    }
};
```

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <chrono>
#include <thread>
#include <atomic>
#include <sys/socket.h>
#include <netinet/in.h>

// Ping工具类
class PingTool {
private:
    std::string target_host;
    int packet_size;
    int timeout_ms;
    int count;
    
public:
    PingTool(const std::string& host, int size = 56, int timeout = 1000, int count = 4) 
        : target_host(host), packet_size(size), timeout_ms(timeout), count(count) {}
    
    // 执行ping测试
    void execute() {
        std::cout << "PING " << target_host << " (" << target_host << "): " 
                  << packet_size << " bytes of data." << std::endl;
        
        // 解析主机名
        struct hostent* host_entity = gethostbyname(target_host.c_str());
        if (!host_entity) {
            std::cerr << "无法解析主机名: " << target_host << std::endl;
            return;
        }
        
        struct in_addr** addr_list = reinterpret_cast<struct in_addr**>(host_entity->h_addr_list);
        if (!addr_list[0]) {
            std::cerr << "无法获取主机地址" << std::endl;
            return;
        }
        
        std::string ip_address = inet_ntoa(*addr_list[0]);
        std::cout << "解析到IP地址: " << ip_address << std::endl;
        
        // 创建原始套接字（需要root权限）
        int sock = socket(AF_INET, SOCK_RAW, IPPROTO_ICMP);
        if (sock < 0) {
            std::cerr << "无法创建原始套接字，可能需要root权限" << std::endl;
            // 尝试使用系统ping命令作为替代
            execute_system_ping();
            return;
        }
        
        // 设置超时
        struct timeval tv;
        tv.tv_sec = timeout_ms / 1000;
        tv.tv_usec = (timeout_ms % 1000) * 1000;
        setsockopt(sock, SOL_SOCKET, SO_RCVTIMEO, &tv, sizeof(tv));
        
        // 执行ping测试
        std::vector<int> rtt_values;
        int received = 0;
        
        for (int i = 0; i < count; ++i) {
            // 发送ICMP回显请求
            if (send_echo_request(sock, ip_address, i + 1)) {
                // 接收ICMP回显应答
                int rtt = receive_echo_reply(sock, i + 1);
                if (rtt >= 0) {
                    rtt_values.push_back(rtt);
                    received++;
                    std::cout << "来自 " << ip_address << " 的回显: icmp_seq=" << i + 1 
                              << " ttl=64 time=" << rtt << "ms" << std::endl;
                } else {
                    std::cout << "请求超时" << std::endl;
                }
            }
            
            // 等待一段时间再发送下一个请求
            if (i < count - 1) {
                std::this_thread::sleep_for(std::chrono::seconds(1));
            }
        }
        
        close(sock);
        
        // 打印统计信息
        print_statistics(rtt_values, received, count);
    }
    
private:
    // 发送ICMP回显请求
    bool send_echo_request(int sock, const std::string& ip_address, int seq) {
        // 构造ICMP数据包
        struct icmp icmp_packet;
        memset(&icmp_packet, 0, sizeof(icmp_packet));
        
        icmp_packet.icmp_type = ICMP_ECHO;
        icmp_packet.icmp_code = 0;
        icmp_packet.icmp_cksum = 0;
        icmp_packet.icmp_id = htons(getpid() & 0xFFFF);
        icmp_packet.icmp_seq = htons(seq);
        
        // 填充数据部分
        char data[packet_size];
        memset(data, 0, packet_size);
        memcpy(&icmp_packet.icmp_data, data, packet_size);
        
        // 计算校验和
        icmp_packet.icmp_cksum = calculate_checksum(&icmp_packet, sizeof(icmp_packet) + packet_size);
        
        // 设置目标地址
        struct sockaddr_in dest_addr;
        memset(&dest_addr, 0, sizeof(dest_addr));
        dest_addr.sin_family = AF_INET;
        dest_addr.sin_addr.s_addr = inet_addr(ip_address.c_str());
        
        // 发送数据包
        ssize_t sent = sendto(sock, &icmp_packet, sizeof(icmp_packet) + packet_size, 0,
                             reinterpret_cast<struct sockaddr*>(&dest_addr), sizeof(dest_addr));
        
        return sent > 0;
    }
    
    // 接收ICMP回显应答
    int receive_echo_reply(int sock, int expected_seq) {
        char buffer[1024];
        struct sockaddr_in from_addr;
        socklen_t from_len = sizeof(from_addr);
        
        auto start_time = std::chrono::steady_clock::now();
        
        // 接收数据包
        ssize_t received = recvfrom(sock, buffer, sizeof(buffer), 0,
                                   reinterpret_cast<struct sockaddr*>(&from_addr), &from_len);
        
        auto end_time = std::chrono::steady_clock::now();
        auto duration = std::chrono::duration_cast<std::chrono::milliseconds>(end_time - start_time);
        
        if (received < 0) {
            return -1; // 超时或错误
        }
        
        // 解析IP头
        struct ip* ip_header = reinterpret_cast<struct ip*>(buffer);
        int ip_header_len = ip_header->ip_hl * 4;
        
        // 解析ICMP头
        struct icmp* icmp_packet = reinterpret_cast<struct icmp*>(buffer + ip_header_len);
        
        // 检查是否是我们期望的回显应答
        if (icmp_packet->icmp_type == ICMP_ECHOREPLY &&
            ntohs(icmp_packet->icmp_id) == (getpid() & 0xFFFF) &&
            ntohs(icmp_packet->icmp_seq) == expected_seq) {
            return static_cast<int>(duration.count());
        }
        
        return -1; // 不是我们期望的包
    }
    
    // 计算校验和
    unsigned short calculate_checksum(void* data, int len) {
        unsigned short* buf = static_cast<unsigned short*>(data);
        unsigned int sum = 0;
        
        while (len > 1) {
            sum += *buf++;
            len -= 2;
        }
        
        if (len == 1) {
            sum += *(unsigned char*)buf;
        }
        
        sum = (sum >> 16) + (sum & 0xFFFF);
        sum += (sum >> 16);
        
        return ~sum;
    }
    
    // 使用系统ping命令作为替代
    void execute_system_ping() {
        std::string command = "ping -c " + std::to_string(count) + " " + target_host;
        system(command.c_str());
    }
    
    // 打印统计信息
    void print_statistics(const std::vector<int>& rtt_values, int received, int sent) {
        std::cout << "\n--- " << target_host << " ping 统计 ---" << std::endl;
        std::cout << sent << " 个包已发送, " << received << " 个已接收, ";
        
        if (sent > 0) {
            float loss_percent = 100.0 * (sent - received) / sent;
            std::cout << loss_percent << "% 包丢失" << std::endl;
        } else {
            std::cout << "100% 包丢失" << std::endl;
        }
        
        if (!rtt_values.empty()) {
            int min_rtt = *std::min_element(rtt_values.begin(), rtt_values.end());
            int max_rtt = *std::max_element(rtt_values.begin(), rtt_values.end());
            
            long long sum_rtt = 0;
            for (int rtt : rtt_values) {
                sum_rtt += rtt;
            }

class PortScanner {
private:
    std::string target_host;
    std::vector<int> ports;
    int timeout_ms;
    
public:
    PortScanner(const std::string& host, const std::vector<int>& port_list, int timeout = 1000) 
        : target_host(host), ports(port_list), timeout_ms(timeout) {}
    
    // 执行端口扫描
    void execute() {
        std::cout << "扫描主机 " << target_host << " 的端口..." << std::endl;
        
        // 解析主机名
        struct hostent* host_entity = gethostbyname(target_host.c_str());
        if (!host_entity) {
            std::cerr << "无法解析主机名: " << target_host << std::endl;
            return;
        }
        
        struct in_addr** addr_list = reinterpret_cast<struct in_addr**>(host_entity->h_addr_list);
        if (!addr_list[0]) {
            std::cerr << "无法获取主机地址" << std::endl;
            return;
        }
        
        std::string ip_address = inet_ntoa(*addr_list[0]);
        std::cout << "目标IP地址: " << ip_address << std::endl;
        
        // 扫描端口
        std::vector<int> open_ports;
        
        for (int port : ports) {
            if (scan_port(ip_address, port)) {
                open_ports.push_back(port);
                std::cout << "端口 " << port << " 开放" << std::endl;
            } else {
                std::cout << "端口 " << port << " 关闭" << std::endl;
            }
        }
        
        // 打印扫描结果
        std::cout << "\n扫描完成。开放端口: ";
        for (size_t i = 0; i < open_ports.size(); ++i) {
            std::cout << open_ports[i];
            if (i < open_ports.size() - 1) {
                std::cout << ", ";
            }
        }
        std::cout << std::endl;
    }
    
private:
    // 扫描单个端口
    bool scan_port(const std::string& ip_address, int port) {
        // 创建套接字
        int sock = socket(AF_INET, SOCK_STREAM, 0);
        if (sock < 0) {
            return false;
        }
        
        // 设置非阻塞模式
        int flags = fcntl(sock, F_GETFL, 0);
        fcntl(sock, F_SETFL, flags | O_NONBLOCK);
        
        // 设置目标地址
        struct sockaddr_in server_addr;
        memset(&server_addr, 0, sizeof(server_addr));
        server_addr.sin_family = AF_INET;
        server_addr.sin_port = htons(port);
        server_addr.sin_addr.s_addr = inet_addr(ip_address.c_str());
        
        // 尝试连接
        connect(sock, reinterpret_cast<struct sockaddr*>(&server_addr), sizeof(server_addr));
        
        // 使用select检查连接状态
        fd_set fdset;
        FD_ZERO(&fdset);
        FD_SET(sock, &fdset);
        
        struct timeval tv;
        tv.tv_sec = timeout_ms / 1000;
        tv.tv_usec = (timeout_ms % 1000) * 1000;
        
        int res = select(sock + 1, NULL, &fdset, NULL, &tv);
        
        bool is_open = false;
        if (res > 0) {
            int so_error;
            socklen_t len = sizeof(so_error);
            getsockopt(sock, SOL_SOCKET, SO_ERROR, &so_error, &len);
            
            if (so_error == 0) {
                is_open = true;
            }
        }
        
        close(sock);
        return is_open;
    }
};
```

```cpp
        std::mt19937 gen(rd());
        std::uniform_int_distribution<> dis(0, 255);
        
        for (int i = 0; i < buffer_size; ++i) {
            buffer[i] = static_cast<char>(dis(gen));
        }
        
        // 启动发送线程
        std::thread sender_thread([&]() {
            while (test_running) {
                ssize_t sent = send(client_socket, buffer.data(), buffer_size, 0);
                if (sent > 0) {
                    bytes_sent += sent;
                } else if (sent < 0) {
                    std::cerr << "发送数据失败" << std::endl;
                    break;
                }
            }
        });
        
        // 启动接收线程
        std::thread receiver_thread([&]() {
            std::vector<char> recv_buffer(buffer_size);
            while (test_running) {
                ssize_t received = recv(client_socket, recv_buffer.data(), buffer_size, 0);
                if (received > 0) {
                    bytes_received += received;
                } else if (received < 0) {
                    std::cerr << "接收数据失败" << std::endl;
                    break;
                } else {
                    // 连接关闭
                    test_running = false;
                    break;
                }
            }
        });
        
        // 等待测试完成
        receiver_thread.join();
        test_running = false;
        sender_thread.join();
        
        std::cout << "客户端测试完成" << std::endl;
        std::cout << "发送: " << bytes_sent << " 字节" << std::endl;
        std::cout << "接收: " << bytes_received << " 字节" << std::endl;
        
        close(client_socket);
    }
};
```

#### 8.2.2 高级TCP服务器

下面是一个更高级的TCP服务器实现，支持多线程连接池和消息广播：

```cpp
#include <iostream>
#include <sys/socket.h>
#include <netinet/in.h>
#include <unistd.h>
#include <string>
#include <thread>
#include <vector>
#include <queue>
#include <mutex>
#include <condition_variable>
#include <map>
#include <json/json.h> // 需要安装jsoncpp库
#include <ctime>
#include <memory>

class AdvancedTCPServer {
private:
    std::string host;
    int port;
    int max_threads;
    int server_socket;
    bool running;
    std::map<int, std::pair<int, struct sockaddr_in>> clients; // {client_id: (socket, address)}
    int client_id_counter;
    std::queue<std::tuple<std::string, int, Json::Value>> message_queue; // (task_type, client_id, data)
    std::vector<std::thread> thread_pool;
    std::mutex clients_mutex;
    std::mutex queue_mutex;
    std::condition_variable queue_cv;
    
public:
    AdvancedTCPServer(std::string host = "0.0.0.0", int port = 8080, int max_threads = 10) 
        : host(host), port(port), max_threads(max_threads), server_socket(-1), running(false), client_id_counter(0) {}
    
    ~AdvancedTCPServer() {
        stop();
    }
    
    void start() {
        try {
            // 创建TCP套接字
            server_socket = socket(AF_INET, SOCK_STREAM, 0);
            if (server_socket < 0) {
                throw std::runtime_error("创建套接字失败");
            }
            
            // 设置地址重用
            int opt = 1;
            if (setsockopt(server_socket, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt)) < 0) {
                throw std::runtime_error("设置套接字选项失败");
            }
            
            // 绑定地址
            struct sockaddr_in server_addr;
            server_addr.sin_family = AF_INET;
            server_addr.sin_addr.s_addr = INADDR_ANY;
            server_addr.sin_port = htons(port);
            
            if (bind(server_socket, (struct sockaddr*)&server_addr, sizeof(server_addr)) < 0) {
                throw std::runtime_error("绑定地址失败");
            }
            
            // 开始监听
            if (listen(server_socket, 5) < 0) {
                throw std::runtime_error("监听失败");
            }
            
            running = true;
            std::cout << "高级TCP服务器启动，监听 " << host << ":" << port << std::endl;
            
            // 启动工作线程
            for (int i = 0; i < max_threads; i++) {
                thread_pool.emplace_back(&AdvancedTCPServer::worker, this);
            }
            
            // 启动广播线程
            thread_pool.emplace_back(&AdvancedTCPServer::broadcast_messages, this);
            
            // 接受客户端连接
            while (running) {
                struct sockaddr_in client_addr;
                socklen_t client_len = sizeof(client_addr);
                
                int client_socket = accept(server_socket, (struct sockaddr*)&client_addr, &client_len);
                if (client_socket < 0) {
                    if (running) {
                        std::cerr << "接受连接失败" << std::endl;
                    }
                    continue;
                }
                
                // 分配客户端ID
                int client_id;
                {
                    std::lock_guard<std::mutex> lock(clients_mutex);
                    client_id = client_id_counter++;
                    clients[client_id] = std::make_pair(client_socket, client_addr);
                }
                
                char client_ip[INET_ADDRSTRLEN];
                inet_ntop(AF_INET, &client_addr.sin_addr, client_ip, INET_ADDRSTRLEN);
                std::cout << "客户端 " << client_id << " 来自 " << client_ip << ":" << ntohs(client_addr.sin_port) << " 已连接" << std::endl;
                
                // 将客户端连接任务加入队列
                {
                    std::lock_guard<std::mutex> lock(queue_mutex);
                    message_queue.push(std::make_tuple("connect", client_id, Json::Value()));
                }
                queue_cv.notify_one();
            }
        } catch (const std::exception& e) {
            std::cerr << "服务器启动失败: " << e.what() << std::endl;
        }
        stop();
    }
    
    void stop() {
        running = false;
        
        // 关闭所有客户端连接
        {
            std::lock_guard<std::mutex> lock(clients_mutex);
            for (auto& pair : clients) {
                int client_id = pair.first;
                int client_socket = pair.second.first;
                try {
                    close(client_socket);
                } catch (...) {
                    // 忽略关闭错误
                }
            }
            clients.clear();
        }
        
        // 关闭服务器套接字
        if (server_socket >= 0) {
            close(server_socket);
            server_socket = -1;
        }
        
        // 通知所有等待的线程
        queue_cv.notify_all();
        
        // 等待所有线程结束
        for (auto& thread : thread_pool) {
            if (thread.joinable()) {
                thread.join();
            }
        }
        
        std::cout << "高级TCP服务器已停止" << std::endl;
    }
    
private:
    void worker() {
        while (running) {
            std::unique_lock<std::mutex> lock(queue_mutex);
            
            // 等待任务，超时1秒
            if (queue_cv.wait_for(lock, std::chrono::seconds(1), [this] { return !message_queue.empty() || !running; })) {
                if (!running) break;
                
                auto task = message_queue.front();
                message_queue.pop();
                lock.unlock();
                
                std::string task_type = std::get<0>(task);
                int client_id = std::get<1>(task);
                Json::Value data = std::get<2>(task);
                
                if (task_type == "connect") {
                    handle_connect(client_id);
                } else if (task_type == "message") {
                    handle_message(client_id, data);
                } else if (task_type == "disconnect") {
                    handle_disconnect(client_id);
                }
            } else {
                lock.unlock();
            }
        }
    }
    
    void handle_connect(int client_id) {
        try {
            std::lock_guard<std::mutex> lock(clients_mutex);
            if (clients.find(client_id) != clients.end()) {
                int client_socket = clients[client_id].first;
                
                // 发送欢迎消息
                Json::Value welcome_msg;
                welcome_msg["type"] = "welcome";
                welcome_msg["client_id"] = client_id;
                welcome_msg["message"] = "欢迎连接到服务器";
                
                Json::StreamWriterBuilder builder;
                std::string response = Json::writeString(builder, welcome_msg);
                send(client_socket, response.c_str(), response.length(), 0);
                
                // 启动客户端处理线程
                std::thread client_thread(&AdvancedTCPServer::handle_client, this, client_id, client_socket);
                client_thread.detach();
            }
        } catch (const std::exception& e) {
            std::cerr << "处理客户端 " << client_id << " 连接时出错: " << e.what() << std::endl;
            handle_disconnect(client_id);
        }
    }
    
    void handle_client(int client_id, int client_socket) {
        try {
            char buffer[1024];
            
            while (running) {
                // 接收数据
                ssize_t bytes_received = recv(client_socket, buffer, sizeof(buffer) - 1, 0);
                if (bytes_received <= 0) {
                    break;
                }
                
                buffer[bytes_received] = '\0';
                
                try {
                    // 解析JSON消息
                    Json::Value message;
                    Json::Reader reader;
                    if (reader.parse(buffer, message)) {
                        std::lock_guard<std::mutex> lock(queue_mutex);
                        message_queue.push(std::make_tuple("message", client_id, message));
                        queue_cv.notify_one();
                    }
                } catch (const std::exception& e) {
                    // 非JSON消息，作为普通文本处理
                    Json::Value text_message;
                    text_message["type"] = "text";
                    text_message["content"] = buffer;
                    
                    std::lock_guard<std::mutex> lock(queue_mutex);
                    message_queue.push(std::make_tuple("message", client_id, text_message));
                    queue_cv.notify_one();
                }
            }
        } catch (const std::exception& e) {
            std::cerr << "处理客户端 " << client_id << " 消息时出错: " << e.what() << std::endl;
        }
        
        {
            std::lock_guard<std::mutex> lock(queue_mutex);
            message_queue.push(std::make_tuple("disconnect", client_id, Json::Value()));
            queue_cv.notify_one();
        }
    }
    
    void handle_message(int client_id, const Json::Value& message) {
        try {
            std::lock_guard<std::mutex> lock(clients_mutex);
            if (clients.find(client_id) != clients.end()) {
                int client_socket = clients[client_id].first;
                
                // 根据消息类型处理
                std::string msg_type = message.get("type", "text").asString();
                
                if (msg_type == "text") {
                    std::string content = message.get("content", "").asString();
                    std::cout << "客户端 " << client_id << " 消息: " << content << std::endl;
                    
                    // 发送确认消息
                    Json::Value response;
                    response["type"] = "response";
                    response["message"] = "服务器收到: " + content;
                    response["timestamp"] = (Json::UInt64)std::time(nullptr);
                    
                    Json::StreamWriterBuilder builder;
                    std::string response_str = Json::writeString(builder, response);
                    send(client_socket, response_str.c_str(), response_str.length(), 0);
                    
                    // 广播消息给其他客户端
                    Json::Value broadcast_msg;
                    broadcast_msg["type"] = "broadcast";
                    broadcast_msg["sender_id"] = client_id;
                    broadcast_msg["content"] = content;
                    broadcast_msg["timestamp"] = (Json::UInt64)std::time(nullptr);
                    
                    add_to_broadcast_queue(broadcast_msg, client_id);
                    
                } else if (msg_type == "get_clients") {
                    // 获取客户端列表
                    Json::Value response;
                    response["type"] = "client_list";
                    Json::Value client_list(Json::arrayValue);
                    
                    for (const auto& pair : clients) {
                        client_list.append(pair.first);
                    }
                    
                    response["clients"] = client_list;
                    
                    Json::StreamWriterBuilder builder;
                    std::string response_str = Json::writeString(builder, response);
                    send(client_socket, response_str.c_str(), response_str.length(), 0);
                    
                } else if (msg_type == "private") {
                    // 私聊消息
                    int target_id = message.get("target_id", -1).asInt();
                    std::string content = message.get("content", "").asString();
                    
                    if (clients.find(target_id) != clients.end()) {
                        int target_socket = clients[target_id].first;
                        
                        Json::Value private_msg;
                        private_msg["type"] = "private";
                        private_msg["sender_id"] = client_id;
                        private_msg["content"] = content;
                        private_msg["timestamp"] = (Json::UInt64)std::time(nullptr);
                        
                        Json::StreamWriterBuilder builder;
                        std::string msg_str = Json::writeString(builder, private_msg);
                        send(target_socket, msg_str.c_str(), msg_str.length(), 0);
                        
                        // 发送确认消息给发送者
                        Json::Value confirm_msg;
                        confirm_msg["type"] = "confirm";
                        confirm_msg["message"] = "私聊消息已发送给客户端 " + std::to_string(target_id);
                        confirm_msg["timestamp"] = (Json::UInt64)std::time(nullptr);
                        
                        std::string confirm_str = Json::writeString(builder, confirm_msg);
                        send(client_socket, confirm_str.c_str(), confirm_str.length(), 0);
                    } else {
                        // 目标客户端不存在
                        Json::Value error_msg;
                        error_msg["type"] = "error";
                        error_msg["message"] = "客户端 " + std::to_string(target_id) + " 不存在";
                        error_msg["timestamp"] = (Json::UInt64)std::time(nullptr);
                        
                        Json::StreamWriterBuilder builder;
                        std::string error_str = Json::writeString(builder, error_msg);
                        send(client_socket, error_str.c_str(), error_str.length(), 0);
                    }
                }
            }
        } catch (const std::exception& e) {
            std::cerr << "处理客户端 " << client_id << " 消息时出错: " << e.what() << std::endl;
        }
    }
    
    void handle_disconnect(int client_id) {
        try {
            std::lock_guard<std::mutex> lock(clients_mutex);
            if (clients.find(client_id) != clients.end()) {
                int client_socket = clients[client_id].first;
                struct sockaddr_in client_addr = clients[client_id].second;
                
                close(client_socket);
                clients.erase(client_id);
                
                char client_ip[INET_ADDRSTRLEN];
                inet_ntop(AF_INET, &client_addr.sin_addr, client_ip, INET_ADDRSTRLEN);
                std::cout << "客户端 " << client_id << " (" << client_ip << ":" << ntohs(client_addr.sin_port) << ") 已断开连接" << std::endl;
                
                // 广播客户端断开消息
                Json::Value disconnect_msg;
                disconnect_msg["type"] = "client_disconnected";
                disconnect_msg["client_id"] = client_id;
                disconnect_msg["timestamp"] = (Json::UInt64)std::time(nullptr);
                
                add_to_broadcast_queue(disconnect_msg);
            }
        } catch (const std::exception& e) {
            std::cerr << "处理客户端 " << client_id << " 断开连接时出错: " << e.what() << std::endl;
        }
    }
    
    void add_to_broadcast_queue(const Json::Value& message, int exclude_client = -1) {
        std::lock_guard<std::mutex> lock(queue_mutex);
        message_queue.push(std::make_tuple("broadcast", exclude_client, message));
        queue_cv.notify_one();
    }
    
    void broadcast_messages() {
        while (running) {
            std::unique_lock<std::mutex> lock(queue_mutex);
            
            // 等待广播任务，超时1秒
            if (queue_cv.wait_for(lock, std::chrono::seconds(1), [this] { 
                return !message_queue.empty() || !running; 
            })) {
                if (!running) break;
                
                // 查找广播任务
                bool found_broadcast = false;
                std::tuple<std::string, int, Json::Value> broadcast_task;
                
                // 检查队列中是否有广播任务
                std::queue<std::tuple<std::string, int, Json::Value>> temp_queue;
                while (!message_queue.empty()) {
                    auto task = message_queue.front();
                    message_queue.pop();
                    
                    if (std::get<0>(task) == "broadcast" && !found_broadcast) {
                        broadcast_task = task;
                        found_broadcast = true;
                    } else {
                        temp_queue.push(task);
                    }
                }
                
                // 恢复队列
                message_queue = temp_queue;
                
                if (found_broadcast) {
                    lock.unlock();
                    
                    int exclude_client = std::get<1>(broadcast_task);
                    Json::Value message = std::get<2>(broadcast_task);
                    
                    std::lock_guard<std::mutex> clients_lock(clients_mutex);
                    for (const auto& pair : clients) {
                        int client_id = pair.first;
                        int client_socket = pair.second.first;
                        
                        if (client_id != exclude_client) {
                            try {
                                Json::StreamWriterBuilder builder;
                                std::string msg_str = Json::writeString(builder, message);
                                send(client_socket, msg_str.c_str(), msg_str.length(), 0);
                            } catch (...) {
                                // 发送失败，可能是客户端已断开
                                handle_disconnect(client_id);
                            }
                        }
                    }
                } else {
                    lock.unlock();
                }
            } else {
                lock.unlock();
            }
        }
    }
};

// 使用示例

    try {
        server.start();
    } catch (...) {
        server.stop();
    }
    return 0;
}
```

#### 8.3.1 基本TCP客户端

下面是一个基本的TCP客户端实现，使用C++编写：

```cpp
#include <iostream>
#include <string>
#include <thread>
#include <atomic>
#include <cstring>
#include <sys/socket.h>
#include <arpa/inet.h>
#include <unistd.h>

class TCPClient {
private:
    std::string host;
    int port;
    int client_socket;
    std::atomic<bool> connected;
    std::thread receive_thread;
    
public:
    TCPClient(const std::string& host = "localhost", int port = 8080) 
        : host(host), port(port), client_socket(-1), connected(false) {}
    
    ~TCPClient() {
        disconnect();
    }
    
    bool connect() {
        try {
            // 创建TCP套接字
            client_socket = socket(AF_INET, SOCK_STREAM, 0);
            if (client_socket < 0) {
                throw std::runtime_error("创建套接字失败");
            }
            
            // 设置服务器地址
            struct sockaddr_in server_addr;
            memset(&server_addr, 0, sizeof(server_addr));
            server_addr.sin_family = AF_INET;
            server_addr.sin_port = htons(port);
            
            // 将主机名转换为IP地址
            if (inet_pton(AF_INET, host.c_str(), &server_addr.sin_addr) <= 0) {
                throw std::runtime_error("无效的地址/地址不受支持");
            }
            
            // 连接到服务器
            if (::connect(client_socket, (struct sockaddr*)&server_addr, sizeof(server_addr)) < 0) {
                throw std::runtime_error("连接失败");
            }
            
            connected = true;
            std::cout << "已连接到服务器 " << host << ":" << port << std::endl;
            
            // 启动接收线程
            receive_thread = std::thread(&TCPClient::receive_messages, this);
            
            return true;
        } catch (const std::exception& e) {
            std::cerr << "连接失败: " << e.what() << std::endl;
            if (client_socket >= 0) {
                close(client_socket);
                client_socket = -1;
            }
            return false;
        }
    }
    
    void disconnect() {
        connected = false;
        if (client_socket >= 0) {
            close(client_socket);
            client_socket = -1;
        }
        if (receive_thread.joinable()) {
            receive_thread.join();
        }
        std::cout << "已断开连接" << std::endl;
```

#### 9.1.1 基本UDP服务器

下面是一个基本的UDP服务器实现，使用C++编写：

```cpp
#include <iostream>
#include <string>
#include <thread>
#include <map>
#include <vector>
#include <chrono>
#include <cstring>
#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>
#include <unistd.h>

class UDPServer {
private:
    std::string host;
    int port;
    int server_socket;
    bool running;
    std::map<std::string, std::chrono::steady_clock::time_point> clients; // 客户端字典 {address: last_seen}
    
    std::string addressToString(const struct sockaddr_in& addr) {
        char ip[INET_ADDRSTRLEN];
        inet_ntop(AF_INET, &(addr.sin_addr), ip, INET_ADDRSTRLEN);
        return std::string(ip) + ":" + std::to_string(ntohs(addr.sin_port));
    }
    
public:
    UDPServer(const std::string& host = "0.0.0.0", int port = 8080) 
        : host(host), port(port), server_socket(-1), running(false) {}
    
    ~UDPServer() {
        stop();
    }
    
    void start() {
        try {
            // 创建UDP套接字
            server_socket = socket(AF_INET, SOCK_DGRAM, 0);
            if (server_socket < 0) {
                throw std::runtime_error("创建套接字失败");
            }
            
            // 绑定地址
            struct sockaddr_in server_addr;
            memset(&server_addr, 0, sizeof(server_addr));
            server_addr.sin_family = AF_INET;
            server_addr.sin_port = htons(port);
            inet_pton(AF_INET, host.c_str(), &(server_addr.sin_addr));
            
            if (bind(server_socket, (struct sockaddr*)&server_addr, sizeof(server_addr)) < 0) {
                throw std::runtime_error("绑定地址失败");
            }
            
            running = true;
            std::cout << "UDP服务器启动，监听 " << host << ":" << port << std::endl;
            
            // 接收数据
            while (running) {
                try {
                    char buffer[1024];
                    struct sockaddr_in client_addr;
                    socklen_t client_len = sizeof(client_addr);
                    
                    // 接收数据和客户端地址
                    ssize_t bytes_received = recvfrom(server_socket, buffer, sizeof(buffer) - 1, 0, 
                                                    (struct sockaddr*)&client_addr, &client_len);
                    
                    if (bytes_received < 0) {
                        if (running) {
                            throw std::runtime_error("接收数据失败");
                        } else {
                            break; // 套接字已关闭
                        }
                    }
                    
                    buffer[bytes_received] = '\0';
                    std::string client_address = addressToString(client_addr);
                    
                    // 更新客户端最后活动时间
                    clients[client_address] = std::chrono::steady_clock::now();
                    
                    // 处理数据
                    std::string message(buffer);
                    std::cout << "来自 " << client_address << " 的消息: " << message << std::endl;
                    
                    // 启动新线程处理客户端请求
                    std::thread client_thread(&UDPServer::handle_client, this, message, client_addr);
                    client_thread.detach();
                } catch (const std::exception& e) {
                    if (running) {
                        std::cerr << "处理客户端请求时出错: " << e.what() << std::endl;
                    }
                }
            }
        } catch (const std::exception& e) {
            std::cerr << "服务器启动失败: " << e.what() << std::endl;
        }
        stop();
    }
    
    void stop() {
        running = false;
        if (server_socket >= 0) {
            close(server_socket);
            server_socket = -1;
        }
        std::cout << "UDP服务器已停止" << std::endl;
    }
    
    void handle_client(const std::string& message, const struct sockaddr_in& client_addr) {
        try {
            std::string response;
            
            // 处理消息
            if (message == "time") {
                // 返回当前时间
                auto now = std::chrono::system_clock::now();
                auto time_t = std::chrono::system_clock::to_time_t(now);
                auto tm = *std::localtime(&time_t);
                char buffer[100];
                std::strftime(buffer, sizeof(buffer), "%Y-%m-%d %H:%M:%S", &tm);
                response = buffer;
            } else if (message == "clients") {
                // 返回客户端数量
                response = "当前在线客户端数量: " + std::to_string(clients.size());
            } else if (message.substr(0, 5) == "echo ") {
                // 回显消息
                response = message.substr(5);
            } else {
                // 默认响应
                response = "服务器收到: " + message;
            }
            
            // 发送响应
            sendto(server_socket, response.c_str(), response.length(), 0, 
                  (struct sockaddr*)&client_addr, sizeof(client_addr));
        } catch (const std::exception& e) {
            std::cerr << "处理客户端 " << addressToString(client_addr) << " 时出错: " << e.what() << std::endl;
        }
    }
    
    void cleanup_inactive_clients(int timeout = 300) {
        auto current_time = std::chrono::steady_clock::now();
        std::vector<std::string> inactive_clients;
        
        for (const auto& client : clients) {
            auto duration = std::chrono::duration_cast<std::chrono::seconds>(current_time - client.second).count();
            if (duration > timeout) {
                inactive_clients.push_back(client.first);
            }
        }
        
        for (const auto& address : inactive_clients) {
            clients.erase(address);
            std::cout << "清理不活跃客户端: " << address << std::endl;
        }
    }
};

// 使用示例
int main() {
    UDPServer server;
    
    // 启动清理线程
    std::thread cleanup_thread([&server]() {
        while (true) {
            std::this_thread::sleep_for(std::chrono::minutes(1)); // 每分钟清理一次
            server.cleanup_inactive_clients();
        }
    });
    cleanup_thread.detach();
    
    try {
        server.start();
    } catch (const std::exception& e) {
        std::cerr << "服务器异常: " << e.what() << std::endl;
        server.stop();
    }
    
    return 0;
}
```

```cpp
        try {
            // 创建UDP套接字
            server_socket = socket(AF_INET, SOCK_DGRAM, 0);
            if (server_socket < 0) {
                throw std::runtime_error("创建套接字失败");
            }
            
            // 绑定地址
            struct sockaddr_in server_addr;
            memset(&server_addr, 0, sizeof(server_addr));
            server_addr.sin_family = AF_INET;
            server_addr.sin_port = htons(port);
            inet_pton(AF_INET, host.c_str(), &(server_addr.sin_addr));
            
            if (bind(server_socket, (struct sockaddr*)&server_addr, sizeof(server_addr)) < 0) {
                throw std::runtime_error("绑定地址失败");
            }
            
            running = true;
            std::cout << "高级UDP服务器启动，监听 " << host << ":" << port << std::endl;
            
            // 启动工作线程
            for (int i = 0; i < 5; i++) {
                thread_pool.emplace_back(&AdvancedUDPServer::worker, this);
            }
            
            // 启动重传线程
            std::thread resend_thread(&AdvancedUDPServer::resendMessages, this);
            resend_thread.detach();
            
            // 启动清理线程
            std::thread cleanup_thread(&AdvancedUDPServer::cleanupInactiveClients, this);
            cleanup_thread.detach();
            
            // 接收数据
            while (running) {
                try {
                    char buffer[1024];
                    struct sockaddr_in client_addr;
                    socklen_t client_len = sizeof(client_addr);
                    
                    // 接收数据和客户端地址
                    ssize_t bytes_received = recvfrom(server_socket, buffer, sizeof(buffer) - 1, 0, 
                                                    (struct sockaddr*)&client_addr, &client_len);
                    
                    if (bytes_received < 0) {
                        if (running) {
                            throw std::runtime_error("接收数据失败");
                        } else {
                            break; // 套接字已关闭
                        }
                    }
                    
                    buffer[bytes_received] = '\0';
                    
                    // 解析消息
                    try {
                        json message = json::parse(buffer);
                        std::lock_guard<std::mutex> guard(lock);
                        message_queue.push(std::make_tuple("message", message, client_addr));
                    } catch (const json::parse_error&) {
                        // 非JSON消息，作为普通文本处理
                        std::string text_message(buffer);
                        std::lock_guard<std::mutex> guard(lock);
                        message_queue.push(std::make_tuple("text", text_message, client_addr));
                    }
                } catch (const std::exception& e) {
                    if (running) {
                        std::cerr << "处理客户端请求时出错: " << e.what() << std::endl;
                    }
                }
            }
        } catch (const std::exception& e) {
            std::cerr << "服务器启动失败: " << e.what() << std::endl;
        }
        stop();
    }
    
    void stop() {
        running = false;
        if (server_socket >= 0) {
            close(server_socket);
            server_socket = -1;
        }
        std::cout << "高级UDP服务器已停止" << std::endl;
    }
    
    void worker() {
        // 工作线程，处理客户端请求
        while (running) {
            std::tuple<std::string, json, struct sockaddr_in> task;
            bool has_task = false;
            
            {
                std::lock_guard<std::mutex> guard(lock);
                if (!message_queue.empty()) {
                    task = message_queue.front();
                    message_queue.pop();
                    has_task = true;
                }
            }
            
            if (has_task) {
                try {
                    std::string task_type = std::get<0>(task);
                    json data = std::get<1>(task);
                    struct sockaddr_in client_address = std::get<2>(task);
                    
                    if (task_type == "message") {
                        handleMessage(data, client_address);
                    } else if (task_type == "text") {
                        handleText(data, client_address);
                    }
                } catch (const std::exception& e) {
                    std::cerr << "工作线程出错: " << e.what() << std::endl;
                }
            } else {
                std::this_thread::sleep_for(std::chrono::milliseconds(100));
            }
        }
    }
    
    void handleMessage(const json& message, const struct sockaddr_in& client_address) {
        // 处理JSON消息
        try {
            std::string msg_type = message.value("type", "unknown");
            
            if (msg_type == "register") {
                handleRegister(message, client_address);
            } else if (msg_type == "data") {
                handleData(message, client_address);
            } else if (msg_type == "ack") {
                handleAck(message, client_address);
            } else {
                std::cout << "收到未知类型消息: " << message.dump() << std::endl;
            }
        } catch (const std::exception& e) {
            std::cerr << "处理消息时出错: " << e.what() << std::endl;
        }
    }
    
    void handleText(const std::string& text, const struct sockaddr_in& client_address) {
        // 处理文本消息
        try {
            std::cout << "来自 " << addressToString(client_address) << " 的文本消息: " << text << std::endl;
            
            // 查找客户端ID
            int client_id = findClientId(client_address);
            
            if (client_id >= 0) {
                // 发送确认
                json response = {
                    {"type", "response"},
                    {"message", "服务器收到: " + text},
                    {"timestamp", std::chrono::duration_cast<std::chrono::seconds>(
                        std::chrono::system_clock::now().time_since_epoch()).count()}
                };
                sendReliableMessage(response, client_address);
            } else {
                // 客户端未注册
                json response = {
                    {"type", "error"},
                    {"message", "请先注册"},
                    {"timestamp", std::chrono::duration_cast<std::chrono::seconds>(
                        std::chrono::system_clock::now().time_since_epoch()).count()}
                };
                sendMessage(response, client_address);
            }
        } catch (const std::exception& e) {
            std::cerr << "处理文本消息时出错: " << e.what() << std::endl;
        }
    }
    
    void handleRegister(const json& message, const struct sockaddr_in& client_address) {
        // 处理注册消息
        try {
            int client_id;
            {
                std::lock_guard<std::mutex> guard(lock);
                client_id = client_id_counter++;
                
                ClientInfo client_info;
                client_info.address = client_address;
                client_info.last_seen = std::chrono::steady_clock::now();
                client_info.sequence = 0;
                
                clients[client_id] = client_info;
            }

            json response = {
                {"type", "register_ack"},
                {"client_id", client_id},
                {"message", "注册成功"},
                {"timestamp", std::chrono::duration_cast<std::chrono::seconds>(

        } catch (const std::exception& e) {

        }
    }
    
    void handleData(const json& message, const struct sockaddr_in& client_address) {
        // 处理数据消息
        try {
            int client_id = message.value("client_id", -1);
            int sequence = message.value("sequence", -1);

            {
                std::lock_guard<std::mutex> guard(lock);
                if (clients.find(client_id) == clients.end()) {
                    std::cout << "未知客户端ID: " << client_id << std::endl;
                    return;
                }
                
                // 验证地址
                if (clients[client_id].address.sin_addr.s_addr != client_address.sin_addr.s_addr ||
                    clients[client_id].address.sin_port != client_address.sin_port) {
                    std::cout << "客户端 " << client_id << " 地址不匹配" << std::endl;
                    return;
                }
                
                // 验证序列号
                if (sequence <= clients[client_id].sequence) {
                    std::cout << "客户端 " << client_id << " 重复或过期消息: " << sequence << std::endl;
                    return;
                }
                
                // 更新序列号和最后活动时间
                clients[client_id].sequence = sequence;
                clients[client_id].last_seen = std::chrono::steady_clock::now();
            }
            
            std::cout << "客户端 " << client_id << " 数据: " << data << std::endl;
            
            // 发送ACK
            json ack = {
                {"type", "ack"},
                {"client_id", client_id},
                {"sequence", sequence},
                {"timestamp", std::chrono::duration_cast<std::chrono::seconds>(
                    std::chrono::system_clock::now().time_since_epoch()).count()}
            };
            sendMessage(ack, client_address);
            
            // 处理数据
            json response = {
                {"type", "data_response"},
                {"client_id", client_id},
                {"sequence", sequence},
                {"message", "服务器收到数据: " + data},
                {"timestamp", std::chrono::duration_cast<std::chrono::seconds>(
                    std::chrono::system_clock::now().time_since_epoch()).count()}
            };
            sendReliableMessage(response, client_address);
        } catch (const std::exception& e) {
            std::cerr << "处理数据消息时出错: " << e.what() << std::endl;
        }

    void handleAck(const json& message, const struct sockaddr_in& client_address) {
        // 处理ACK消息
        try {
            std::string message_id = message.value("message_id", "");
            
            std::lock_guard<std::mutex> guard(lock);
            if (ack_waiters.find(message_id) != ack_waiters.end()) {
                ack_waiters.erase(message_id);
                std::cout << "收到消息 " << message_id << " 的ACK" << std::endl;
            }
        } catch (const std::exception& e) {
            std::cerr << "处理ACK消息时出错: " << e.what() << std::endl;
        }
    }
    
    void sendMessage(const json& message, const struct sockaddr_in& client_address) {
        // 发送消息
        try {
            std::string data = message.dump();
            sendto(server_socket, data.c_str(), data.length(), 0, 
                  (struct sockaddr*)&client_address, sizeof(client_address));
        } catch (const std::exception& e) {
            std::cerr << "发送消息失败: " << e.what() << std::endl;
        }
    }
    
    void sendReliableMessage(json message, const struct sockaddr_in& client_address) {
        // 发送可靠消息（需要ACK确认）
        try {
            // 生成消息ID
            std::string message_id = generateMessageId(message);
            
            // 添加消息ID
            message["message_id"] = message_id;
            
            // 发送消息
            sendMessage(message, client_address);
            
            // 添加到等待ACK列表
            std::lock_guard<std::mutex> guard(lock);
            AckWaiter waiter;
            waiter.message = message;
            waiter.address = client_address;
            waiter.retries = 0;
            waiter.timestamp = std::chrono::steady_clock::now();
            ack_waiters[message_id] = waiter;
        } catch (const std::exception& e) {
            std::cerr << "发送可靠消息失败: " << e.what() << std::endl;
        }
    }
    
    void resendMessages() {
        // 重传未确认的消息
        while (running) {
            try {
                std::this_thread::sleep_for(std::chrono::seconds(1)); // 每秒检查一次
                
                auto current_time = std::chrono::steady_clock::now();
                std::vector<std::string> messages_to_resend;
                std::vector<std::string> messages_to_remove;
                
                {
                    std::lock_guard<std::mutex> guard(lock);
                    for (const auto& pair : ack_waiters) {
                        const std::string& message_id = pair.first;
                        const AckWaiter& waiter = pair.second;
                        
                        // 检查是否超时
                        auto duration = std::chrono::duration_cast<std::chrono::seconds>(current_time - waiter.timestamp).count();
                        if (duration > timeout) {
                            // 检查重试次数
                            if (waiter.retries < max_retries) {
                                messages_to_resend.push_back(message_id);
                            } else {
                                messages_to_remove.push_back(message_id);
                                std::cout << "消息 " << message_id << " 超过最大重试次数，放弃重传" << std::endl;
                            }
                        }
                    }
                }
                
                // 重传消息
                for (const auto& message_id : messages_to_resend) {
                    std::lock_guard<std::mutex> guard(lock);
                    if (ack_waiters.find(message_id) != ack_waiters.end()) {
                        AckWaiter& waiter = ack_waiters[message_id];
                        waiter.retries++;
                        waiter.timestamp = current_time;
                        
                        std::cout << "重传消息 " << message_id << "，第 " << waiter.retries << " 次重试" << std::endl;
                        sendMessage(waiter.message, waiter.address);
                    }
                }
                
                // 移除超时消息
                for (const auto& message_id : messages_to_remove) {
                    std::lock_guard<std::mutex> guard(lock);
                    ack_waiters.erase(message_id);
                }
            } catch (const std::exception& e) {
                std::cerr << "重传消息时出错: " << e.what() << std::endl;
            }
        }
    }
    
    void cleanupInactiveClients() {
        // 清理不活跃的客户端
        while (running) {
            try {
                std::this_thread::sleep_for(std::chrono::minutes(1)); // 每分钟清理一次
                
                auto current_time = std::chrono::steady_clock::now();
                std::vector<int> inactive_clients;
                
                {
                    std::lock_guard<std::mutex> guard(lock);
                    for (const auto& client : clients) {
                        auto duration = std::chrono::duration_cast<std::chrono::seconds>(current_time - client.second.last_seen).count();
                        if (duration > 300) { // 5分钟超时
                            inactive_clients.push_back(client.first);
                        }
                    }
                }
                
                for (int client_id : inactive_clients) {
                    std::lock_guard<std::mutex> guard(lock);
                    if (clients.find(client_id) != clients.end()) {
                        clients.erase(client_id);
                        std::cout << "清理不活跃客户端: " << client_id << std::endl;
                    }
                }
            } catch (const std::exception& e) {
                std::cerr << "清理不活跃客户端时出错: " << e.what() << std::endl;
            }
        }
    }
};

// 使用示例
```

#### 9.2.1 基本UDP客户端

下面是一个基本的UDP客户端实现，使用C++编写：

```cpp
#include <iostream>
#include <string>
#include <thread>
#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>

class UDPClient {
private:
    std::string host;
    int port;
    int client_socket;
    bool running;
    std::thread receive_thread;
    
    void receiveMessages() {
        // 接收消息
        while (running) {
            try {
                char buffer[1024];
                struct sockaddr_in server_addr;
                socklen_t server_len = sizeof(server_addr);
                
                // 接收数据
                ssize_t bytes_received = recvfrom(client_socket, buffer, sizeof(buffer) - 1, 0, 
                                                (struct sockaddr*)&server_addr, &server_len);

                    if (running) {

                    }
                    break;
                }
                
                buffer[bytes_received] = '\0';
                
                // 处理数据
                std::string message(buffer);
                std::cout << "服务器响应: " << message << std::endl;
            } catch (const std::exception& e) {

                break;
            }
        }
    }
    
public:

        : host(host), port(port), client_socket(-1), running(false) {}

        disconnect();
    }
    
    bool connect() {
        // 连接到服务器
        try {
            // 创建UDP套接字
            client_socket = socket(AF_INET, SOCK_DGRAM, 0);
            if (client_socket < 0) {
                throw std::runtime_error("创建套接字失败");
            }
            
            running = true;
            std::cout << "UDP客户端已启动，服务器地址 " << host << ":" << port << std::endl;
            
            // 启动接收线程
            receive_thread = std::thread(&UDPClient::receiveMessages, this);
            
            return true;
        } catch (const std::exception& e) {
            std::cerr << "连接失败: " << e.what() << std::endl;
            return false;
        }
    }
    
    void disconnect() {
        // 断开连接
        running = false;
        if (client_socket >= 0) {
            close(client_socket);
            client_socket = -1;
        }
        
        if (receive_thread.joinable()) {
            receive_thread.join();
        }
        
        std::cout << "UDP客户端已停止" << std::endl;
    }
    
    bool sendMessage(const std::string& message) {
        // 发送消息
        if (!running) {
            std::cerr << "客户端未启动" << std::endl;
            return false;
        }
        
        try {
            // 设置服务器地址
            struct sockaddr_in server_addr;
            memset(&server_addr, 0, sizeof(server_addr));
            server_addr.sin_family = AF_INET;
            server_addr.sin_port = htons(port);
            inet_pton(AF_INET, host.c_str(), &(server_addr.sin_addr));
            
            // 发送数据
            ssize_t bytes_sent = sendto(client_socket, message.c_str(), message.length(), 0, 
                                      (struct sockaddr*)&server_addr, sizeof(server_addr));
            
            if (bytes_sent < 0) {
                throw std::runtime_error("发送数据失败");
            }
            
            return true;
        } catch (const std::exception& e) {
            std::cerr << "发送消息失败: " << e.what() << std::endl;
            return false;
        }
    }
    
    void runInteractive() {
        // 运行交互式客户端
        if (!connect()) {
            return;
        }
        
        try {
            while (running) {
                // 获取用户输入
                std::string message;
                std::cout << "请输入消息 (输入 'quit' 退出): ";
                std::getline(std::cin, message);
                
                if (message == "quit") {
                    break;
                }
                
                // 发送消息
                sendMessage(message);
            }
        } catch (const std::exception& e) {
            std::cerr << "运行交互式客户端时出错: " << e.what() << std::endl;
        } finally {
            disconnect();
        }
    }
};

// 使用示例
int main() {
    UDPClient client;
    client.runInteractive();
    
    return 0;
}
```

#### 9.2.2 高级UDP客户端

下面是一个更高级的UDP客户端实现，使用C++编写：

```cpp
#include <iostream>
#include <string>
#include <thread>
#include <mutex>
#include <condition_variable>
#include <queue>
#include <map>
#include <chrono>
#include <random>
#include <functional>
#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>
#include <unistd.h>
#include <cstring>
#include <openssl/md5.h>

class AdvancedUDPClient {
private:
    std::string host;
    int port;
    int max_retries;
    int timeout_sec;
    
    int client_socket;
    bool running;
    bool registered;
    std::string client_id;
    int sequence;
    std::thread receive_thread;
    std::thread resend_thread;
    std::mutex lock;
    std::map<std::string, std::function<void(const std::map<std::string, std::string>&)>> message_handlers;
    std::map<std::string, std::tuple<std::map<std::string, std::string>, int, std::chrono::steady_clock::time_point>> ack_waiters;
    
    void receiveMessages() {
        // 接收消息
        while (running) {
            try {
                char buffer[1024];
                struct sockaddr_in server_addr;
                socklen_t server_len = sizeof(server_addr);
                
                // 接收数据
                ssize_t bytes_received = recvfrom(client_socket, buffer, sizeof(buffer) - 1, 0, 
                                                (struct sockaddr*)&server_addr, &server_len);
                
                if (bytes_received < 0) {
                    if (running) {
                        std::cerr << "接收消息失败" << std::endl;
                    }
                    break;
                }
                
                buffer[bytes_received] = '\0';
                
                // 解析消息
                std::map<std::string, std::string> message;
                try {
                    message = parseJson(buffer);
                    handleMessage(message);
                } catch (const std::exception& e) {
                    // 非JSON消息，作为普通文本处理

                }
            } catch (const std::exception& e) {
                std::cerr << "接收消息失败: " << e.what() << std::endl;
                break;
            }
        }
    }
    
    void handleMessage(const std::map<std::string, std::string>& message) {
        // 处理接收到的消息
        std::string msg_type = "unknown";
        auto it = message.find("type");
        if (it != message.end()) {
            msg_type = it->second;
        }
        
        // 调用注册的消息处理器
        auto handler_it = message_handlers.find(msg_type);
        if (handler_it != message_handlers.end()) {
            handler_it->second(message);
        } else {
            std::cout << "收到未知类型消息: " << messageToString(message) << std::endl;
        }
    }
    
    void resendMessages() {
        // 重传未确认的消息
        while (running) {
            try {
                std::this_thread::sleep_for(std::chrono::seconds(1)); // 每秒检查一次
                
                auto current_time = std::chrono::steady_clock::now();
                std::vector<std::tuple<std::string, std::map<std::string, std::string>, int>> messages_to_resend;
                std::vector<std::string> messages_to_remove;
                
                {
                    std::lock_guard<std::mutex> lock_guard(lock);
                    for (const auto& entry : ack_waiters) {
                        const auto& message_id = entry.first;
                        const auto& message_data = entry.second;
                        const auto& message = std::get<0>(message_data);
                        const auto& retries = std::get<1>(message_data);
                        const auto& timestamp = std::get<2>(message_data);
                        
                        // 检查是否超时
                        auto elapsed = std::chrono::duration_cast<std::chrono::seconds>(current_time - timestamp).count();
                        if (elapsed > timeout_sec) {
                            // 检查重试次数
                            if (retries < max_retries) {
                                messages_to_resend.push_back(std::make_tuple(message_id, message, retries + 1));
                            } else {
                                messages_to_remove.push_back(message_id);
                                std::cerr << "消息 " << message_id << " 超过最大重试次数，放弃重传" << std::endl;
                            }
                        }
                    }
                }
                
                // 重传消息
                for (const auto& item : messages_to_resend) {
                    const auto& message_id = std::get<0>(item);
                    const auto& message = std::get<1>(item);
                    const auto& retries = std::get<2>(item);
                    
                    std::cout << "重传消息 " << message_id << "，第 " << retries << " 次重试" << std::endl;
                    sendMessage(message);
                    
                    std::lock_guard<std::mutex> lock_guard(lock);
                    auto it = ack_waiters.find(message_id);
                    if (it != ack_waiters.end()) {
                        ack_waiters[message_id] = std::make_tuple(message, retries, std::chrono::steady_clock::now());
                    }
                }
                
                // 移除超时消息
                for (const auto& message_id : messages_to_remove) {
                    std::lock_guard<std::mutex> lock_guard(lock);
                    ack_waiters.erase(message_id);
                }
            } catch (const std::exception& e) {
                std::cerr << "重传消息时出错: " << e.what() << std::endl;
            }
        }
    }
    
    std::string generateMessageId(const std::map<std::string, std::string>& message) {
        // 生成消息ID
        std::string content = messageToString(message);
        unsigned char digest[MD5_DIGEST_LENGTH];
        MD5((unsigned char*)content.c_str(), content.length(), digest);
        
        char md5_string[33];
        for (int i = 0; i < 16; i++) {
            sprintf(&md5_string[i*2], "%02x", (unsigned int)digest[i]);
        }
        md5_string[32] = '\0';
        
        return std::string(md5_string);
    }
    
    std::map<std::string, std::string> parseJson(const std::string& json_str) {
        // 简单的JSON解析（实际应用中应使用JSON库）
        std::map<std::string, std::string> result;
        
        // 这是一个非常简化的JSON解析，仅适用于特定格式
        size_t pos = 0;
        while (pos < json_str.length()) {
            // 跳过空白字符
            while (pos < json_str.length() && (json_str[pos] == ' ' || json_str[pos] == '\n' || json_str[pos] == '\r' || json_str[pos] == '\t')) {
                pos++;
            }
            
            if (pos >= json_str.length() || json_str[pos] != '"') {
                break;
            }
            
            // 解析键
            pos++; // 跳过开始的引号
            size_t key_start = pos;
            while (pos < json_str.length() && json_str[pos] != '"') {
                if (json_str[pos] == '\\') {
                    pos++; // 跳过转义字符
                }
                pos++;
            }
            std::string key = json_str.substr(key_start, pos - key_start);
            pos++; // 跳过结束的引号
            
            // 跳过空白字符和冒号
            while (pos < json_str.length() && (json_str[pos] == ' ' || json_str[pos] == '\n' || json_str[pos] == '\r' || json_str[pos] == '\t' || json_str[pos] == ':')) {
                pos++;
            }
            
            // 解析值
            if (pos >= json_str.length()) {
                break;
            }
            
            std::string value;
            if (json_str[pos] == '"') {
                // 字符串值
                pos++; // 跳过开始的引号
                size_t value_start = pos;
                while (pos < json_str.length() && json_str[pos] != '"') {
                    if (json_str[pos] == '\\') {
                        pos++; // 跳过转义字符
                    }
                    pos++;
                }
                value = json_str.substr(value_start, pos - value_start);
                pos++; // 跳过结束的引号
            } else {
                // 数字或其他值
                size_t value_start = pos;
                while (pos < json_str.length() && json_str[pos] != ',' && json_str[pos] != '}') {
                    pos++;
                }
                value = json_str.substr(value_start, pos - value_start);
            }
            
            result[key] = value;
            
            // 跳过空白字符和逗号
            while (pos < json_str.length() && (json_str[pos] == ' ' || json_str[pos] == '\n' || json_str[pos] == '\r' || json_str[pos] == '\t' || json_str[pos] == ',')) {
                pos++;
            }
        }
        
        return result;
    }
    
    std::string messageToString(const std::map<std::string, std::string>& message) {
        // 将消息转换为字符串
        std::string result = "{";
        bool first = true;
        
        for (const auto& entry : message) {
            if (!first) {
                result += ",";
            }
            result += "\"" + entry.first + "\":\"" + entry.second + "\"";
            first = false;
        }
        
        result += "}";
        return result;
    }
    
    // 默认消息处理器
    void handleRegisterAck(const std::map<std::string, std::string>& message) {
        client_id = getValue(message, "client_id");
        registered = true;

    void handleResponse(const std::map<std::string, std::string>& message) {

    }

    }
    
    void handleAck(const std::map<std::string, std::string>& message) {
        std::string message_id = getValue(message, "message_id");
        
        std::lock_guard<std::mutex> lock_guard(lock);
        auto it = ack_waiters.find(message_id);

            std::cout << "收到消息 " << message_id << " 的ACK" << std::endl;
        }
    }
    
    void handleError(const std::map<std::string, std::string>& message) {
        std::string error_msg = getValue(message, "message");
        std::cerr << "错误消息: " << error_msg << std::endl;
    }
    
    std::string getValue(const std::map<std::string, std::string>& message, const std::string& key, const std::string& default_value = "") {
        auto it = message.find(key);
        return (it != message.end()) ? it->second : default_value;
    }
    
public:
    AdvancedUDPClient(const std::string& host = "localhost", int port = 8080, int max_retries = 3, int timeout = 5) 
        : host(host), port(port), max_retries(max_retries), timeout_sec(timeout),
          client_socket(-1), running(false), registered(false), sequence(0) {

        registerMessageHandler("response", [this](const std::map<std::string, std::string>& message) {

    bool connect() {

        try {
            // 创建UDP套接字
            client_socket = socket(AF_INET, SOCK_DGRAM, 0);
            if (client_socket < 0) {
                throw std::runtime_error("创建套接字失败");
            }

            receive_thread = std::thread(&AdvancedUDPClient::receiveMessages, this);
            
            // 启动重传线程

    void disconnect() {
        // 断开连接
        running = false;
        registered = false;
        
        if (client_socket >= 0) {
            close(client_socket);
            client_socket = -1;
        }
        
        if (receive_thread.joinable()) {
            receive_thread.join();
        }
        
        if (resend_thread.joinable()) {
            resend_thread.join();
        }
        
        std::cout << "高级UDP客户端已停止" << std::endl;
    }
    
    void registerWithServer() {
        // 向服务器注册
        std::map<std::string, std::string> register_message;
        register_message["type"] = "register";
        register_message["timestamp"] = std::to_string(std::chrono::duration_cast<std::chrono::seconds>(
            std::chrono::system_clock::now().time_since_epoch()).count());
        
        sendReliableMessage(register_message);
    }
    
    bool sendMessage(const std::map<std::string, std::string>& message) {
        // 发送消息
        if (!running) {
            std::cerr << "客户端未启动" << std::endl;
            return false;
        }
        
        try {
            // 将消息转换为JSON字符串
            std::string json_str = messageToString(message);
            
            // 设置服务器地址
            struct sockaddr_in server_addr;
            memset(&server_addr, 0, sizeof(server_addr));
            server_addr.sin_family = AF_INET;
            server_addr.sin_port = htons(port);
            inet_pton(AF_INET, host.c_str(), &(server_addr.sin_addr));
            
            // 发送数据
            ssize_t bytes_sent = sendto(client_socket, json_str.c_str(), json_str.length(), 0, 
                                      (struct sockaddr*)&server_addr, sizeof(server_addr));
            
            if (bytes_sent < 0) {
                throw std::runtime_error("发送数据失败");
            }
            
            return true;
        } catch (const std::exception& e) {
            std::cerr << "发送消息失败: " << e.what() << std::endl;
            return false;
        }
    }
    
    void sendReliableMessage(const std::map<std::string, std::string>& message) {
        // 发送可靠消息（需要ACK确认）
        try {
            // 生成消息ID
            std::string message_id = generateMessageId(message);
            
            // 创建消息副本并添加消息ID
            std::map<std::string, std::string> message_with_id = message;
            message_with_id["message_id"] = message_id;
            
            // 发送消息
            sendMessage(message_with_id);
            
            // 添加到等待ACK列表
            std::lock_guard<std::mutex> lock_guard(lock);
            ack_waiters[message_id] = std::make_tuple(message_with_id, 0, std::chrono::steady_clock::now());
        } catch (const std::exception& e) {
            std::cerr << "发送可靠消息失败: " << e.what() << std::endl;
        }
    }
    
    void sendData(const std::string& data) {
        // 发送数据消息
        if (!registered) {
            std::cerr << "客户端未注册" << std::endl;
            return;
        }
        
        // 增加序列号
        {
            std::lock_guard<std::mutex> lock_guard(lock);
            sequence++;
        }
        
        std::map<std::string, std::string> message;
        message["type"] = "data";
        message["client_id"] = client_id;
        message["sequence"] = std::to_string(sequence);
        message["data"] = data;
        message["timestamp"] = std::to_string(std::chrono::duration_cast<std::chrono::seconds>(
            std::chrono::system_clock::now().time_since_epoch()).count());
        
        sendReliableMessage(message);
    }
    
    void registerMessageHandler(const std::string& message_type, std::function<void(const std::map<std::string, std::string>&)> handler) {
        // 注册消息处理器
        message_handlers[message_type] = handler;
    }
    
    void runInteractive() {
        // 运行交互式客户端
        if (!connect()) {

        }
        
        try {
            while (running) {
                // 等待注册完成
                if (!registered) {
                    std::this_thread::sleep_for(std::chrono::milliseconds(500));

                }

                std::cout << "请输入命令 (data/quit): ";

                if (command == "quit") {
                    break;
                } else if (command == "data") {
                    std::cout << "请输入数据内容: ";
                    std::string data;
                    std::getline(std::cin, data);
                    sendData(data);
                } else {
                    std::cout << "未知命令" << std::endl;
                }
            }
        } catch (const std::exception& e) {
            std::cerr << "运行交互式客户端时出错: " << e.what() << std::endl;
        } finally {
            disconnect();
        }
    }
};
```

## 10. HTTP编程实践

### 10.1 HTTP服务器实现

#### 10.1.1 基本HTTP服务器

下面是一个基本的HTTP服务器实现，使用C++编写：

```cpp
#include <iostream>
#include <string>
#include <thread>
#include <vector>
#include <map>
#include <functional>
#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>
#include <unistd.h>
#include <cstring>
#include <ctime>
#include <sstream>
#include <regex>
#include <fstream>

class HTTPServer {
private:
    std::string host;
    int port;
    int server_socket;
    bool running;
    std::map<std::string, std::pair<std::function<std::string(const std::map<std::string, std::string>&, const std::map<std::string, std::string>&, const std::string&)>, std::vector<std::string>>> routes;
    std::vector<std::thread> client_threads;
    
    struct Request {
        std::string method;
        std::string path;
        std::string version;
        std::map<std::string, std::string> query_params;
        std::map<std::string, std::string> headers;
        std::string body;
    };
    
    std::map<std::string, std::string> parseQueryParams(const std::string& query) {
        std::map<std::string, std::string> params;
        std::istringstream iss(query);
        std::string pair;
        
        while (std::getline(iss, pair, '&')) {
            size_t pos = pair.find('=');
            if (pos != std::string::npos) {
                std::string key = pair.substr(0, pos);
                std::string value = pair.substr(pos + 1);
                params[key] = value;
            }
        }
        
        return params;
    }
    
    Request parseRequest(const std::string& request_data) {
        Request request;
        
        // 分割请求头和请求体
        size_t header_end = request_data.find("\r\n\r\n");
        std::string header_part = request_data.substr(0, header_end);
        std::string body_part = (header_end != std::string::npos) ? 
                               request_data.substr(header_end + 4) : "";
        
        // 解析请求行
        std::istringstream header_stream(header_part);
        std::string request_line;
        std::getline(header_stream, request_line);
        
        // 移除\r
        if (!request_line.empty() && request_line.back() == '\r') {
            request_line.pop_back();
        }
        
        std::istringstream request_line_stream(request_line);
        request_line_stream >> request.method >> request.path >> request.version;
        
        // 解析查询参数
        size_t query_start = request.path.find('?');
        if (query_start != std::string::npos) {
            std::string query = request.path.substr(query_start + 1);
            request.path = request.path.substr(0, query_start);
            request.query_params = parseQueryParams(query);
        }
        
        // 解析请求头
        std::string header_line;
        while (std::getline(header_stream, header_line)) {
            // 移除\r
            if (!header_line.empty() && header_line.back() == '\r') {
                header_line.pop_back();
            }
            
            size_t colon_pos = header_line.find(':');
            if (colon_pos != std::string::npos) {
                std::string key = header_line.substr(0, colon_pos);
                std::string value = header_line.substr(colon_pos + 1);
                
                // 去除前后空格
                size_t start = value.find_first_not_of(" \t");
                if (start != std::string::npos) {
                    size_t end = value.find_last_not_of(" \t");
                    value = value.substr(start, end - start + 1);
                }
                
                request.headers[key] = value;
            }
        }
        
        request.body = body_part;
        
        return request;
    }
    
    bool pathMatches(const std::string& route_path, const std::string& request_path) {
        // 简单实现，支持静态路径匹配
        return route_path == request_path;
    }
    
    void sendResponse(int client_socket, int status_code, const std::string& content, const std::string& content_type = "text/html") {
        std::map<int, std::string> status_texts = {
            {200, "OK"},
            {201, "Created"},
            {400, "Bad Request"},
            {404, "Not Found"},
            {500, "Internal Server Error"}
        };
        
        std::string status_text = status_texts.count(status_code) ? status_texts[status_code] : "Unknown";
        
        // 获取当前时间
        time_t now = time(0);
        struct tm* timeinfo = gmtime(&now);
        char time_str[100];
        strftime(time_str, sizeof(time_str), "%a, %d %b %Y %H:%M:%S GMT", timeinfo);
        
        // 构建响应头
        std::string response_headers = 
            "HTTP/1.1 " + std::to_string(status_code) + " " + status_text + "\r\n" +
            "Content-Type: " + content_type + "\r\n" +
            "Content-Length: " + std::to_string(content.length()) + "\r\n" +
            "Date: " + std::string(time_str) + "\r\n" +
            "Server: SimpleHTTPServer/1.0\r\n" +
            "Connection: close\r\n" +
            "\r\n";
        
        // 构建完整响应
        std::string response = response_headers + content;
        
        // 发送响应
        send(client_socket, response.c_str(), response.length(), 0);
    }
    
    void handleClient(int client_socket, struct sockaddr_in client_address) {
        try {
            // 接收请求数据
            char buffer[4096];
            ssize_t bytes_received = recv(client_socket, buffer, sizeof(buffer) - 1, 0);
            
            if (bytes_received <= 0) {
                return;
            }
            
            buffer[bytes_received] = '\0';
            std::string request_data(buffer);
            
            // 解析HTTP请求
            Request request = parseRequest(request_data);
            
            std::cout << "来自 " << inet_ntoa(client_address.sin_addr) << ":" << ntohs(client_address.sin_port) 
                      << " 的请求: " << request.method << " " << request.path << std::endl;
            
            // 查找路由处理器
            std::function<std::string(const std::map<std::string, std::string>&, const std::map<std::string, std::string>&, const std::string&)> handler;
            bool found_route = false;
            
            for (const auto& route : routes) {
                if (pathMatches(route.first, request.path)) {
                    const auto& methods = route.second.second;
                    if (std::find(methods.begin(), methods.end(), request.method) != methods.end()) {
                        handler = route.second.first;
                        found_route = true;
                        break;
                    }
                }
            }
            
            // 处理请求
            if (found_route) {
                try {
                    std::string response = handler(request.query_params, request.headers, request.body);
                    sendResponse(client_socket, 200, response);
                } catch (const std::exception& e) {
                    std::cerr << "处理请求时出错: " << e.what() << std::endl;
                    sendResponse(client_socket, 500, "Internal Server Error");
                }
            } else {
                // 没有找到路由
                sendResponse(client_socket, 404, "Not Found");
            }
        } catch (const std::exception& e) {
            std::cerr << "处理客户端时出错: " << e.what() << std::endl;
        } finally {
            close(client_socket);
        }
    }
    
public:
    HTTPServer(const std::string& host = "0.0.0.0", int port = 8080) 
        : host(host), port(port), server_socket(-1), running(false) {
    }
    
    ~HTTPServer() {
        stop();
    }
    
    void route(const std::string& path, const std::vector<std::string>& methods = {"GET"}, 
               std::function<std::string(const std::map<std::string, std::string>&, const std::map<std::string, std::string>&, const std::string&)> handler) {
        routes[path] = std::make_pair(handler, methods);
    }
    
    void start() {
        try {
            // 创建TCP套接字
            server_socket = socket(AF_INET, SOCK_STREAM, 0);
            if (server_socket < 0) {
                throw std::runtime_error("创建套接字失败");
            }
            
            // 设置地址重用
            int opt = 1;
            if (setsockopt(server_socket, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt)) < 0) {
                throw std::runtime_error("设置套接字选项失败");
            }
            
            // 绑定地址
            struct sockaddr_in server_addr;
            memset(&server_addr, 0, sizeof(server_addr));
            server_addr.sin_family = AF_INET;
            server_addr.sin_addr.s_addr = INADDR_ANY;
            server_addr.sin_port = htons(port);
            
            if (bind(server_socket, (struct sockaddr*)&server_addr, sizeof(server_addr)) < 0) {
                throw std::runtime_error("绑定地址失败");
            }
            
            // 开始监听
            if (listen(server_socket, 5) < 0) {
                throw std::runtime_error("监听失败");
            }
            
            running = true;
            std::cout << "HTTP服务器启动，监听 " << host << ":" << port << std::endl;
            
            // 接受客户端连接
            while (running) {
                try {
                    struct sockaddr_in client_address;
                    socklen_t client_len = sizeof(client_address);
                    
                    int client_socket = accept(server_socket, (struct sockaddr*)&client_address, &client_len);
                    if (client_socket < 0) {
                        if (running) {
                            throw std::runtime_error("接受连接失败");
                        } else {
                            break; // 服务器正在关闭
                        }
                    }
                    
                    std::cout << "接受来自 " << inet_ntoa(client_address.sin_addr) 
                              << ":" << ntohs(client_address.sin_port) << " 的连接" << std::endl;
                    
                    // 为每个客户端创建新线程
                    client_threads.emplace_back([this, client_socket, client_address]() {
                        this->handleClient(client_socket, client_address);
                    });
                } catch (const std::exception& e) {
                    std::cerr << "接受连接时出错: " << e.what() << std::endl;
                }
            }
        } catch (const std::exception& e) {
            std::cerr << "服务器启动失败: " << e.what() << std::endl;
        } finally {
            stop();
        }
    }
    
    void stop() {
        running = false;
        
        // 关闭服务器套接字
        if (server_socket >= 0) {
            close(server_socket);
            server_socket = -1;
        }
        
        // 等待所有客户端线程完成
        for (auto& thread : client_threads) {
            if (thread.joinable()) {
                thread.join();
            }
        }
        client_threads.clear();
        
        std::cout << "HTTP服务器已停止" << std::endl;
    }
};

// 使用示例
int main() {
    HTTPServer server;

    server.route("/api/data", {"GET", "POST"}, [](const std::map<std::string, std::string>& query_params,
```

## 11. WebSocket编程实践

### 11.1 WebSocket服务器实现

#### 11.1.1 基本WebSocket服务器

下面是一个基本的WebSocket服务器实现，使用C++编写：

```cpp
#include <iostream>
#include <string>
#include <thread>
#include <vector>
#include <map>
#include <mutex>
#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>
#include <unistd.h>
#include <cstring>
#include <ctime>
#include <sstream>
#include <regex>
#include <fstream>
#include <openssl/sha.h>
#include <openssl/evp.h>
#include <openssl/bio.h>
#include <openssl/buffer.h>
#include <iomanip>

class WebSocketServer {
private:
    std::string host;
    int port;
    int server_socket;
    bool running;
    std::map<int, std::string> clients;  // 客户端套接字到ID的映射
    std::map<std::string, int> client_sockets;  // 客户端ID到套接字的映射
    int client_id_counter;
    std::mutex clients_mutex;
    std::vector<std::thread> client_threads;
    
    // Base64编码
    std::string base64_encode(const std::string& input) {
        BIO *bio, *b64;
        BUF_MEM *bufferPtr;
        
        b64 = BIO_new(BIO_f_base64());
        bio = BIO_new(BIO_s_mem());
        bio = BIO_push(b64, bio);
        
        BIO_set_flags(bio, BIO_FLAGS_BASE64_NO_NL);
        BIO_write(bio, input.c_str(), input.length());
        BIO_flush(bio);
        BIO_get_mem_ptr(bio, &bufferPtr);
        
        std::string result(bufferPtr->data, bufferPtr->length);
        BIO_free_all(bio);
        
        return result;
    }
    
    // 生成WebSocket接受密钥
    std::string generate_accept_key(const std::string& client_key) {
        // WebSocket魔术字符串
        const std::string magic_string = "258EAFA5-E914-47DA-95CA-C5AB0DC85B11";
        std::string combined = client_key + magic_string;
        
        // 计算SHA1哈希
        unsigned char hash[SHA_DIGEST_LENGTH];
        SHA1(reinterpret_cast<const unsigned char*>(combined.c_str()), combined.length(), hash);
        
        // Base64编码哈希值
        return base64_encode(std::string(reinterpret_cast<char*>(hash), SHA_DIGEST_LENGTH));
    }
    
    // 解析HTTP请求头
    std::map<std::string, std::string> parse_headers(const std::string& request) {
        std::map<std::string, std::string> headers;
        std::istringstream iss(request);
        std::string line;
        
        // 跳过请求行
        std::getline(iss, line);
        
        // 解析请求头
        while (std::getline(iss, line) && line != "\r") {
            size_t colon_pos = line.find(':');
            if (colon_pos != std::string::npos) {
                std::string key = line.substr(0, colon_pos);
                std::string value = line.substr(colon_pos + 1);
                
                // 去除前后空格
                size_t start = value.find_first_not_of(" \t\r\n");
                if (start != std::string::npos) {
                    size_t end = value.find_last_not_of(" \t\r\n");
                    value = value.substr(start, end - start + 1);
                }
                
                headers[key] = value;
            }
        }
        
        return headers;
    }
    
    // 发送WebSocket握手响应
    bool send_handshake_response(int client_socket, const std::string& client_key) {
        std::string accept_key = generate_accept_key(client_key);
        
        std::string response = 
            "HTTP/1.1 101 Switching Protocols\r\n"
            "Upgrade: websocket\r\n"
            "Connection: Upgrade\r\n"
            "Sec-WebSocket-Accept: " + accept_key + "\r\n"
            "\r\n";
        
        return send(client_socket, response.c_str(), response.length(), 0) > 0;
    }
    
    // 解析WebSocket帧
    struct WebSocketFrame {
        bool fin;
        bool rsv1, rsv2, rsv3;
        int opcode;
        bool masked;
        uint64_t payload_length;
        std::string masking_key;
        std::string payload_data;
    };
    
    WebSocketFrame parse_frame(const std::string& frame_data) {
        WebSocketFrame frame;
        
        if (frame_data.length() < 2) {
            return frame; // 无效帧
        }
        
        // 解析第一个字节
        unsigned char first_byte = frame_data[0];
        frame.fin = (first_byte & 0x80) != 0;
        frame.rsv1 = (first_byte & 0x40) != 0;
        frame.rsv2 = (first_byte & 0x20) != 0;
        frame.rsv3 = (first_byte & 0x10) != 0;
        frame.opcode = first_byte & 0x0F;
        
        // 解析第二个字节
        unsigned char second_byte = frame_data[1];
        frame.masked = (second_byte & 0x80) != 0;
        frame.payload_length = second_byte & 0x7F;
        
        size_t offset = 2;
        
        // 解析扩展的载荷长度
        if (frame.payload_length == 126) {
            if (frame_data.length() < offset + 2) {
                return frame; // 无效帧
            }
            frame.payload_length = (static_cast<unsigned char>(frame_data[offset]) << 8) | 
                                   static_cast<unsigned char>(frame_data[offset + 1]);
            offset += 2;
        } else if (frame.payload_length == 127) {
            if (frame_data.length() < offset + 8) {
                return frame; // 无效帧
            }
            frame.payload_length = 0;
            for (int i = 0; i < 8; i++) {
                frame.payload_length = (frame.payload_length << 8) | 
                                       static_cast<unsigned char>(frame_data[offset + i]);
            }
            offset += 8;
        }
        
        // 解析掩码键（如果存在）
        if (frame.masked) {
            if (frame_data.length() < offset + 4) {
                return frame; // 无效帧
            }
            frame.masking_key = frame_data.substr(offset, 4);
            offset += 4;
        }
        
        // 解析载荷数据
        if (frame_data.length() < offset + frame.payload_length) {
            return frame; // 无效帧
        }
        frame.payload_data = frame_data.substr(offset, frame.payload_length);
        
        // 如果有掩码，解密载荷数据
        if (frame.masked) {
            for (size_t i = 0; i < frame.payload_data.length(); i++) {
                frame.payload_data[i] ^= frame.masking_key[i % 4];
            }
        }
        
        return frame;
    }
    
    // 创建WebSocket帧
    std::string create_frame(int opcode, const std::string& payload_data, bool fin = true) {
        std::string frame;
        
        // 第一个字节：FIN + RSV + opcode
        unsigned char first_byte = (fin ? 0x80 : 0x00) | (opcode & 0x0F);
        frame.push_back(first_byte);
        
        // 载荷长度
        uint64_t payload_length = payload_data.length();
        
        // 第二个字节：MASK + payload_length
        if (payload_length < 126) {
            frame.push_back(static_cast<unsigned char>(payload_length));
        } else if (payload_length < 65536) {
            frame.push_back(126);
            frame.push_back(static_cast<unsigned char>((payload_length >> 8) & 0xFF));
            frame.push_back(static_cast<unsigned char>(payload_length & 0xFF));
        } else {
            frame.push_back(127);
            for (int i = 7; i >= 0; i--) {
                frame.push_back(static_cast<unsigned char>((payload_length >> (i * 8)) & 0xFF));
            }
        }
        
        // 载荷数据
        frame += payload_data;
        
        return frame;
    }
    
    // 发送文本消息
    bool send_text_message(int client_socket, const std::string& message) {
        std::string frame = create_frame(1, message); // opcode 1 = 文本帧
        return send(client_socket, frame.c_str(), frame.length(), 0) > 0;
    }
    
    // 发送二进制消息
    bool send_binary_message(int client_socket, const std::string& data) {
        std::string frame = create_frame(2, data); // opcode 2 = 二进制帧
        return send(client_socket, frame.c_str(), frame.length(), 0) > 0;
    }
    
    // 发送Ping帧
    bool send_ping(int client_socket) {
        std::string frame = create_frame(9, ""); // opcode 9 = Ping
        return send(client_socket, frame.c_str(), frame.length(), 0) > 0;
    }
    
    // 发送Pong帧
    bool send_pong(int client_socket, const std::string& payload = "") {
        std::string frame = create_frame(10, payload); // opcode 10 = Pong
        return send(client_socket, frame.c_str(), frame.length(), 0) > 0;
    }
    
    // 发送关闭帧
    bool send_close(int client_socket, int code = 1000, const std::string& reason = "") {
        std::string payload;
        payload.push_back(static_cast<unsigned char>((code >> 8) & 0xFF));
        payload.push_back(static_cast<unsigned char>(code & 0xFF));
        payload += reason;
        
        std::string frame = create_frame(8, payload); // opcode 8 = 关闭帧
        return send(client_socket, frame.c_str(), frame.length(), 0) > 0;
    }
    
    // 处理客户端连接
    void handle_client(int client_socket, struct sockaddr_in client_address) {
        try {
            // 接收握手请求
            char buffer[4096];
            ssize_t bytes_received = recv(client_socket, buffer, sizeof(buffer) - 1, 0);
            
            if (bytes_received <= 0) {
                return;
            }
            
            buffer[bytes_received] = '\0';
            std::string handshake_request(buffer);
            
            // 解析握手请求
            std::map<std::string, std::string> headers = parse_headers(handshake_request);
            
            // 检查是否是WebSocket升级请求
            auto upgrade_it = headers.find("Upgrade");
            if (upgrade_it == headers.end() || upgrade_it->second != "websocket") {
                close(client_socket);
                return;
            }
            
            // 获取WebSocket密钥
            auto key_it = headers.find("Sec-WebSocket-Key");
            if (key_it == headers.end()) {
                close(client_socket);
                return;
            }
            
            std::string client_key = key_it->second;
            
            // 发送握手响应
            if (!send_handshake_response(client_socket, client_key)) {
                close(client_socket);
                return;
            }
            
            std::cout << "WebSocket握手完成，来自 " << inet_ntoa(client_address.sin_addr) 
                      << ":" << ntohs(client_address.sin_port) << std::endl;
            
            // 生成客户端ID
            std::string client_id = "client_" + std::to_string(++client_id_counter);
            
            // 添加客户端到列表
            {
                std::lock_guard<std::mutex> lock(clients_mutex);
                clients[client_socket] = client_id;
                client_sockets[client_id] = client_socket;
            }
            
            // 处理WebSocket消息
            char frame_buffer[4096];
            while (running) {
                bytes_received = recv(client_socket, frame_buffer, sizeof(frame_buffer), 0);
                
                if (bytes_received <= 0) {
                    break;
                }
                
                std::string frame_data(frame_buffer, bytes_received);
                WebSocketFrame frame = parse_frame(frame_data);
                
                if (frame.opcode == 8) { // 关闭帧
                    break;
                } else if (frame.opcode == 9) { // Ping帧
                    send_pong(client_socket, frame.payload_data);
                } else if (frame.opcode == 1) { // 文本帧
                    std::cout << "收到来自 " << client_id << " 的消息: " << frame.payload_data << std::endl;
                    
                    // 简单回显
                    send_text_message(client_socket, "Echo: " + frame.payload_data);
                    
                    // 广播消息给所有客户端
                    broadcast_message(client_id, frame.payload_data);
                }
            }
        } catch (const std::exception& e) {
            std::cerr << "处理客户端时出错: " << e.what() << std::endl;
        } finally {
            // 从客户端列表中移除
            {
                std::lock_guard<std::mutex> lock(clients_mutex);
                auto it = clients.find(client_socket);
                if (it != clients.end()) {
                    std::string client_id = it->second;
                    clients.erase(it);
                    client_sockets.erase(client_id);
                }
            }
            
            close(client_socket);
        }
    }
    
    // 广播消息给所有客户端
    void broadcast_message(const std::string& sender_id, const std::string& message) {
        std::lock_guard<std::mutex> lock(clients_mutex);
        
        for (const auto& client : client_sockets) {
            if (client.first != sender_id) {
                send_text_message(client.second, "Broadcast from " + sender_id + ": " + message);
            }
        }
    }
    
public:
    WebSocketServer(const std::string& host = "0.0.0.0", int port = 8080) 
        : host(host), port(port), server_socket(-1), running(false), client_id_counter(0) {
    }
    
    ~WebSocketServer() {
        stop();
    }
    
    void start() {
        try {
            // 创建TCP套接字
            server_socket = socket(AF_INET, SOCK_STREAM, 0);
            if (server_socket < 0) {
                throw std::runtime_error("创建套接字失败");
            }
            
            // 设置地址重用
            int opt = 1;
            if (setsockopt(server_socket, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt)) < 0) {
                throw std::runtime_error("设置套接字选项失败");
            }
            
            // 绑定地址
            struct sockaddr_in server_addr;
            memset(&server_addr, 0, sizeof(server_addr));
            server_addr.sin_family = AF_INET;
            server_addr.sin_addr.s_addr = INADDR_ANY;
            server_addr.sin_port = htons(port);
            
            if (bind(server_socket, (struct sockaddr*)&server_addr, sizeof(server_addr)) < 0) {
                throw std::runtime_error("绑定地址失败");
            }
            
            // 开始监听
            if (listen(server_socket, 5) < 0) {
                throw std::runtime_error("监听失败");
            }
            
            running = true;
            std::cout << "WebSocket服务器启动，监听 " << host << ":" << port << std::endl;
            
            // 接受客户端连接
            while (running) {
                try {
                    struct sockaddr_in client_address;
                    socklen_t client_len = sizeof(client_address);
                    
                    int client_socket = accept(server_socket, (struct sockaddr*)&client_address, &client_len);
                    if (client_socket < 0) {
                        if (running) {
                            throw std::runtime_error("接受连接失败");
                        } else {
                            break; // 服务器正在关闭
                        }
                    }
                    
                    std::cout << "接受来自 " << inet_ntoa(client_address.sin_addr) 
                              << ":" << ntohs(client_address.sin_port) << " 的连接" << std::endl;
                    
                    // 为每个客户端创建新线程
                    client_threads.emplace_back([this, client_socket, client_address]() {
                        this->handle_client(client_socket, client_address);
                    });
                } catch (const std::exception& e) {
                    std::cerr << "接受连接时出错: " << e.what() << std::endl;
                }
            }
        } catch (const std::exception& e) {
            std::cerr << "服务器启动失败: " << e.what() << std::endl;
        } finally {
            stop();
        }
    }
    
    void stop() {
        running = false;
        
        // 关闭所有客户端连接
        {
            std::lock_guard<std::mutex> lock(clients_mutex);
            for (const auto& client : clients) {
                try {
                    send_close(client.first);
                    close(client.first);
                } catch (...) {
                    // 忽略关闭错误
                }
            }
            clients.clear();
            client_sockets.clear();
        }
        
        // 关闭服务器套接字
        if (server_socket >= 0) {
            close(server_socket);
            server_socket = -1;
        }
        
        // 等待所有客户端线程完成
        for (auto& thread : client_threads) {
            if (thread.joinable()) {
                thread.join();
            }
        }
        client_threads.clear();
        
        std::cout << "WebSocket服务器已停止" << std::endl;
    }
    
    // 获取连接的客户端数量
    size_t get_client_count() {
        std::lock_guard<std::mutex> lock(clients_mutex);
        return clients.size();
    }
};

// 使用示例
int main() {
    WebSocketServer server;
    
    try {
        server.start();
    } catch (const std::exception& e) {
        std::cerr << "程序异常: " << e.what() << std::endl;
        server.stop();
    }
    
    return 0;
}
```
